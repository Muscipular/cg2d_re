## 战斗目标选择依赖 SPEC（2026-09-28）

499C30的两个真实调用为43C560和43C060；前者另依赖405B40，三者全部指令已核。
405B40对S32位置0..4或10..14加5，其他减5，不加范围校验。
43C560先将完整W32目标标志发布到5ABC44，再计算宠物位；bit1清时返回0，
不清对象旧选择位。bit4宠物、bit8自身、bits810友方、bit20敌方依原顺序扫描；
友方排除自身和宠物，bit10清时仅bit800且载荷原FDC低字节bit4者继续。

允许者在比较后重新取同源对象指针，原flags24置8，不缓存HP或合并重复候选。
友敌范围按位置有符号小于10划分。bit1置时即使没有候选，仍返回1。

原四行顺序固定为14/12/10/11/13、19/17/15/16/18、
9/7/5/6/8、4/2/0/1/3。仅目标bit400且（玩家flags bit80或位置!=当前位）

对方前排的flags bit8，满足时清对方后排bit8，其他行不变。

5ABC44以World唯一U32零初值保存完整目标位模式。两个对象函数放既有Yobi实现，

由action.payload借用类型化T*，不复制x86的13E8H布局或猜测未用字段；
