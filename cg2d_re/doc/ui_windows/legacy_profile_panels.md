## 501F60闪烁

原`501F60..501FC9`30条指令。D67440是唯一U32时间戳，CC3EF8是唯一U32显示标志，
两者原is_loaded=false，初值零；只在本文件私有承载，未增加平行状态。
BP仍借D2F788，当前已查两地址只由此函数及5014A0直接访问。

- BP为零：先清CC3EF8，再清D67440，返回0，不读取时钟。
- BP非零且时间戳零：先标志=1，再读一次GetTickCount并发布时间戳、返回该值。
- 时间戳非零：先读时钟，再读取时间戳，以U32比较`timestamp+1000 < now`。
  条件不成立返回第一次时钟值，不改标志/时间戳；成立才完整W32
  `(flag-1)&1`写回标志，**再读一次时钟**保存并返回。
  不改为差值计时、不用`<=`、不以第一读替代第二读，不钳制回绕。

平台沿既有ReadTickCount32；本轮不执行计时、发送或绘制逻辑。
