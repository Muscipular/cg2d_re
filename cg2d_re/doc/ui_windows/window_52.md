## 窗口52与商店选择 SPEC（2026-09-29）

接续15ac5cdb，完成49FCA0/49FD20/49FE40/49FF70/49FFA0、
4A00C0/4A0140及56D838三元素。窗口52既有54E960主/拖动原型不改。
原状态C9A978..C9A998归唯一UI选择对话状态：类型/图号S32，
标题为借用const char*，正文/选项/提示均为借用const char* const*，
回调为原生`int32_t (*)(int32_t)`，两计数保存U8、循环按S8比较；
关闭有效标记仍U8。所有地址不存W32，不增加文本所有权或释放行为。

- 49FCA0按原顺序发布上述状态；有旧52实例才置关闭并清有效标记，
  随后Yobi::newWindow2(52,1,0,0)，不提前拒绝或清空借用源。
- 49FD20在value=-1时复制标题、按TextMeasure(title,1)重新测量，
  中心x=(当前宽-测量)>>1再加6；既有动画载荷图号2A8写入口图号，
  方向2B8写5，各次重取当前实例。选项计数非零按S8算14*n-2，否则高度0，
  标记置1；每次更新均4D3040(2,2)，命中先关闭、SE57，再无条件回调(-1)。
- 49FE40先DrawCurrentWindow，再按S8计数绘制正文和选项，跳空文本指针，
  每轮重取共享表/计数/当前实例；正文x+87/y+40+13*i，
  选项用第三元素坐标和14*i。随后49BE00背景、类型不一致时关闭/SE57，
  最后清文本队列3并返回1。
- 49FF70仅在标记非零且当前类型仍一致时清581800=-1；沿已证release接口void，
  不恢复上下文、不释放借用文本、不添加回调。
- 49FFA0仅检查state最低位；无该位返回0，其余最终返回1。
  每项按低S16坐标作12高命中，悬停后重读当前元素宽画边框，
  拷贝对应提示至D68AE8。实际点击来自D68D9C（鼠标edgeButtons）最低位，
  不是state bit2；点击仅在回调非空时调用，再SE79、重取当前实例并关闭。
  回调返回不控制关闭，未点击继续扫描，计数每轮按S8重取。

原型三元素逐8个W32核对：type3标题(40,10)借56D828，
四元数据00/0C/00/00、文本借593850；type2动画(40,135)借56D830图号100000；
type0选择区(99,142,108,0)、回调49FFA0。均初始可见1，不追加关闭按钮。

4A0140读取字段1图号、字段2标题(cap21)、字段3正文(cap255)，后两项原位
Unescape2。逐五行503AB0(cap81,width20)写CC2525并发布D672D8借用指针，
字段4取低U8：bit0追加买/命令1，bit1追加卖/命令2，末尾必追加不用了/命令3；
不清未使用尾槽。六个标签/提示保留57E6B8..CC实际指向的原字节。
4A00C0仅有符号index0..1发送，对应命令按S8格式化，经52D2D0(cap15)，
依序采D2DE6C/CC21E0/Y/X/socket并512620(button0)；其余返回原index。
因此“不用了”是否发送取决于实际索引，不能按标签或命令3直接省略发送。

工程存储裁决：CC24D4及CC2525相差81B，与其他NPC窗口同源，采用唯一30个

后续窗口仍须复用并核其余重叠消费，容量选择不是原源码数组声明/最终布局冻结。
