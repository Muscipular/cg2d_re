# 环境检测与异常上报移除 SPEC

日期：2026-10-17。编号：PRM01。状态：按用户“那移除该功能逻辑”的明确要求实施。

## 范围

移除InitializeProtection_4041E0及其环境检测、窗口扫描、规则解析、校验和PGXE上报整条链路。当前所有PGXE生产者均位于此链路，包含F10触发的另一组窗口扫描及周期报码101；一并删除，而不是保留返回固定成功的空入口。

1. MainLoopSupport删除防护初始化／释放、进程模块枚举、系统函数入口字节检查、命名互斥量检查、调试器检查、窗口标题规则扫描、规则表解析与校验及专属状态。刚替换的RtlGetVersion也随唯一消费者移除。
2. MainLoop删除上述调用、F10检测入口、标题／尺寸匹配回调、延迟上报和周期报码101，删除专用时间状态和CheckSystemSeconds_458A10间隔判断；ReadSystemSeconds_4589D0仍供WindowBottomBar使用，保留实现及声明。实际帧节奏、FPS显示、游戏更新时间、消息循环、渲染与KeepAlive保持。
3. 登录响应继续按原分隔符保留前半段正文，不解析或保存后半段防护规则；登录结果、协议模式和其他命令保持。发送队列删除仅处理窗口上报状态的分支，保留原发送队列与连接状态处理。
4. 删除无剩余消费者的Report_512CA0声明／实现，以及防护专属的三个LegacyCryptInt全局对象。LegacyCryptInt类及其他消费者保持。
5. 删除仅供防护检查使用的启动命名互斥量创建、释放和句柄。原启动处没有ERROR_ALREADY_EXISTS处理，未承担单实例拒绝逻辑；updated命令行检查与其他启动行为保持。
6. 保留仍用于业务的SeedRandom／Rand16／RandomRange／ReadTickCount64、窗口API、系统DLL和通用网络发送函数；不按DLL名称批量移除系统依赖。
7. 按用户追加的“相关无用变量也一并移除”，删除失去防护消费者的登录结果标志gRequestOutcomeFlag及读取接口、网络首标记valueD9F2D0及写入接口／复位点、窗口回调专用ReadProtocolByte593850接口。登录回复码、请求状态、协议模式及发送队列保持；不按名称或相邻地址扩删其他状态。

## 具名行为变化

客户端不再枚举其他进程模块或桌面窗口进行这类检查，不检测调试器或GetTickCount64入口字节，不按检测结果重设帧间隔，不发送PGXE。服务器不再收到对应上报；服务端的处理策略不在本次修改范围，尚无运行验证。

移除三个防护CryptInt对象及防护路径中的读写，减少相应RNG消费；移除窗口扫描和周期上报的随机播种／随机间隔，后续共享随机序列因此可能改变。这是移除该功能的明确后果，不保留仅为模拟已移除功能的随机数消耗。其他业务随机调用及对象构造顺序保持。

此移除要求覆盖本链路的旧还原／RNG顺序约束及371的版本查询实现，不外推到其他模块；UBW01异常分支处理仍待确认。
