## 2. 真实数据与取样

- 说明常量559694/5596A0两12B含NUL原字节沿既有constexpr数组；共享说明100B/IME状态/组合属性各256B/候选指针仍WindowProcedure.cpp唯一存储，生命周期和通知生产沿[IME合同](cg2d_ime_lifecycle.md)、[窗口合同](cg2d_window_procedure.md)。
- 两说明坐标为.data中的原低W16读，初值X=542/Y=461；各只见一个直接reader，未证间接writer。RenderInput.cpp原生两个S16实际存储承接，位置读取不从常量参数或独立新影子布局产生；本组不构造未经证明的坐标更新入口。
- 各组合/属性阶段和候选序号字体→转换→位置、正文字体→两候选读取→位置、strlen缓存→测宽→选择→框都按原点重取当前指针/完整字体和字段。两个候选读取不合并；正文测宽用strlen前缓存的同一文本指针，不再次换列表。
- CANDIDATELIST字段维持DWORD +8/+C/+10/+14/+18；真实头/可变尾仍API owner，ReadCandidateOffset只读取一个原W32 offset、在原生地址边界拓宽。既有固定头dwOffset[1]不当数组容量，未记录分配尺寸的未知边界不造检查。
- 候选序号仍原S32十进制itoa，12B当前局部不清；其返回char*为借用同一目标，序号绘制消费该实际返回。正文strlen边界W32且signed<2取2、向零除2的布局规则保持，不能把原下限2当额外保护删除。
- DrawText/DrawText2/TextMeasure/DrawGraphicHover返回消费、原字节/低S16坐标/低U16框/低S8参数、选中D9/0与未选D8/252、无RNG和共享owner不改。

## 3. 实施裁决

1. 只在既有RenderInput.cpp移除IsValidFontType/HasSafeCompositionText/CanScanCompositionAttributes与无用kImeBufferCapacity，撤销组合/属性/候选辅助空对象/字体/重复Count条件及影子valid/hasWidth标志。保留原入口/列表/项门禁，不新建cpp/公共接口/依赖、RTTI或候选owner。
2. FormatDecimalW32保持既有签名参数和Itoa_54ABDD真实callee，返回改char*并被序号绘制消费。其正文之外、Itoa/协议调用及叶逻辑不变；ReadField138Bits/地址边界与既有运算/截断helper保持，不新增故障/溢出模拟。
3. 两说明S16原槽放既有业务namespace、按已加载值初始化，说明调用前独立Y→X取样；本组无外部直接使用，不扩公共头或补虚构writer。未知alias仍R02开放。
4. DrawCandidateEntry无新增早退/补值，每次读原阶段存储，units先在正文阶段增加1、strlen后再按原长度/2增加；loop有效项完成后才重新读取候选表，跳过项维持本轮表，读取pageSize→递增→无符号比较。不得由额外尾指针检查改变原流程。
5. 两局部键态/序号预清撤销。API失败留下未写字节、外部调用后空对象/列表、表外字体/偏移和越界/溢出依RPLAN.24不专项处理；不加默认键态/检查/补零，不模拟或声明x64安全/原故障等价。
6. 补4590E0完整语义，已有44B250/44B2A0/54ABDD只更新局部父关联/当前状态；不重复提升这些叶或其余21父完整处置。T01/T02与整体输入/文本门禁保持open，EIC01/ICA01成果保持。
