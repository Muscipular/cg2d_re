## 2. 本步工程决定

1. 保留现有 SurfaceTransformCache 类型、完整指针键和两个独立 owner。宿主 STL 承接私有节点、空节点、树形、分配/异常及计数，不创建 62B0AC/62B0B0 的假镜像或旧 48B 节点。
2. 将两个自动构析的 map 全局对象改为同文件内两块 alignas/sizeof(SurfaceTransformCache) 的被动存储。构造用 std::construct_at，借用用已存活对象的 std::launder，析构用 std::destroy_at；不通过字节偏移访问旧节点。
3. 提供两个具名 S32 初始化入口，分别固定调用本树构造后 std::atexit 登记本树无参析构，并透传实际登记结果。接受 D02 的宿主退出表及私有分配差异，不把 std::atexit 记为旧 53B406 已还原或新增其原本体调用。
4. 当前同模块启动位置使用一个无析构动作的启动对象，按原相邻槽顺序调用两个入口且忽略结果。取消两个 map 的自动构造/自动析构，构造/登记/退出只保留这一套活动路径；不加 once、懒构造、重试、回滚、额外保护或固定成功。
5. 构析只处理节点。三个现有业务选择位置（查询、发布、场景清理）改为借用各自同一已构造对象；键、场景读取时点、面创建/释放、erase 次序与所有 TextureSurfaceOwner 行为保持。
6. 两个公开初始化接口用于后续 C02/C04 的原应用序接入；当前没有第二调用者。迁移全表时必须在同一步移除本模块启动适配，不能在其仍活动时重复执行。跨模块原应用相对顺序、快速退出以及完整客户端入口继续未闭，不以本局部模块位置替代全表。

这里保留当前同模块的启动位置，避免改变已有消费者的前置条件；同时把本组构造和退出变成可在真实应用序中成对移动的具名提供者。不得给初始化入口新增正常重复调用保证；原表与本模块活动路径均每项一次。

## 3. 验收边界

| 局部门禁 | 必须证明 |
|---|---|
| I 实现 | 两块被动存储、两个真实 map 构造、两个具名析构及两个实际宿主登记，没有自动 map 析构并行执行 |
| W 接线/寿命 | 629300 构造→立即登记→62A630 构造→立即登记；仅本组模块启动调用；查询/发布/清理借用同一存储；退出逆序由实际宿主登记承担 |
| S 静态对照 | 原 178 条/相邻槽与新增路径对应；析构无面释放，场景清理仍先释放/清值/摘项；无残留旧 map 对象、旧节点布局或假私有槽 |
| R 运行 | 当前禁止构建/测试/运行，宿主实际初始化、登记失败、退出/重入和跨模块顺序未验 |

私有节点/共享空节点由宿主承接标为 host；应用固定 owner、即时登记与顺序标为 adapted。局部证据不能升级整个渲染或启动门禁。C09 仍须与 C02/C04、G01 的全应用启动/清理闭合，任务先保持 open。

## 4. 源码与局部证据收口

本步已在既有 GraphicDxCache.cpp 实施 §2：两个 alignas/sizeof 被动存储、两个固定构造、两个固定节点析构、两个实际宿主登记入口，以及一个 trivially destructible 的模块启动适配。对每树是 construct_at → 即时 atexit 登记；适配先第一项再第二项，不读取登记结果，不在第一次失败时短路。取消原两个 map 全局自动构析，没有第二套 map、自动 map 析构、旧节点表头或私有计数/空节点镜像。TextureSurfaceOwner 的既有构析位置/面行为不改。

查询、发布和场景清理三个实际选择位置都借用上述同一已存活对象，仍各自在原时点重读场景。析构回调固定 owner，只 std::destroy_at；44D490 仍在既有两个调用点按 release → 清值 → erase 逐项处理。没有在节点退出加 surface 释放、全树业务 clear、懒初始化、once、回滚或空保护。两个 S32 初始化接口目前各只有这一模块适配调用；未来 C02/C04 接原应用表序时必须同时移除该适配。

语义登记仍 1144 条/1141 个原 ID，更新八已有身份的具名提供者、原 chunks/指令数与批准边界；六应用构析/登记处置 adapted，两私有节点机制处置 host。原八身份 178 条、两相邻槽、两数据范围直接引用和新增路径仅作本组静态对照，454050/44D490 的已存在算法不重做。全量未知、原应用顺序、失败传播、快速退出、完整资源/场景清理仍保留。

归档 E-GRAPHIC-TREES-I/W/S-20261004 三条限定局部证据，版本固定到 Git 命名快照 cg2d-re-graphic-trees-source-20261004。函数字段、宿主职责分类与当前接线源码可核，不把获批私有机制承接称为旧 CRT 逐指令等价。FUNC-STARTUP/FUNC-RENDER 明确登记本组八成员但枚举未闭；完整功能门禁仍未提升。

C09 当前仍 open，累计关闭的源码任务保持 10 项，叶功能验收保持 0/182；本步不构建、检查产物、新增或执行测试、运行或计算任何文件摘要。
