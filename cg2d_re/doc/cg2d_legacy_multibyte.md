仅非两个相同斜杠的路径才调用543D37，将首字节大写后建立“=X:”环境项。

## 原共享存储

当前原.data的[1086764,1086988)为无文件后备区域，沿已批准映像虚拟零合同初始化。
新LegacyMultibyteStorage逐字段保持原数值/字节偏移，不含指针：

| 相对偏移 | 原地址 | 类型与职责 |
|---|---|---|
| 00 | 1086764 | U32多字节代码页 |
| 04 | 1086768..108676F | 8B暂不解释，保持原共享窗口 |
| 0C | 1086770/74/78 | 三个U32代码页表参数 |
| 18 | 108677C | S32多字节标记 |
| 1C | 1086780 | 256B大小写映射 |
| 11C | 1086880 | 257B分类表；1086881[value]为字符槽，首项单独保留 |
| 21D | 1086981..83 | 三字节间隔 |
| 220 | 1086984 | U32多字节locale，不能误放到108676C |

该存储与LegacyStringCompare的C语言分类表、1086160 locale分开；
它们是原端不同地址和生产链，不因都称locale就合并。
它也不是第二份模拟表：后续5468EA/546B29必须直接写这一对象。
未来跨区间原字节别名必须映射到同一owner，不因已有独立对象忽略别名。
初始零仅是映像装载状态，不代表初始化已完成或可用空目录数据。

### NLS范围和失败

分类只承接本生产器的infoType=1/sourceCount=256/strict=0，保留独立10862E4
A/W探测状态；ANSI分支的locale=0回退到1086160，宽分支代码页0回退1086170。
宽分支按flags=1查长，在同一栈帧分配并清对应WCHAR字节，然后真实转换，
只把第二次转换返回的长度传GetStringTypeW。分配/转换/API失败返回0。

大小写映射只承接flags=100h或200h、source/destinationCount=256、strict=0；
仍先按首NUL缩短源范围。复用原1086198 A/W探测；宽分支两次栈分配分别用于
源宽串和映射宽串，保持API顺序与220h回转flags。没有SORTKEY调用域，
不公开通用LCMap包装。保留栈申请异常返回0，不换堆申请或增加默认字符。

546B29的三个调用全部执行，输出局部数组保持未初始化、返回继续忽略。
没有新补值或失败早退；失败后未写字节的C++行为不能证明复现旧栈内容，
此项明确未验，不能计为完整失败语义验收。此处不改变已有明确待批补值项目。

### 状态生产和顺序

新增10862E4分类后端、10862E8系统代码页标志、1087AEC初始化门禁，
均沿原虚拟零初值、各自唯一持有；原共享字节窗口仍需未来别名消费者使用同一owner。
546A83保留先清系统标志；-2/-3先置1再取OEM/ACP，-4先读1086170再置1。
5468EA参数保持U32位型；相同代码页直接返回0，不能无条件刷新表。
五组48B常量逐字段取自5923F0，掩码取5923E8；源常量只回映对照，不计算摘要。

固定表命中先清分类再逐区间OR，按原位发布isMultibyte、codePage、参数0/1、
locale、参数2。通用GetCPInfo返回严格等于1才使用结构；保留lead标记4、
1..254的trail标记8及原参数清零。失败按系统标志决定SBCS回退或-1。
所有成功更新最后进入546B29，不省略第二次GetCPInfo。
546CAE只在门禁为0时调用setmbcp(-3)，返回值不作为重试条件，调用后门禁置1。

在LegacyMouse已有晚段CRT对象之后添加553178对应初始化器，无析构/额外atexit。
三个原环境/参数启动辅助不消费其返回；当前只接真实CRT初始化职责，
不声称这三个旧环境入口本身已重建或跨全部翻译单元顺序已验。

### 目录边界

LegacyTime实现ChangeLegacyDirectory_53DD2F并复用542F44，StartupCommon两处_chdir
真实换接。SetCurrentDirectoryA失败立即取系统错误并映射-1；
成功后GetCurrentDirectoryA(261,buffer)，返回0才失败，不额外比较所需长度。
原缓冲在首斜杠和次字节相等时直接成功；否则按已初始化表转换首U8，
构造4B“=X:”环境项，再SetEnvironmentVariableA。失败映射并返回-1，
不回滚已改变CWD；成功不清共享errno。
保留261B未预清零的栈缓冲、旧ANSI字节，不添加Unicode转换、长度保护或重试。
路径过长/未写局部缓冲等异常不专项模拟，亦不记为故障等价通过。
