但原元素回调与代码/RET边界明确，不修改数据库。

SE51→读场景→取当前窗口/状态→标关闭→OpenWindow→发布CF4690→返回1。

不判断打开返回、不消费非点击hover、不保存文件或清状态栏闪烁相位。
