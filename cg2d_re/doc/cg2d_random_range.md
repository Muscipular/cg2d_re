## 原端 W32 算法、早退与消费次数

记 `L`、`U` 为 lower、upper 的 W32 位模式；`W32(x)` 表示保留低 32 位，
`S32(x)` 表示将同一 W32 位模式按 signed32 解释。
区间除数为 `D = S32(W32(U - L + 1))`。
`N` 只表示非早退路径上一次 `NextRandom_53B4C9` 的结果，不表示提前取数。

| 条件 | 原端结果 | 本入口 RNG 消费 |
|---|---|---|
| `W32(U + 1) == 0` | `EAX = 0`；不读 lower、不取余 | 0 次 |
| `W32(U + 1) != 0` 且 `D != 0` | `EAX = W32(L + (N % D))`，按 S32 返回 | 1 次 |
| `W32(U + 1) != 0` 且 `D == 0` | `0x46FB0B: idiv esi` 整数除零，无正常返回 | 故障前已消费 1 次 |

非早退路径在 RNG 调用后读取 lower；`0x46FB0B-0x46FB12` 完成 signed
除法取余、W32 加下界及返回。表中的 `%` 表示 signed32 余数语义，
表中故障为原端证据，不代表 C++ 零除数取模具有相同的故障或副作用保证。
负除数仍使用 signed 余数，不交换上下界，也不保证返回值落入所谓“修正区间”。

### 普通除零事实与历史门禁

非早退普通除零的精确条件为：
`W32(upper + 1) == lower` 且 `upper != -1`；
等式两侧按 W32 位模式比较，`-1` 表示 signed32 的全 1 位模式。

- `(lower, upper) = (1, 0)` 无需发生 overflow 就会除零；原入口先消费 1 次 RNG，
  再在 `idiv esi` 故障。这只是入口条件示例，不是已证 caller 输入。
- `(0, -1)` 虽然区间除数按位计算为零，但先命中 upper 早退，返回 0，不消费 RNG。
- 上下界倒置不必导致除零，不能用“倒置区间”替代上述精确条件。
- `N` 仅为 `0..32767`，所以此处不存在 IDIV 商溢出；除数为 `INT32_MIN`
  或 `-1` 也不造成商溢出。不设置数值极值门槛。
- 旧阶段排除 overflow、专项回绕及令牌耗尽，但仍将一般内存、栈及除零留作门禁；
  其中与 `RPLAN.24` 冲突的异常限制已被覆盖，不再作为本步阻塞。
  正常位宽、掩码及有符号取模语义仍须保留。

不得为异常擅自 `return 0`、拒绝范围、交换边界或 clamp；也不得以 C++ `% 0` 的
未定义行为声称复现了原端异常。旧阶段要求普通除零适配策略单独获批；
本步按“除零先不管”及 `RPLAN.24` 不实施故障映射，不承诺 UB 域故障或 RNG 副作用等价。

### 普通 int32 表达与顺序

1. 先判断 `upper == -1`；成立即返回 `0`，函数体不使用 lower，也不消费 RNG。
2. 否则先且仅调用一次 `NextRandom_53B4C9()`，将结果保存为 `std::int32_t random`。
3. 取数之后再计算 `std::int32_t divisor = upper - lower + 1`。
4. 以有符号 `random % divisor` 取余，加 lower 后返回完整 `std::int32_t`。

主线程本步决定使用普通 `int32` 算术，不添加专项 W32 回绕或 `bit_cast`。
负 divisor 原样保留；不交换上下界、不取 `abs`、不钳制、不新增输入前提、
默认成功、除零检查或其他异常保护。正常返回仍是上述数值结果，不是 bool。

### 正常域等价范围与未处理事实

对 signed32 upper，`upper == -1` 与原 `W32(U + 1) == 0` 等价；
该分支无需计算 lower 或区间宽度即可返回，RNG 消费为零。
非早退时，在逐步减法、加法均无 signed32 溢出且 divisor 非零的范围内，
普通 `upper - lower + 1` 与原 S32 除数相同，signed `%` 与原余数语义相同，
加 lower 后的返回值及一次 RNG 消费顺序相同；此结论包含负 divisor。

这里的正常域仅限定等价结论覆盖范围，不是新增调用前提，不假设上下界合法、
divisor 非零或所有 caller 正常，不缩窄接口输入域。
除零与 overflow 不处理；不承诺 C++ UB 域的确定结果、原故障位置、故障方式，
也不承诺该域的 RNG 副作用等价。原端“除零前已消费一次”的事实仍保留，
但不能据源码语句先后把它外推成 C++ UB 域保证。
