# 原大小写比较与坐标路径共享

## 1. 范围与裁决

2026-09-27，按用户工程决策委托，由本线程采用下述局部承接。
本节不把 `_strcmpi` 替换为现代 `_stricmp`，不外推四个已批准 std
入口的替换范围，也不宣称已复刻全部 locale、CRT 或邮件链。
证据来自现有 `ida-17524` 的只读指令和数据。

`CoordLoadInit@[45C040,45C146)` 调用 `_strcmpi@[53CF50,53CFDC)`，
后者根据 `1086160` 选择 C/非 C 两条路径。该槽除 CRT 读取外还有
[邮件末槽第 14 次写入](cg2d_network_runtime.md) 的跨界别名，不能根据
零初值或没有直接写 xref 删除非 C 分支。

采用 `platform::CompareInsensitive_53CF50` 窄入口；Win32 NLS 类型与
调用仅放在 `LegacyStringCompare.cpp`。只承接比较器可达的
`tolower@53DC64` 输入域及 `__crtLCMapStringA@543AE8` 的固定参数
`flags=100h,destinationSize=3,codePageArg=0,strict=1`，不公开不完整的
通用 tolower/LCMap 包装。所有分支均由真实状态/API 返回决定。

## 2. 唯一共享存储

- 新平台私有 `LegacyTextLocaleStorage` 承接原 `[1086160,10861A0)`：
  `+00` 为 W32 locale，`+10` 为 W32 转换代码页，`+38` 为 W32
  LCMap 后端选择，其余字节暂原样保留。大小 64B、原偏移与自然对齐
  用静态断言表达，字段都是已证数值，不含原生指针。
- 三槽位于既有 PE 零填充区；保持初值零。`LegacyTime.cpp` 原独立
  `gConversionCodePage_1086170` 改为同名引用，直接别名到该窗口
  `+10`，原时区转换调用和读取时点不变，不复制第二个代码页。
- 未来已证邮件写入必须让落入此区间的字节写入该对象表示；不能再建
  邮件私有副本或独立 locale/代码页槽。此为完整邮件窗口中的确定子区，
  **不是**整个 `[1085DA0,1086A20)` 或邮件 owner 已完成；区间之外的
  退出状态、原生指针、其他 CRT 状态及变长跨界仍按各自证据落实。
- 原 `58FC38` 的 257 项 U16 ctype 数据和 `58FC30→58FC3A` 指针
  分别唯一承接；指针用 `uint16_t*`，首项为 EOF 槽，指向下项后按
  字符索引。保留全表位型，不只造一个 ASCII 大写布尔表。
  `D68A7C` 的 ANSI 探测首字节另为共享可写字节，初值零；
  宽字符探测 `54FB60` 的两字节为零。未新增 locale 设置器。

## 3. 比较与字符转换

| 指令 | 行为 |
|---|---|
| `53CF5C–53CF66` | 入口读取同一 locale；为零走 C 路径，否则非 C |
| `53CF70–53CFA1` | 先读右字节、再读左字节；原字节相等时不折叠，遇 NUL 返回 0；不等时仅折叠 ASCII A..Z，按无符号字节返回 -1/1 |
| `53CFA3–53CFDB` | 右累积槽初值 FF、左槽初值 0；每轮只替换低 W8，原字节不等才先转换左、再转换右；比较结果只看低 W8 |
| `53CFAC–53CFAE` | 低 W8 为零时直接返回完整右槽，不把保留的高位一概清成零 |
| `53DC68–53DC8C` | tolower 自身重读 locale；为零时仅在完整整数为 A..Z 时加 32 |
| `53DC91–53DCC3` | 输入 >=256 时直接映射；否则必须 ctype mask 1 命中 |
| `53DCC5–53DCF0` | 根据输入高 W8 的 ctype 8000h 位选择一字节或高/低两字节源，按原位补终止字节 |
| `53DCF2–53DD2E` | 调真实 NLS 包装；失败返回原整数；返回长度为 1 取低字节，其余非零长度合并前两个输出字节 |

非 C 累积槽由初始 FF/0、低字节替换和 tolower 的 U8/U16 返回组成，
故本比较器传给 tolower 的值始终在 0..65535。对于进入分类的 0..255，
`__isctype@541955` 无论原多字节最大长度为何，均由
`54195C–541971` 直接读同一 U16 表并与 1；可合并该纯读取，不必为了
不可达的其他输入域引入 `_isctype` 的另一套 NLS 分支。

## 4. NLS 窄路径

`543B10–543B54` 后端槽为零时先以 locale=0、flags=100h、源长=1、
输出空/长=0 探测 `LCMapStringW`；成功才写 1。失败再探测 ANSI，
成功才写 2；两者失败返回 0，不锁定失败值。

之后按 `strncnt@[543D0C,543D37)` 将正输入长度收缩到首个 NUL。
后端=2 时直接 `LCMapStringA` 并透传返回；其他非 1 值返回 0。
后端=1 时才读取共享代码页，并保留调用序列：

1. `MultiByteToWideChar`，flags=9，空输出查询长度；零则失败。
2. 在当前栈帧申请所需 WCHAR 数，flags=1 真正转换；零则失败。
3. `LCMapStringW` 空输出查询映射长度；零则失败。
4. 在同一栈帧申请映射 WCHAR 数，再作实际 `LCMapStringW`；零则失败。
5. `WideCharToMultiByte`，flags=220h、原目的区长 3、默认字符和
   used-default 指针均空；透传长度（零同样表示失败）。

该固定 flags 不进入原 SORTKEY 分支，目的区始终非空、长 3。
原两个 alloca 区有捕获后返回零的路径，窄实现保留栈分配及该失败出口，
不另加堆分配、字符集猜测、Unicode 正规化或现代 `_stricmp` 回退。
API 的环境行为仍由 Windows 提供；不声称跨系统版本 NLS 数据相同。

## 5. CoordLoadInit 接线

唯一直接 caller `45791B–457925` 传入数据路径表、Info 路径表；
IDA 的参数/全局自动名称与实际用途相反，以 `45C085–45C08E` 向
已实现 CoordLoad 传参为准。原无已证返回值消费者，入口承接为 void。

- 入口先清九个坐标文件槽，不关闭旧槽。
- 每个槽只有当前文件为空才调用 CoordLoad；忽略其返回。
- 只有执行过该调用的槽才与后续槽比较数据路径，使用完整比较返回
  是否为零；不是只看 AL。
- 匹配时依次复制当前数据路径、当前 Info 路径（含 NUL），然后把
  当前实际 FILE* 写到后续槽。不能只共享句柄而忽略大小写规范化和
  Info 路径覆盖；也不把比较改成 Info 路径相等。
- CoordLoad 即使失败仍继续比较/复制。若发布的是空，后续槽轮到时
  仍会再次尝试加载；若非空，后续槽直接跳过整个加载/比较阶段。

本项保留原字节和现有文件身份，不新增句柄 owner 或关闭逻辑。
完整初始化父入口、邮件别名写入及运行加载仍未闭合；仅作静态检查，
不构建、测试、运行或使用 subAgent。
