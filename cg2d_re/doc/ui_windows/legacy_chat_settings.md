# 旧聊天设置页（旧选择编号5）

本页为585000旧面板，不是主窗口表window id 5。
复用[公共旧面板](shared_legacy_panels.md)类型与交互，
八个回调沿用[显示设置回调](../cg2d_display_settings.md)现有本体。

## 本步方案

在既有`LegacyUiRecord.cpp`中增加585000面板和D67E80的18条文字记录，
作为各自唯一可变owner；原文本/回调/提示三个指针使用原生类型。
保留原交错字段写入和未写+23H字节，不以整记录清零代替构造。
CRT5530AC接在5530A8旧设置菜单之后，完整4FD1A0同步落位；
不重写八个既有回调、不更改设置值与存档owner、不猜造上层分派。
属于局部实现，不触发总SPEC对齐或日志压缩。

## 完整父入口

4FD1A0共250条原指令，先503160(opened,面板,nullptr,1)：
0直接返回；2按520470、520590、角色S16读取、520510、520640、5206F0、
520200保存并透传返回。其他状态先5030A0(18条)，非零直接返回。

正常绘制使用128B局部缓冲，依次：

1. 55463C按553FB4的`%2d`格式化，现场重读Y/X，在X+62/Y+60绘字。
2. 554644非零选择58A668，否则58A664；拷贝后在现场X+62/Y+180绘字。
3. 554640按5531A4的`%d`格式化，再次重读Y/X，在X+62/Y+220绘字。
4. 取626AA0.field140低字节写第6行color，再503120(18条)。
5. 提示严格按关闭、行3、行4、行12、行15、行16优先查询；
   未命中不覆盖5030A0已有提示。最后503440(面板,1)，返回完整W32。

动态提示门槛按S32读取：行3的55463C<512，行4的55463C>0，
行12的554644非零，行15的554640<5，行16的554640>1。
不提前批量查询所有按钮，不复用绘字时的设置值快照。
父入口不重新构造文字几何，503160的初始化参数仍为空。
