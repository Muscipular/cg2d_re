## 创建入口495F00

实际代码495F00..495F4F，共26条指令。先查窗口33：
存在则标state8000，重读33窗口指针，先读x再y；
不存在则先读保存状态x再y。不清槽，不使用窗口原型的高度作为动画高度。

随后调用既有 `Sub_475950(x,y,184,159,33,flags,mode,completionSlot)`，
透传返回的非拥有 `YobiAction*`，不改用按主原型尺寸创建的475AA0。
当前已证唯一直接caller为47094A，三个实参均0；调用后仅返回点击消费1。

工程适配：前两参数按既有475950使用U32 flags/mode，第三参数采用
`YobiAction** completionSlot`，不是S32。此槽原样传入既有展开动画，
已有失败清空及完成清空语义不在本入口重复实现；不新增指针到W32转换或影子槽。
保留三参数，不因为唯一caller全零而删掉其他参数的透传。
