<a id="exception-runtime-decision"></a>
## 处置边界

26个入口登记为host，归FUNC-CRT；当前提供者是已安装MSVC编译器、VCRuntime及其Windows边界。项目CMake限定Windows／MSVC／x64，现有标准流、locale及其C++对象已沿MC01-C1使用真实MSVC对象。这是库职责承接，不是26份新CPP函数，也不声称旧机器ABI或原函数本体等价。

当前src/include未见这26个旧地址入口／名称的定义或调用；不添加固定成功、空包装、旧FS链、x86栈、FuncInfo、异常记录或自定义throw／catch对象。本轮不改现有CPP、头文件或构建配置。

保留[MC01-C3](cg2d_crt_host_migration_spec.md#msvc-crt-exit-source-state-20261010)的真实数组构造／析构／展开、5405F5筛选及终止消费；这些仍有业务callback、数量／步长、完成／剩余前缀和传播合同，不在本批退休。5402AB／5404FA／5407BC／5409E7此前C1处置保持，不重计。
