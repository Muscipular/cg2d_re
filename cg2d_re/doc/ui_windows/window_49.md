# 窗口49：群组选人

主原型54EC00，元素572F90共37项，主绑定4B4B00/4B4B90/4B4B70。
[窗口22](window_22.md)群发消费CC1A30计数、CC1A34模式、
CC1A38索引与CC1D58选择标志；本窗口补其真实名单生产。
本步范围为生产/排序、主回调、滚动换算及七行刷新；选择/翻页交互和37元素后续补齐。

## 工程边界

复用22已建WindowMailGroupSlotsCC1A30，不复制名单、选择标志或CC2078。
新增同一UI聚合内的D67B88滚动S32、CB0600排序类别S32和CC2E6C的200个S32索引。
三者均有原生产/消费，未加载区保持零存储，不将初值算作名单生产。
公会32个职级标志/文本借LegacyRecordOrder既有接口，普通60联系人、
公会200成员与比较叶均复用同源owner。

原qsort比较器相等仍可能返回-1，不满足std::sort契约；
抽取窗口21已核53C112/53C266四字节排序循环为同文件私有助手，
两入口仅传自身数组、项数和比较器。保留全部比较/交换/分区/30层指针栈次序，
不使用新排序算法、不扩大排序范围、不建立W32地址栈。
窗口21原初始化、类别计数及比较器不变，抽取前后循环逐字规范化核对。

六个原文本原型以同源WindowTextPrototype保存，供本窗口刷新和后续元素共同借用；
不复制成运行时翻译文本。4B4E20以及清理/名单/排序入口的原残留地址或寄存器返回
均不被已核caller消费，采用void；4B4DB0透传4742C0整数，4B4DF0返回写入的滚动位置。
主绘制保留传给4B4DF0的原S32参数，后者不使用。释放按已存在void主绑定。
