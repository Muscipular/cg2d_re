1. 仅SceneState.cpp既有共用helper两片段及ReadPlayerOptions194LowByte一片段。先以unsigned char读取同一PlayerRuntimeSlots::options194首字节，保原mask判断；清/置位仍只写同一U16字段、其它位保。同源低字节consumer也撤掉先读U16再截位，现有函数名称/返回/调用者保；只核471DF0实际BYTE读窗口，不外推完整父或其他调用者。不新接口、字段、helper、状态或owner。

4. 六正确请求主体、十二包装、原方向表、状态/共享计时、BVN父与另一UI父/声明/全部音频保持。组队入口选择只采一次、加入过时间门禁后bit100静默返回；交易两查询均执行，后状态不通过仍声51；家族权限实际BYTE按48B原行读取，不抹平差别。
