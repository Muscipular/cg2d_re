# 原窄字符串字节分配域宿主迁移 SPEC

> NSH01；2026-10-04依既有工程委托采用。[运行库边界](cg2d_crt_runtime_boundary_spec.md) §1批准按真实分配域成组承接；本组推进C08/C11，C06/C07异常提供者与完整CRT域仍开放。

<a id="narrow-string-heap-baseline"></a>
## 1. 原入口与实际闭包

[原证据](cg2d_narrow_string_heap_migration_evidence.json)保留53C9CF六条、53B4E7四条、53C3BE十六条、541A28十三条、53C3EA四十六条，共85条完整提供者指令；另54908A的两分配邻窗34条、548E29完整释放体24条，总143唯一指令。只用于本组边界，不重验其他字符串算法或推全部原调用已闭合。

原5490BE和5490D9都调用53C9CF；其原参数为U32，53C9CF固定enableHandler=1。53C3BE先按无符号比较拒绝大于FFFFFFE0，再尝试实际分配；失败调用541A28，传原请求，不传内部对齐量。处理器每轮重读108614C，空或返0结束，非零再尝试；异常向外传播。53C3EA私有模式1/2/3与16B对齐由D02允许宿主承接，零请求在系统堆分支先转1。

原548E4F只在共享标记U8为0/FF时把buffer-1实际块起点交53B4E7；其他值仅减引用，随后清buffer/length/capacity。这里的buffer[-1]是业务可见共享标记，必须保留，不能误认为待移除的私有堆块头。

现有LegacyNarrowString八叶及54A315共享赋值共九本体均通过本模块私有分配/释放入口持有字节块；增长按分配新块→复制有效正文→Tidy旧块→发布新buffer/容量/长度/NUL执行。逻辑capacity来自原请求算法，不查询HeapSize或块前缀。整串赋值共享同一buffer与引用；冻结、拆分和释放仍用同一域。对象本身的存储、异常对象基类text、locale facets、filebuf对象和六处裸字节适配不是本域，不能一并改成宿主释放。

## 2. 当前缺口

两个私有入口仍调用旧模式分配/释放，依赖未闭合的模式3拆分/合并核心。仅替换分配会使buffer-1宿主块进入旧Free与区域查找；仅替换释放会跨堆。原文本、共享生命周期和逻辑容量已有源码，不重写成std::string，也不引入新的块表或容量影子状态。

版本正文9A5C10、旧99表外层路由本轮仍缺事实：两个直接发送消费者与表内状态提供者存在，不证明正文容量/生产或旧handler调用点。它们不由本裁决补空正文、强转地址token或宣布不可达。

<a id="narrow-string-heap-decision"></a>
## 3. 本组实施决定

1. 在既有LegacyNarrowString.cpp内成对迁移两个私有字节入口，分配采用std::malloc，释放采用std::free；新增显式cstdlib，不新建分配器文件/公共接口或外部依赖。
2. 分配保留原U32拒绝上界及enableHandler=1对应的真实循环。宿主请求零时取1，其余直接传原byteCount；不复制私有16B对齐/模式。每轮失败仍调用现有CallLegacyHeapNewHandler_541A28，传原byteCount，非零重试、零返空、异常原样传播；不改处理器槽或增加宿主new-handler影子状态。
3. 释放接收同一私有入口产生的实际块起点；std::free处理空。九字符串本体、buffer[-1]标记、原空串背板、prefix/length/capacity、复制/发布/捕获次序与原异常消息提供者源码全部保持。不得把返回空转换成新异常或固定成功，也不增加null保护/回滚。
4. 原增长仍分配→复制→释放，不改用realloc；逻辑容量、trim/整串共享/引用减一/冻结行为保持，不读宿主可用容量或旧块头。私有内存布局/实际地址/物理容量/失败时机按已批准D02，数值与可见字节不放宽。
5. 不改变其他分配域、原堆/模式2/3证据、共享处理器、六处裸字节适配或已批准21应用calloc。旧私有入口在其他CRT域继续原合同，不能把本组写成整个C08已完成。
6. 在原共享53C9CF/53B4E7记录上只更新本域关联与当前合同；九既有字符串记录关联同一裁决。原身份、57/120入向总数和其他域关系保留，不把所有关联都标宿主迁移或原体等价。

<a id="narrow-string-heap-acceptance"></a>
## 4. 局部门禁

| 门禁 | 本组标准 |
|---|---|
| I | 两私有入口成对使用宿主分配/释放，保原上界、零请求及真实处理器循环；九字符串本体全文保持 |
| W | 两原分配点与一释放点仍指向同一私有入口；共享、增长与Tidy沿同一buffer，其他原堆域不混入 |
| S | 143原唯一指令和当前签名/调用可追踪；扣除两入口、cstdlib和头注释后同前提交全文一致；没有旧堆分配/释放/容量读取进入本字节域 |
| R | 禁构建/测试/运行；分配失败、实际异常传播、locale/filebuf/标准流完整生命周期与SDK运行仍未验 |

只归档NSH01限定I/W/S，不给完整功能门禁置pass。C08/C11继续open，原函数审核只覆盖两共享入口的具名当前域处置，不代表全部原caller或完整CRT迁移验收。


<a id="narrow-string-heap-source-closure"></a>
## 5. 本组源码收口

两个私有入口已成对改为std::malloc/std::free；分配保原U32上界、零请求宿主1、每轮失败调用同一541A28并传原byteCount，零返空/非零重试/处理器异常向外传播。源码只增cstdlib和这两入口，头仅纠正buffer当前分配域注释；九字符串本体、原空串背板、共享U8、逻辑容量、增长/复制/发布和捕获源码保持。

本域不再进入旧AllocateLegacyHeapWithHandler/FreeLegacyHeapMemory或HeapSize、模式3查找/块头读取，buffer[-1]仍是不可删除的共享标记。对象存储、异常基类文本/locale facets/filebuf对象等其他原堆域及六裸字节/21应用calloc未切换。保留原模式2/3代码和事实，不造三核心或宣称整个C08已完成。

两共享入口、九字符串叶、53C3BE责任关联与541A28新源级caller共13既有语义记录同步，1152条/1149有效ID、18pending/4分类引用保持。两个共享入口以本域限定adapted审核，已审73→75/3680；原全部57/120入向不由此收口。三条E-NARROW-STRING-HEAP-I/W/S-20261004限定证据使累计27→30，源码固定至Git命名快照cg2d-re-narrow-string-heap-source-20261004。

C08/C11保持open，源码关闭任务10/60、叶验收0/182及完整B/I/W/S未提升。其他域整组迁移、真实异常抛出/SDK、完整生命周期和R仍待；不构建/检查产物/新增或执行测试/运行/摘要，音频暂停及原格式明文网络保持。
