C821D8 CryptInt等于0、传入索引非负，再取tick并要求U32 D67D20+500严格小于tick。

`0,2,4,6,8,10,12,14,16,17`改为索引1，其余不改。

无骑乘时先读取action原+2A8图号。位于以下任一S32闭区间时保持索引，
否则同样将上述十索引改为1：
`186A0..18A87,19A28..1A130,1AF0E..1AF25,197D0..19848,1D524..1D553,1D55C..1D563`（十六进制）。
不能合并成一个区间，也不为索引新增上界保护。

发送后另查584B6C本地动作表、调用已有51A060，最后重新取tick发布D67D20。
