## 基线与实际缺口

45C5A0／F:0005C5A0完整161条544B、三页只读取证，20原调用为19直接／12目标和1个PostMessageA间接；31跳转／两RET，唯一World::Update 51C430@51C493。实际指令、字节及引用见[机器证据](cg2d_login_mode_normal_message_branch_evidence.json)。

现源状态3、4、100加一用uint32/bit_cast构造回绕模型，按RPLAN.24恢复普通S32。原状态3/4共享45C66F INC，状态100为45C75A INC；三个源表达式不能计作三个原指令或新F。

负返回分支在45C79B写状态100并复制原提示，45C7BB直接跳45C73C消息重置；原不经过45C733状态100检查。现源复制后再次检查共享状态，需恢复原分支。非负（包括关闭返回2）仍在45C733检查100，随后45C760独立检查101；两次实时取样不能合并。普通数值原已正确，不宣称观察到运行故障。

原根结束45C7C0即相邻输入初始化真入口，无待分类X；不创建填充或内部共享块函数身份。

<a id="login-mode-message-decision"></a>
## 实现裁决

只改src/LoginModeScene.cpp五个精确片段，一个既有业务体：

1. 状态3／4在调色板调用后、状态100在重置和声音调用后，继续读取当时共享状态，用普通S32 ++并写回。
2. 消息重置条件使用`result < 0 || world::gCurrentSceneState == 100`；负返回短路不再读状态100，直接重置。非负仍现场检查100；之后的101检查保原独立重读。
3. 删除三处位型算式后无用的bit include，不新增工具、状态或依赖。

保持入口状态一次样本、0..5分派／只入口2把mode置0、两能力探测和调用后能力取样／palette参数、一次输入控制器、返回1原空操作／两持久槽／保存／声音／palette及状态3早退，返回2投递关闭后仍检查消息；原29B提示与256B私有缓冲、100→101同帧贯穿和消息非零回状态1及其余整源保持。

负返回是原已有分支，不新增故障模型或异常处理。按RPLAN.24不增保护、拒绝、补零、钳制、限制或回绕模拟；保持失败／返回和真实字段宽度。公开void接口沿已有调用合同，不能据此声明机器ABI或全部caller完成。
