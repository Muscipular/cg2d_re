# Yobi动画播放模式与返回值枚举 SPEC（YAPN01）

2026-10-25。用户要求继续分析Yobi其他magic number；本步只命名动画播放的模式参数与返回值，按本线工程委托实施，不扩展播放逻辑。

## 范围与裁决

在既有公开头YobiRuntime.hpp的cg::yobi定义AnimationPlaybackMode与AnimationFrameResult，底层均为std::int32_t。字段、参数、局部变量及返回类型继续使用原整数，保留所有未知值。仅替换src/Yobi内已证参数位置、同源模式生产及直接／有界局部结果比较；公开头与内部声明补充用途说明。

| 域 | 数值 | 成员 | 已证含义与边界 |
|---|---:|---|---|
| 模式 | 0 | AnimationPlayback_Loop | 到达末尾后清帧下标并增加循环数。 |
| 模式 | 1 | AnimationPlayback_StopAtEnd | 仅严格等于1时停播，写remain=255和completedLoops=1并返回1；不能改成非零判断。 |
| 模式 | 3 | AnimationPlayback_LoopMode3 | 当前DrawMapMainGear406的Field／Shield挂件传入3；播放函数按非1值循环。保留编号，不推测额外业务语义。 |
| 结果 | -1 | AnimationFrameResult_ResourceFailure | 动作装载失败；当前共享帧应用的资源属性发布失败也沿用此结果。 |
| 结果 | 0 | AnimationFrameResult_Continue | 未给出停播／不可用结果；包括取帧、等待、隐藏、空对象、无图及静图路径，不代表一定播放了新帧。 |
| 结果 | 1 | AnimationFrameResult_StoppedOrUnavailable | 停播终点，或动画上界／索引／动作缺失；不将其统一视为成功完成。 |

两种模式0／1的同值不能与返回值混用。保留playRevert完整S32发布，不能改成bool或枚举字段；模式3的生产来自当前已采用的4.06挂件接线，不声称是cg2d原生产分支。

## 原端证据

- 继续使用当前已打开的cg2d.exe数据库，只读核对517880与517DA0。原0x5178A2／0x5178AC及0x517DC2／0x517DCC将停播参数完整发布到+2E0。
- 原0x517A35将EAX置1，0x517A57比较第三参数与EAX，非等进入0x517A75回绕；等于时0x517A5D写+2C4=255，0x517A67写+2DC=1并返回1。另一入口在0x518041置EAX=1、0x518063比较，0x518069／0x518073完成同样发布，非等进入0x518081。
- 原0x517F6E在图号上界失败时返回1；0x517F8F及0x517985在索引负值时返回1；0x5179C7在动作数零时返回1；0x518013在动作／方向选择失败时返回1。因此成员名称同时保留Stopped与Unavailable。
- 原0x517990／0x517F9A调用AnimeLoadAction，结果零在0x51799F／0x517FA9返回-1。当前ApplyYobiAnimeFrame的SetGraphicAnimeActionFlags失败也映射-1，只命名既有结果，不新增失败或保护。
- 原0x517916／0x517920及0x517E36／0x517E40在remain等待路径递减后返回0。其余0结果沿既有[YFPS01](cg2d_yobi_frame_playback_sampling_spec.md)与当前源码，不重复取证已通过且未改的全部根。
- 原0x4065F3直接比较PlayFrame返回1；该函数本身的0／1表示是否找到攻击帧事件，属于另一结果域，不能连带替换。

保留播放速率、flipStatic及低BYTE判断、syncSource、frameIndex／remain／completedLoops、资源匹配与装载调用、事件10000／20000门槛、缓存-1、其他函数的返回值、绘制位及场景阶段。模式局部生产只覆盖stopAtEnd、已证ResolveGearPetAnimationState输出及其revert调用变量；资源ActionEntry::revert是绘制属性，排除。
