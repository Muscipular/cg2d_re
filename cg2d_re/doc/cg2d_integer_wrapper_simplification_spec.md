# 整数转换短包装整理 SPEC（IWC01）

按用户要求消除 `LowSignedByte` 及同类纯整数转换包装，沿此前“做完 SPEC 后执行”的授权实施。现有目标均启用 C++20，整数转换可直接保留目标位宽的低位及对应有符号值。

1. 移除 18 个仅处理整数截断／符号解释的帮助函数：Yobi 的 `LowSignedByte`；输入／渲染中的 `SignedByte`、`LowS8`、`LowS16`、`LowU16`、`IncrementModeW8`；登录中的 `LowW16`／`Low16`；选人中的 `LowInt16`、`CreationSignedByte` 和两份 `UnsignedBits`；主循环中的 `SignedLowWord`。同时删除 Yobi 的私有跨组声明。
2. 在调用处直接使用 `static_cast<std::int8_t>`／`std::int16_t`／相应无符号目标类型，保每个参数仅求值一次。原递增模式先加一、再取低 S8，仍以同样的无符号加法表达。
3. `x & 0xFF` 表达无符号低字节，不能单独替代 S8 符号扩展；有符号目标直接窄化后，由原接收位置扩展。格式化模板的三个调用显式扩展到原 S32 类型，避免改变参数类型。两个“低 S8 再解释为 U8”的队列写入直接转 U8。
4. 不按函数长度删除平台／资源／对象访问接口；专门的单字节存储读取保原读取宽度，浮点截断和有数值合同的算术帮助不扩展。仅清理因此失效的标准头及空匿名命名空间，不增加宏、全局类型、依赖或业务逻辑。

限定 14 个源／头文件。核完整差异、旧符号零残留、类型／取样顺序、UTF-8 无 BOM／LF 后精确提交，同步两份进度。仅静态检查，不构建、测试、运行或计算摘要，不生成／更新 JSON 台账及派生定位。

IWC01 完成：通过 apply_patch 删除 18 个包装定义及一处跨组声明，143 处调用直接使用目标整数转换；保留三个格式化参数的 S32 类型。两个队列 U8 写入及五处快照重复截断合并，五份不再使用的 bit 头和一个空匿名命名空间删除。14 份源码与限定迁移稿全文一致，原整数操作数、调用及读取顺序保持，旧符号和编码／差异静态检查通过；未编译、测试或运行，不生成 JSON 台账。
