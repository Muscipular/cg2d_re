## 本次缺口与原范围

[MFA01](cg2d_map_effect_arithmetic_spec.md)已修46F1D0固定点。相邻五处像素运动及46F000投影增量仍使用U32加减后按S32消费，承载整数回绕。[场景合同](cg2d_scene_state.md)的方向修正和边界检查已有正常S32，本步沿同一真实记录链恢复前置坐标算术，不改字段存储或计时/RNG业务。

[原证据](cg2d_map_coordinate_arithmetic_evidence.json)保存六体908条2948B及六直接call/三父身份：

| 原根 | 条数/字节 | 本次坐标块 |
|---|---|---|
| 46E4E0 | 141/473B | kind1像素X/Y |
| 46E6C0 | 198/632B | kind2像素X/Y，Y位置读在X写前、Y速度读在X写后 |
| 46E940 | 196/615B | 多轮kind2像素X/Y |
| 46EBB0 | 126/406B | 多轮kind1像素X/Y |

前五根+00/+04坐标、+08/+0C速度按原W32读取/相加并写回，随后方向修正及边界用signed比较；46ED50的X速度生产原写FFFFFFFF即−1，不能把它当正大整数语义。46F000旧/新投影均S32；原46F055..46F076按X差→X累计→Y差→Y累计，46F078/46F07F再发布两个新快照。

<a id="map-coordinate-arithmetic-decision"></a>
## 工程裁决与实际源码

1. 五处像素运动读取真实W32后解释S32，按正常S32相加，写回W32位型。46ED50保(randomX−1)/(randomY−1)原分组、X随机→X读写→Y随机→Y读写；remaining门槛/计时不改；重设尾先取得新Y速度RNG结果，再写remaining=4，最后写+2C新Y速度，恢复46EFAF→46EFB2原顺序。
2. 46E6C0保持其独有顺序：先读X速度/X/Y，写X后再读Y速度/写Y。其他四块按现有各自原读取点和X→Y写序，不合并快照、加共享算术工具或重排。
3. 46F000的deltaX/currentX−旧X及deltaY/currentY−旧Y改正常S32，*x/*y原位累计；旧X为−1时仍不访问两输出指针，发布两新快照并返回新Y。两次F32→F64+0.5→S64→低W32/S32真实窄化保持，不把位型截断当回绕工具删除。
4. 仅SceneState.cpp六种文本片段、七实际局部块（六坐标块/一重设尾）；共享片段在46E940/46EBB0各一次。原所有位型/低W16编码、unsigned时钟/期限、计数门槛、生成/循环、方向修正/条件写、失败/回收、返回、RNG与相位均不改；仅上述重设尾恢复原计数/速度写序。
5. 六根各补唯一语义/来源和x64场景承载adapted，仅本次正常坐标局部，不重验六个完整父或全部908条业务。数学溢出/越界不保护/拒绝/钳制/补零/回绕或故障模拟，正常字段宽度不扩为S64。
6. 无新接口/依赖/owner，不触及专用x87/通用pow/网络格式/音频；MFA01正常固定点与ATP01载荷合同保持。
