# 大地图界面迁移（BMUI01）

2026-10-19，用户已明确“实施spec”，开始执行BMUI01。目标是当前地图完整查看界面；仅迁移4.06的UI处理，使用当前项目的数据与渲染；小地图左上角按钮为唯一入口，不增加快捷键；七类地点筛选及标注数据接入包含在范围内。mapdesc.txt不内嵌，统一放游戏data目录读取；外部数据文件已按该要求准备。

## 界面与行为

1. 在现有小地图左上角加入“大地图”按钮，不遮挡右侧关闭按钮与坐标。只允许该按钮创建/聚焦大地图；不增加键盘入口、全局菜单入口或脚本公开入口。
2. 大地图使用当前逻辑画布内的大视口，采用本项目窗口、文字、图元和SDL队列。保留4.06的地图主体、左侧可收起选项栏、人物坐标、目标坐标及关闭按钮布局，不依赖4.06的D3D界面资源。
3. 打开时以玩家为中心；左键拖动平移地图，拖动后解除居中跟随；“玩家居中”恢复跟随。右键选定有效地图坐标，显示目标标记；“开始寻路”调用现有Copilot，不能点击穿透到场景移动。4.06的Ctrl组合键及快捷键文字均不迁入。
4. 显示鼠标指向的地图坐标、玩家标记、目标标记及现有寻路路线；仅消费当前项目已有数据/寻路结果，不迁移4.06寻路算法或网络处理。
5. 七类复选框独立控制显示：0小的地点或居所、1伐木地点、2挖掘地点、3狩猎地点、4村镇大地点、5宠物Lv1坐标、6特定NPC。“刷新坐标”重新加载标注文件，重建当前地图标记。
6. 沿当前窗口焦点、裁剪和关闭生命周期；离开普通地图场景关闭大地图，换图时重置视口/目标并读取对应标注，避免旧地图坐标继续使用。

## 数据与渲染边界

- 地图底图复用现有UIMapExControl的地图文件、可见区同步、分块像素图及DrawPixelImage队列，不迁移4.06的D3D9/D3DX缩略纹理生成、MBM/bin持久化或截图式底图。未知区域与可见性沿当前地图数据，不扩大获取范围。
- 扩展窗口沿UIWindowInstanceEx与现有窗口调度，采用C++接线；不要求用户安装Lua脚本，不增加依赖，不扩大原71个原生窗口的存档布局。
- MapEx仅增加本项需要的地图/屏幕坐标换算、标注绘制与可见性查询接口；现有Lua控件默认行为保持。地图、文字、图标与标记共同裁剪在视口内。
- 标注唯一来源为游戏目录下的`data/mapdesc.txt`，沿当前游戏工作目录资源约定解析；TAB分隔，`#`为注释。外部旧格式中文按GBK边界解码；项目源码、文档保持UTF-8。不猜测地图点或分类。
- 按用户最新裁决，不把标注写入CPP数组、RC资源或可执行文件；不保留内嵌回退，不在运行时从旧客户端EXE提取。缺文件时显示标注缺失状态，基础地图仍使用已有数据；“刷新坐标”只重读外部文件。mappoint.dat与mapdesc.txt保持各自独立用途，不自动混入七类标注。
