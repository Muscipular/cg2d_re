# 整数转换短包装整理 SPEC（IWC01）

按用户要求消除 `LowSignedByte` 及同类纯整数转换包装，沿此前“做完 SPEC 后执行”的授权实施。现有目标均启用 C++20，整数转换可直接保留目标位宽的低位及对应有符号值。

2. 在调用处直接使用 `static_cast<std::int8_t>`／`std::int16_t`／相应无符号目标类型，保每个参数仅求值一次。原递增模式先加一、再取低 S8，仍以同样的无符号加法表达。
