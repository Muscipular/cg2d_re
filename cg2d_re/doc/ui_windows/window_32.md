# 窗口32运行期明细

## 原型与范围

沿[战斗场景入场依赖](shared_battle.md#scene-entry-helpers)取证43C950和49BD40。
原型54E840：type2、category3、坐标224/162、尺寸192/96、flags80010101、两元素，
更新49BD40、绘制49BDB0、释放4A4210。后两入口复用既有完整实现，不重新定义。
本窗口只有两条互斥文本，无新增按钮或交互业务；不猜原文本编码。

## 49BD40更新合同

原区间[49BD40,49BDAB)，适配既有WindowCallback保留未使用S32参数。
先固定gCurrentWindow，再清5ABFB8非拥有动画引用，然后清固定窗口首元素visible；
重取gCurrentWindow清第二元素visible。场景状态完整S32不为3时标当前窗口8000关闭，
但继续读玩家低U8：bit1优先显示首文本，否则bit2显示次文本，否则再次标关闭。
各次元素/状态操作按原点重取窗口，始终返回1，不因为场景不为3而提前返回。
开窗43C950在475AA0返回后写5ABFB8，失败也播放SE56；父场景后续MarkDeath并清槽。
