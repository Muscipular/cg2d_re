## 常规对话回复与字节校验 SPEC（2026-09-28）

本步沿49D2E0真实依赖实现49DA30及476740/45E770，不先接部分父路由。

49DFF5/49E6E1等生产第四槽。数值仍S32，文本参数为借用char* const*，
输入数仅U8。CB1398行表留待文本生产步核容量，不以影子文本补齐。

49DA30@[49DA30,49DDA9)分支及顺序：

- button0/row负只清581800=-1返回1；row非负走独立的行回复尾。
- button非零/type2格式化负CB1394，再52D2D0至发送缓冲。
- 普通类型仅inputCount低字节==1时读取texts[0]，否则读取同源593850文本。
- type35仅button最低位置位时依次校验：两行不可同时空、476740第一行/第二行、
  45E770第一行/第二行；前两项返回0或后两项返回1立即失败且不发送、不清状态。
  校验通过或按钮最低位未置，依次复制两文本至各256B区，分别原位52D2D0，
  用原格式`%s|%s`拼入第三256B区，再52D1B0至回复区。
- 发送前按目标CB1390→请求CB138C→玩家Y→X→socket采值，调用512620，
  清581800，再SE79→SE57；随后仍判断row，非负时另发一条，不改成互斥回复。
- 行回复尾格式化row+1并52D2D0，重新采目标/请求/Y/X/socket，
  以button0发送，清581800并SE79，返回1。

476740@[476740,4767D4)两遍扫描，长度各重新计算一次，均用44B250的
高位规则（80..FF步长2，其余步长1）。首遍拒绝单字节逗号/竖线/反斜杠；
第二遍要求至少有一个不是20H或双字节8140H的单元，空串返回0。

只检查单字节竖线/反斜杠，命中返回1，空串或未命中返回0；
尾字节NUL仍立即结束，不校验完整编码。两入口收敛既有Input模块，
不共用一套近似“合法文本”规则、不转Unicode、不调用系统字符分类。
