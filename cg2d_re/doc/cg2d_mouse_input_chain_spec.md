<a id="mouse-input-chain-decision"></a>
## 基线与登记裁决

1. **命中与RNG读取**：472F00先调用401E60读取mouseX并减left；x<0或x>=width立即返0，不读取Y。
   只有X通过才读取mouseY并减top；0<=y<height返1，否则返0。几何参数/返回保持S32，不额外钳制或预读。
2. **阶段生产**：473E40进入阶段2时清阶段后返回；进入阶段1且callback为空，只写focus=1和D68DB4低W8=5。
   callback存在时按edge→held→pulse取W8标志，再调用(0,events,sourceIndex)并重读阶段。
   回调后阶段3置4并发布focus/低字节5；阶段4可选调用(2,0,sourceIndex)，之后按原序清同源槽。
   清理宽度为W32标量/本机非拥有函数指针、两个S16坐标、W32焦点/阶段，元素索引最后置-1；不建立私有副本。
   阶段6清阶段；阶段1发布focus/低字节5。**回调后变为2不走入口阶段2的清理**，保留原分支位置。
3. **元素消费**：473560保存入口窗口的元素引用和矩形。阶段1/4/2/6先检低U8<212，再命中并重读阶段；
   同一焦点窗口/共享元素索引才追加按钮事件。其他阶段仅无焦点时命中，初始events=1，type4才按X→Y读取/存两个S32相对坐标。
   阶段4以S16拖动坐标和保存的矩形判断追加0x40；后续仍使用入口保存的element，严格visible==1才调用mouseCallback(index,events)。
   返回非零后重读阶段、写D68DB4低W8=212/focus=1，阶段4可选拖动(4,0,sourceIndex)后重置。
4. **按钮映射**：edge的1/2/0x10/0x20分别追加0x02/0x04/0x100/0x200；held的1/2追加0x08/0x10；pulse的1/2追加0x400/0x800。
   共享helper只是源码复用，不为原内联片段制造函数ID，不改变W8取样或回调前消费顺序。

新增三语义/三adapted源码处置、一限定S证据和公共窗口已知成员/合同。现有唯一定义、原数据/回调借用和真实473F80调用保持。
两void入口仅描述当前已证caller弃返回的源码适配，不宣称原EAX固定为0或已证明所有间接调用/本机ABI等价。
