# 技能与宠物技能预览类型边界修复SPEC（BVZ01）

<a id="skill-preview-baseline"></a>
## 具体问题与原合同

六个旧页面直接访问公开头中仅前置声明的YobiAction::flags，越过类型边界；判空和清位又分别读取共享槽。原端均为一次指针取样、同样本判空后AND W32 flags与~2。现有SetYobiActionFlag2已在原生实现内部承接此字段，直接复用即可解决两项差异。

<a id="skill-preview-decision"></a>
## 实施决定

每个父仅替换一个片段：先保存非拥有YobiAction* const previewAction，再按原判空，以同指针调用既有SetYobiActionFlag2(false)。原生helper/公开头保持；不公开对象布局、不新增helper、接口、owner或保护，不合并不同预览槽。

同一技能预览槽由前三页原样共享，后三页各用既有独立槽。初始化、关闭MarkDeath/清槽、文件与格式、技能/宠物数据生产、请求及网络原格式明文保持。只修六个已证阶段，不借本步补造旧99表分派或商店模式；音频暂停及RPLAN.24保持。
