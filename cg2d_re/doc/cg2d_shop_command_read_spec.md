# 旧商店命令原宽度读取边界SPEC（BWT01）

<a id="shop-command-read-baseline"></a>
## 缺口与原端基线

SCP01已保存4D8DA0完整321条1080B和三个命令的原写入/消费合同。当前CPP在row<=1命中后直接把commands[row]求值为%d参数；原低两位全零只写命令0的3，仍扫描两行，命令1没有生产，不能让C++直接读取未初始化整数来承担原MOV EAX,[EDI]。

本轮原会话只核4D8ED5..4D8F6D的完整命令分支/扫描/读值至格式调用窗口，复用全根原证。原4D8EF0/4D8F09/4D8F23分别条件写1/2及末尾写3；4D8F56/59保row<=1门槛，4D8F5B两字节8B07实际读取一个W32，经原PUSH EAX/%d/53B304消费。该槽是数值，不是可扩宽地址。

C9A94C真实生产、未写第二命令的原实际值及旧外层路由仍未证。修复新端语言求值问题不能填0/2/3、拒绝输入、删第二行、造原栈字节/地址或宣原值及故障等价。

<a id="shop-command-read-decision"></a>
## 实施决定

- 依工程委托修复已知源码问题，在既有LegacyFloatEnvironment.asm中追加一个私有纯W32读取叶，在既有LegacyFormat.hpp声明固定S32返回/const S32*借址，不新增文件、CMake、依赖、共享owner或原函数身份。
- Cg2dReadLegacyShopCommandW32只执行MOV EAX,DWORD PTR[RCX];RET。RCX借本次命令元素的原生地址，返回实际读到的W32；不读额外字节、判空、补值、改写存储、保存虚拟x86栈或调用宿主算法。
- 原三个S32命令槽及全部写规则保持，CPP只把&commands[row]传给真实ASM叶，再把其S32返回值交既有FormatLegacyString_53B304。取地址不读取未生产的C++整数；数值从真实原生读取叶返回后消费。不生成/预填未生产第二命令，也不声称其值已获得原证。
- 仅替换该格式参数一处直接求值；已确定生产的commands[0]提示读取、mode==3的三行/其它两行、所有命中/写入/文字/后续发送次序及原格式明文保持。读取叶没有外调和寄存器保存/全局状态，不扩大父业务或恢复音频。
- 普通原生局部命令存储不承载旧栈地址模型；只保持原条件写及实际四字节读机制。此边界解决源码的C++未初始化整数直接求值，不代原未写值、真实模式、机器ABI/链接/运行或故障等价。
- 更新既有1226、mixed处置和pending6当前事实；不新增语义/F/原成员，不关闭P07或UI-L-062。该页两限定I/S与P07/U04/U05/V04/R04同步，其他完整门禁保持。
