## 完整校验与材料生产

4F4470先取D67AD8(S8)→配对index(S16)→skillId快照，之后：

1. 按20槽外层/20槽内层顺序拒绝两个不同已标记槽拥有相同itemId，返回2。
   不检查used，不合并同类堆叠。
2. 除215/216外，扫描标记槽并以4F4430(itemType,真实skillId)判断特殊材料；
   遇第二个返回2。
3. 读取5846BC快照。逐个标记槽，215/216直接查五材料；
   其他先分类，**每次分类调用后重读配方号**，特殊类跳过材料成员检查。
   非特殊槽必须匹配五材料itemId；遇负itemId立即返回2，不跨空项继续找。
4. 用最终配方快照遍历五种需求。非负itemId各自扫描20背包槽，
   每次先读count，仅count==0视作1，然后查标记、itemId和count>=需求。
   首满足即继续下一材料，找不到返回1；不累加数量、不将负数量钳为1。
   全部满足返回4，包括五种需求全空。没有返回3或0的隐含补分支。

4F4690按20个选择标记生产数组，不检查used或重新校验。
分类故意调用4F4430(itemType,0)，不是上面校验的真实技能号。
特殊类直接写六槽的第5项：先图号、4F4630(itemId)、数量、来源槽；
普通类按普通计数写同样三字段，再递增普通计数。普通数达6立即结束；
特殊不递增，也不保护第5项免于随后普通材料覆盖。
CF4008/D66E20/CA0AA4正是各既有六槽第5项，不能建三个独立标量。
唯一直接caller4F49FF不消费返回；新端void，不伪造原残留EAX/AL。

4F4720数20个非零标记，4F4740清同一20B并返回0。
4F4760依序调用清标记、阶段0、详情页0、上次悬停-1、拖动槽-1、图号0，
返回0；不清六材料数组。

1. 已拖动且点击低字节bit02：取消拖动/图号，直接绘制，不翻页也不播放SE。

   即使已满6而未选中也清拖动，不重新计数或下落按钮处理。

6. 其余路径只有悬停有效时处理拖放，并重新采拖动槽和鼠标低字节。
   已拖动且bit1：不同目标才510EC0(socket,source+8,target+8,0)，
   发送后重取拖动槽清两端标记；同槽不发送/不清标记。两路都清拖动、SE51。
