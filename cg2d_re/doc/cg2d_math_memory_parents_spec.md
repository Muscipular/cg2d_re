# 原八个内存除法加载父与两个共享区间SPEC（BWQ01）

<a id="math-memory-parents-baseline"></a>
## 原端基线与缺口

已补545916/545929正逆向T80包装及完整545360核心。本轮沿它们的真实原调用，完整开发54593C..545B3C八个内存加载父：F32/F64/S16/S32各正向和逆向。全172条512B、16CALL/两个callee、12跳/20RET；两个未分类R7与原545A65函数身份互补，不只实现内部分支来缩减缺口。

原545A65九条27B是逆向F32加载父中TOP=0路径的一段，上游545A63的FXCH顺流进入，后面POP EAX/RET4回其原调用方；不能虚构为独立未决业务。X:0014593C-00145A65与X:00145A80-00145B3C合163条485B，前后所有代码与该函数合连续172条512B，无对齐填充。

浮点F32/F64父先读原值的指数位（7F800000H/7FF00000H），全一时按原FDIV/FDIVR直接内存运算；其它路径FNSTSW AX、AND EAX,3800H取实际TOP，非零直接加载原标量后调用对应545916/545929。TOP=0时先FXCH/FSTP额外T80、再加载/真实调用、重载/FXCH及释放临时区。整数父没有浮点指数位分支，S16/S32以原FILD分别读2B/4B。

八父均按原PUSH/POP EAX恢复完整W32，不默认填T80/输入。原S16占四字节调用槽但FILD只读低两字节，RET4/RET8是旧值参数调用边界，不是数值扩大；顶标志不是栈标签完整性检查，不得新增空栈/溢出保护。

<a id="math-memory-parents-decision"></a>
## 实施决定

- 沿LegacyFloatEnvironment.asm/.hpp两现源三处追加：八导出/完整本体和私有合同；零CPP/C桥/新owner、文件、CMake或依赖。
- 八真实ASM提供对应四标量类型的正/逆入口，ST0输入/结果保持；RCX只借该原值参数的对应位宽只读内存。借址是Win64值传送边界，不扩大原数值字段、不解释原未消费的S16槽高W16、不模拟旧栈地址/RET4或RET8。
- 每父用72B正常Win64帧：32B影子区、+32实际T80十字节、+44原W32 EAX、+48原生借用值地址；不填T80尾/padding或新增全局暂存。原值地址不持有/改写，结果连续留ST0，不包装CPP double ABI。
- 保原指数位读取位置/F32-F64位掩码及直接FDIV/FDIVR分支，FNSTSW非等待读取与3800H判断、原FLD/FILD位宽/符号和16次真实包装调用，不借宿主除法或其它等待式状态API。
- TOP=0路径保持原FXCH、实际T80落存/重载、标量加载及交换顺序；临时空间在正常原生帧内承载。非临时退出用LEA释放，临时路径仍原ADD释放机制；不宣原x86栈地址算术标志、机器展开或故障等价。
- 原545A65分块置于逆向F32完整父的真实内部标签，七个相邻未列函数的代码通过两个R7 mapped纳管；仅新增一个原F，不造八个原函数身份、不排除未见直接入口的代码。
- 两个区间逐字节为真实加载父/分支，按shared_memory_division_parents分类mapped。整个R7分类仍未闭，继续外层原调用/描述符生产和其它CRT/全应用生命周期。
- RPLAN.24、原格式明文、音频暂停及禁止执行限制保持；原已有指数/状态分支照原实现，不新增输入拒绝、保护、钳制、默认结果或故障/回绕样例。
