## 2. 数据与接线

- 原文本池62ECB8、尾槽62ECA0、计数73ECB8、fontLayer558F50及当前context槽626C04按实际operand确认；共享结构/容量、现有token接口与初始化/退出owner不改。记录x/y、模式/颜色/字体及value7按原写；next在裁宽后写0，marker/field108不写。
- 多行context始终原参数，不改成当前全局重取；每段源是该轮context+lineStart，复制/分类/绘制之后该context内字段按原点重读。原maxLine不限制实际绘制段数，仅决定光标边界所属。
- 单行初始记录使用入口计数，裁宽成功/超宽两分支重读计数；非空尾先连接旧尾再读计数/模式，末尾对当前共享计数加一。空尾先更新尾槽再QueueText，返回弃用，不增回滚。
- 三测宽全部真实调用现有Font::measure；该叶仅原非正预算返回0，没有字体范围拒绝。原字节/度量与队列消费者本步不改。

## 3. 决定与实施

1. 删除仅供新增拒绝的三个常量及IsInputOffset/IsPendingIndex/CanMeasureInputText，保现有AddW32/SubW32/LowS16/LowS8。只在同文件以ReadRenderMode读取四字节模式，供三原W32取样点；低W8绘制/记录直接取field138[0]。
2. 多行撤销固定NUL/长度及预清和全部额外写界限/零推进拒绝；恢复逐字节预算、复制前预算/复制后NUL预算/分类后推进预算三阶段。绘制参数依原点保存当前值，之后真实DrawText2，原返回弃用/Y增量/所属行保持。
3. 单行先写原记录字段；星号每步重读total/visible，普通文本先扫描、含NUL低U32、逐四字节读/写再余字节，使用memcpy只承接已知4B标量读写，不整段改变alias/顺序。
4. 裁宽先读field154门禁再扫描记录、S32预算；测宽返回后重新读field154，超宽重新读源+158、分类/减量与计数重读。保原可能完全不截断和逐字节切开DBCS的行为。
5. 单行尾模式/层模式/非空续尾模式各按原点读取完整W32，计数与现有token/链连序保持。两锚点真实测宽，负差回写后再取font及实际visible源，X/Y所需字段按原顺序先取再写。
6. 绘制根已有语义更新、字符串核心仅本组当前说明更新；不新增或重复函数映射。根限定equivalent，局部I/W/S各一；完整INPUT/TEXT、T01/T02和闭包不提升。未构建/查产物/新增或执行测试/运行/摘要，单线程、音频暂停及网络原格式明文保持。
