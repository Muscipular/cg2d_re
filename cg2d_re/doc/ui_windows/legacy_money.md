# 旧选择编号15：金钱页

本页是旧表选择15，由[旧14物品页](legacy_inventory.md)金钱按钮发起打开，
不是现代窗口15。共用数字键见[旧16数量页](legacy_item_split.md#共用数字键502b80)。

## 本轮 SPEC 与承载

原已打开cg2d会话只读核4FBB30..4FBB3B的2条、
4FBB40..4FC41A的561条原指令，共563条。
584DA8面板196B原值为x440/y0、200×200、选择15、背景22930，其余零。
D2D618为S32金额草稿，xref只见本页与4FBB30；面板和草稿均由
LegacyUiRecord私有持有，初值0。玩家金额FDA7FC、坐标、输入焦点、
网络/按钮/数字键依赖复用已有owner，不新增现代窗口状态。

4FBB30只有D2D618=0且不改EAX，使用void初始化回调；
父页关闭时先保存焦点比较/恢复留下的完整返回，再重置草稿并透传，
不能以“重置写0”误认为原返回也为0。

## 完整交互

正常帧先SetContext(nullptr)。先读草稿，非零才查询确认按钮bit1，
确认成立后**重读草稿**，再依次读取玩家Y、X，发送510DA0(socket,x,y,amount)，
发送后草稿清零；不打开14、不播放SE、不提前退出。
草稿为0时不查询确认点击，也没有旧16的SE55拒绝路径。

否则顺序为返回、全部、清零、退格、数字0..9首命中：
返回只打开14；全部现读FDA7FC，清零写0，退格S32除10，
数字写旧草稿×10+键值。除返回外上述实际编辑点击才SE51；
未命中不播放。全部/退格/数字不增加额外范围保护。

所有正常分支均继续502B80(&draft,7)，随后先读取玩家金额，再读草稿，
仅当玩家金额<草稿时改为该金额，**不播放错误音效**。
此金额快照直接用于第一行%7d，不像旧16重新读取来源物品count。
第二行独立读草稿；两行文字坐标为面板+(88,46)/(88,86)，
文字层2/font1、最终W16坐标。发送/返回请求不跳过这些共同尾。

## 绘制与提示

先画数字0..9，再重读草稿选择确认图，依次绘确认/返回/退格/全部/清零。
所有按钮层218/style0，不套用旧16的212；每次独立读取悬停颜色。
关闭提示55331C，不是旧16的553FD0。

提示依序为关闭、确认（非零585B54/零585B44）、返回589CA4、
全部585B28、清零585B14、退格585B34，最后数字首命中。
数字提示处先取草稿再现读玩家金额，小于用585B6C，否则58A3B4；
不复用之前上限/显示快照。六段专有提示按原字节保留，
返回和退格复用同地址既有常量，无命中不改提示。
最后503440(panel,1)透传完整W32。
