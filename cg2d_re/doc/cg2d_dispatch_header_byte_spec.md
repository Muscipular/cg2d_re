# 网络分派头逐字节比较SPEC（BWU01）

<a id="dispatch-header-byte-baseline"></a>
## 原端基线与缺口

原512E40的108条命令比较仍由新端TryDispatchReply共享模板中的宿主strcmp承接。既有参数读序/工作区合同已落位，本步只补头比较的原字节读取、条件和循环；不重做分派、协议或已过参数链。

当前cg2d原会话按108条比较块集中取证，共2593条6307B及108个含NUL原标记共433B；107块24条、一块iKe25条，多出的MOV EBP取原fd后才TEST比较结果。原函数库存5779条/512E40..516B5D仅作边界，本步不宣全根5779条或全部callee已验。

每块先取头U8、再取命令U8，比较不符进入下条；相符才用同一头样本判NUL。非NUL继续取第二对U8/比较，随后两地址各加2，再以第二头样本判NUL，非零回首对。原XOR/SBB结果仅由后续TEST EAX,EAX的相等/不等分派消费，不能以宿主字符串实现证明读取宽度/顺序。

<a id="dispatch-header-byte-decision"></a>
## 实施决定

- 依工程委托先记SPEC，在既有TryDispatchReply正文只替换strcmp条件一个片段，内联原两字节一轮的U8循环，不新增helper、接口、文件、owner或原函数身份。
- head/command只借const unsigned char*，保原先头样本后命令样本、先比较再同样本判NUL、不符立即false；第二对相符后两原生地址各加2再判同样本NUL。匹配才进入既有解码/回调，不额外读第二对或重取样。
- 保原命令相等/不等消费，CPP模板既有bool合同继续承接原TEST零/非零；原SBB的大小关系没有下游消费，不将其另造为返回API或原函数身份。iKe独有fd取样的原父/三末段继续路径以既有源合同保留，不宣机器寄存器等价。
- 108源命令、顺序、类型参数、既有工作区读序掩码、全部解码/tuple/实际callback和末三非提前返回源行全文保持。原接收头生产/格式/明文旁路、队列/owner/释放与SDK边界不改。
- 仅现有1216/F:00112E40追加局部原证/源码范围，零新语义/F处置/R7分类/NETWORK成员；FUNC-NETWORK仅两限定I/S，U10/V03/R04保持open。
- 本轮先追C9A94C邻近字段引用，目标仍只有既有4D8ECD读取，邻近写者属于别的字段，不能作为模式生产；不据空引用判不可达或补值。该事实独立保留，不影响本步头比较的真实开发。
- RPLAN.24、原格式明文/两加解密叶既定排除和音频暂停保持；不新增输入限制、保护、默认成功、故障/回绕样例或故障等价。
