# cg2d 黑名单共享状态与 `sub_401000` / `sub_4011A0` 证据

## 权威范围

本文的行为、地址和指令结论只依据当前只读 IDA 实例 `ida-17524` 中的
`D:\SOFTSTAR\cg2d.exe`；IDB 记录的原始输入 SHA-256 为
`dad3f292c6df28e9b7208ad1d339f56ab68c1e728f6595e849e37296551c0f08`。
当前同名磁盘副本的 SHA-256 为
`e7c2790f479862635932e043b2d7e93b9e791a1edc276a960af05f1454c54010`，
与 IDB 原始输入不同，不覆盖 IDA 基线，也不参与本项验收。STONAGE 不参与本项
行为、地址、语义或验收结论。

本项还原 `sub_401000` 的外层语义、其持久化 callee `sub_4011A0` 和四项共享
状态 owner；独立加载函数 `sub_401030` 仍未实现。

## `sub_401000` 边界与行为

- 精确范围：`sub_401000@[0x401000,0x401029)`，共 41 字节、11 条指令、
  3 个基本块。
- 原型：`char __cdecl(int32_t fileId)`；新端以
  `std::int8_t PersistAndReset_401000(std::int32_t fileId)` 保持 W8 返回值和
  signed W32 参数。
- 唯一 callee：`sub_4011A0@0x4011A0`。
- 唯一 caller：`sub_45D990` 中的 `call` 指令 `0x45DAE1`；调用者传入
  `gValue55A054`，并忽略返回值。

控制流严格为：

1. 以原参数调用一次 `sub_4011A0`。
2. 返回 AL 为 0 时立即返回 0，不写任何共享状态。
3. 返回 AL 为任意非零值时，先把 `0x5531A0` 以 W32 写为 -1，再把
   `0x59384C` 以 W32 写为 0，最后返回 AL=1。

该函数不清空记录表或路径，不附加文件 ID、路径、游标或空指针门禁。登录连接
控制器保持 `sub_5081A0`、本入口、`sub_508140` 的原调用顺序。

## `sub_4011A0` 边界与行为

- 精确范围：`sub_4011A0@[0x4011A0,0x401269)`，共 201 字节、72 条指令、
  13 个基本块。
- 原型：`char __cdecl(int32_t fileId)`；新端以 cpp 私有的
  `std::int8_t PersistBlacklistFile_4011A0(std::int32_t fileId)` 保持 signed W32
  参数，且 AL 只返回 0 或 1。
- 4 处直接调用指令位于 `0x401005`、`0x4012DB`、`0x4013BE`、`0x4014A1`。
- 直接库调用依次覆盖 `sprintf`、`fopen`、循环内的 `fputs` 两次和 `fclose`。

控制流严格为：

1. 建立全零的 512 字节局部路径缓冲区，以 `sprintf` 和原 signed W32 参数格式化
   `data\blacklist_%d.txt`，忽略返回值。
2. 将局部路径与共享路径作内联、区分大小写、逐字节至 NUL 的比较；新端用
   `strcmp` 只判断相等或不等，不依赖其返回值符号。不等时立即返回 0，不打开
   文件，也不写四项共享状态 owner。
3. 相等时严格以共享路径作为 `fopen` 参数，并以 `w` 模式打开；不改用局部路径，
   也不检查返回的 `FILE*`。
4. 按共享记录表的固定顺序最多遍历 100 条、每条 17 字节。每轮只先检查首字节；
   首字节为零就立即结束。否则将记录首地址作为 C 字符串调用一次 `fputs`，再以
   `"\n"` 调用一次 `fputs`，两次返回值均忽略。源代码提交 LF；Windows CRT 的
   文本 `w` 模式在磁盘上写为 CRLF。
5. 循环结束后无条件调用 `fclose` 并忽略结果，返回 AL=1。

该函数不读取 `gCursor`，不按长度写入，不补 NUL，不做编码转换，也不检查
`fileId`、目录、打开、写入或关闭结果；它本身不写 `gRecords`、`gPath`、
`gCursor` 或 `gCurrentFileId` 中任何一项。`fopen` 返回 NULL 时，原控制流仍会把
该值传给后续 `fputs` 或 `fclose`；17 字节记录若首字节非零但没有 NUL，`fputs`
也会继续越过该记录寻找终止符。这些异常域按原函数保留，不新增恢复、重试或
失败返回门禁。

## 四项唯一 owner

| 原地址 | 公开布局 | PE 映像初值 | 新端唯一 owner |
|---|---|---:|---|
| `0x592FA8` | `100 * 17` 字节，合计 `0x6A4` | 全零 | `cg::blacklist::gRecords` |
| `0x59364C` | `char[512]`，合计 `0x200` | 全零 | `cg::blacklist::gPath` |
| `0x59384C` | signed W32 游标 | 0 | `cg::blacklist::gCursor` |
| `0x5531A0` | signed W32 当前文件 ID | -1 | `cg::blacklist::gCurrentFileId` |

公开头使用 `std::array` 固定两项数组布局；实现对单条记录 17 字节、记录表
`0x6A4` 字节及路径 `0x200` 字节作静态断言。`gValue55A054` 只是
`sub_45D990` 传给本入口的另一项 W32 owner，不是 `gCurrentFileId`；R110 的
两个状态也都是不同存储，均不得并入上述四项。

## 独立加载边界

`sub_401030` 与本模块共享状态 owner，但属于独立的加载任务；本项不修改其真实
声明，不把加载逻辑合并到 `PersistAndReset_401000` 或 `sub_4011A0`。持久化
callee 已实现，但最终链接与服务器连接链仍因该独立未实现边界而未闭合。
