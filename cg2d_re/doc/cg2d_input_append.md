# cg2d 单字节输入追加还原

## 函数边界与状态

- `Input::AppendChar@[0x44ADB0,0x44B044)`，大小 `0x294`，IDA 统计 182 条指令、29 个基本块，原型为 `void __cdecl(char)`。
- `sub_44B190@[0x44B190,0x44B1C5)` 检查完整零结尾串的末个 ANSI 单元，返回空串 0、末个单字节 1、完整高位双字节 2、孤立高位字节 3。
- 该算法现在以 `cg::input::ClassifyLastAnsiUnit_44B190` 窄接口公开；
  `AppendChar_44ADB0` 与 `DrawInputText_4568A0` 只复用同一份定义，不复制算法，
  不改变本函数的追加或截断语义。
- `sub_44B1D0@[0x44B1D0,0x44B244)` 先以 `strncpy` 复制前 `Count` 字节并补零，再按同一规则判断边界；返回 3 表示 `Count` 切断高位双字节。
- 当前上下文指针来自原 `0x626C04`。`InputContext` 固定为 `0x15C` 字节：`text[288]@0x000`、`x/y@0x120/0x124`、光标字节偏移 `@0x128`、总字节数 `@0x12C`、`maxLine@0x144`、`maxCharPerLine@0x148`、`encrypt@0x150`。
- IDA 当前类型中的 `length/cursor` 自动字段名与指令用途相反：`0x44AE3A..0x44AE4E` 明确以 `0x128` 索引写入；`0x44AE5B..0x44AE62` 先递增总字节数 `0x12C`，`0x44AE6D..0x44AE74` 后递增光标 `0x128`；截断路径 `0x44AF66..0x44AFCB` 先缩短 `0x12C`，再把 `0x128` 向其夹紧。
- 原 `0x626C0C` 只按已取证行为承接所有接受路径末尾的 `20`；`0x626C20` 只承接超行后的分支选择；`0x626C28` 只承接特定回滚路径写 `1`。未为三者扩展业务语义。

## 字节行为

- `0x44ADCF..0x44ADE3` 对参数按有符号 8 位判断：接受 `00`、`0D`、`20..FF`，拒绝 `01..1F` 中除回车外的字节。实现显式使用 `std::int8_t`，不依赖本机 `char` 的默认符号性。
- 插入前以原 `strncpy` 次数保存光标后的尾串和旧 `text[288]`；随后写 `text[caret]=byte`、`text[caret+1]=NUL`，总字节数与光标各加一，再以原 `strncat` 上限拼回尾串。
- `NUL` 是原函数接受的输入。首次合法调用不会被拒绝：空串仍为空，但光标和总字节数均按原行为加一，最终 `0x626C0C` 对应状态写 20。
- 行扫描严格按原回车和 `maxCharPerLine` 字节数推进。高位字节仅表示旧 ANSI/DBCS 双字节单元的首字节；不验证第二字节的高位，也不解释为 UTF-8。
- 超过 `maxLine` 且 `0x626C20==0` 时，从最后允许边界截断，并删除边界处孤立的高位字节；总字节数随截断缩短，光标仅在超过新总长时向其夹紧。
- 超过 `maxLine` 且 `0x626C20!=0` 时，仅在插入后 `caret==total-1` 恢复旧文本、旧光标和旧总长，并把 `0x626C28` 对应状态写 1。其余情况保留插入结果。所有已接受路径最终把 `0x626C0C` 对应状态写 20。
