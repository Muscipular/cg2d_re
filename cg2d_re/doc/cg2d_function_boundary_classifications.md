# R1：函数边界片段与填充分类

[机器可读清单](cg2d_function_boundary_classifications.json)引用既有[原函数元数据](cg2d_ida_inventory.json)的稳定ID。本文件不修订IDA数据库，不删除原条目、不重新计算覆盖分母；只解释已取证的三个条目为何不能直接按自动名称生成独立函数。

| 元数据入口 | 实际证据 | 当前处理 |
| --- | --- | --- |
| 4C2634 | 4C2630的四字节mov先取栈中index，随后落入正文；原元素表第13项指向4C2630 | 现有WindowRuntime.cpp的Sub_4C2630包含两个参数与完整页面回调 |
| 4D6650 | 单字节C3；4D6644分配后test EAX，成功跳4D6651，失败落入此处返回 | 现有YobiRuntime.cpp的Sub_4D6640分配失败返回nullptr，保留成功续段 |
| 4C48EB..4C48F0 | 五个90字节；前回调4C48E9已经retn，后接4C48F0真实入口，本区直接xref为空 | 分类为已确认NOP区间，不生成空业务函数 |

4C2634的实现依[晶石商店分页合同](ui_windows/shared_69_70.md)，不是改变函数参数或另建页面。4D6650依[旧技能选择工厂合同](ui_windows/legacy_skill_choice.md)，不能把自动nullsub标签变成一次空调用后继续解引用分配失败结果。

填充结论只覆盖所列五字节，不以无直接xref证明所有间接路径不可达，也不把其他未归属区间一概排除。原入口、末界与稳定ID保持元数据原值；实际入口和父入口另列，避免伪造新函数ID。
