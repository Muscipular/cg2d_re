# 浮点强转整理 SPEC（FCS01）

用户要求清理缩放动画及同类代码中无意义的 `static_cast<double>`，沿此前“做完 SPEC 后执行”的授权实施。范围为本线 `src`／`include` 的现有源码，不新增业务、辅助类型或依赖，不生成 JSON 台账。

## 整理规则

1. 删除已有 double 操作数、double 接收位置或已是 double 的值上的重复强转；逐个核对直接参与的运算，不能因整条表达式最终赋给 double 就删除运算前的提升。
2. 缩放步长等现有只参与 double 运算的 float 常量，可将局部声明改为 double，仍先按原 `bit_cast<float>` 解出同一常量值，再由通常算术转换提升字段。保留 float 字段、写回时的窄化转换及写回前局部 double 的阈值判断。
3. 与精确可表示的二进制常量运算时，可使用同值的 double 字面量消除重复提升；不把 `0.1F` 等非精确小数直接改为不同值的 double 字面量。
4. 保留防止整数除法／运算溢出、控制浮点运算精度或数学函数重载的必要转换；不改运算结合次序、原常量位模式、F32 落存位置、读取／写入及调用顺序。已停止开发的离线 MIDI 工具不扩展数值重构。

整型入参的 `log`／`sqrt`／`pow` 已核本机 MSVC `<cmath>`：整数模板内部提升为 double 并调用同一双精度 CRT 函数，可直接传整数。float 入参的 `sqrt` 保留提升，避免改走单精度重载；整数除法前的提升、整数取负前避免溢出的提升同样保留。
