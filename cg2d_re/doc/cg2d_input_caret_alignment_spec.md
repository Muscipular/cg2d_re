## 3. 决定与实施范围

1. 既有InputCaret.cpp删两个额外helper IsValidFontType/CanMeasureImeComposition、三处辅助空对象拒绝、两处直接索引字体拒绝以及父的正游标/字体判断。保留原入口两门禁和所有原IME/首字节/首属性分支。
2. DrawImeCaret始终直接调用既有Font::measure。所有测宽前后字段/样本和截断、坐标公式/常量/入队参数不改；不新增probe/缓存/快照、Unicode迁移/接口或依赖。
3. AdvanceCaretPhase保存nextPhase与signed>=40判定，随后写新值，判定为真再写0；不在发布后重读共享相位。保留已有W32承载表达，不新增异常/溢出模拟或专项门禁。
4. 空对象/域外字体/组合越界等原异常事实依RPLAN.24保留，不新增安全保护、不承诺原x86故障或x64安全，不把这类情况纳入确定结果或故障等价PASS。正常字段与调用/状态取样仍须对照。
5. 补44A410完整语义映射；既有44B2E0只补本组父调用/证据关联，不改变叶body或提升其全局处置。只追加一局部equivalent/三限定I/W/S，T01/T02及完整输入/文本门禁保持open。
6. 渲染/资源owner、DrawText2/字体/三父body与其他输入绘制差异不借本组外推；EIC01组合提交成果保持。
