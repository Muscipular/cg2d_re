# 人物选择后的使用提示 SPEC

日期：2026-10-17。编号：CUN01。按用户“选择人物后弹出游戏对话框，是继续，否退出程序”实施。

## 接入与行为

1. 删除ApplyServerAddressPolicy中的MessageBoxW提示块，保留地址映射、DNS查询、SHA-256比较及原校验退出逻辑。使用提示统一归人物选择页控制，不再依附地址策略分支。
2. 在ProcessScene_460FF0（原0x00460FF0）的已有角色进入操作（槽位动作1，包括自动选角）后记录选中槽位，非Debug进入新增具名状态22；原人物准备、场景5切换及随后场景6的登录请求均延后到同意之后。Debug继续原路径。空槽动作0进入创建场景4，不接本提示。
3. 新增页面内局部对话框处理函数，复用CreateModalAction_5044E0、CharacterModalUiRecord及503990／503A20按钮交互。原完整提示只添加视觉分行，标题“提示”，按钮“是”“否”。使用640×480逻辑坐标，576×336模态窗口，正文8行，按钮位于正文下方。
4. 等待期间仅绘制人物页及模态框，禁用人物槽、创建／删除、返回和升级操作，并阻止页尾升级分支改变等待状态。不得发送角色登录请求或将选中人物切换到另一个槽。
5. 选“是”销毁模态动作、清空其引用，按原顺序执行人物准备与进入场景5；选“否”清理模态引用后退出。2026-10-17按[CUN02](cg2d_usage_notice_exit_crash.md)及用户“直接exit吧”修正为std::_Exit(std::rand())，跳过CRT静态析构。
6. 每次选择已有角色进入游戏均确认，不新增持久同意标志；创建／修改人物流程保持。模态动作创建失败时继续等待，不绕过确认。
