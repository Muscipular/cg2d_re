# 旧底部栏初始化

本页记录CRT5530CC..5530F4的11项初始化及真实数据写入，不赋予未证window id，
不把初始化记录认定为已有绘制或交互能力。公共边界见[旧面板运行期](shared_legacy_panels.md)。

## 局部方案与证据边界

在既有`LegacyUiRecord.cpp`建立六个已证W32数值的唯一私有存储，
以及八组各九个S32初始化值；不增加CMake目标或调用推测的绘制入口。
九槽数组只表示已观察的W32赋值，**不是完整原40B按钮结构或最终x64布局**：
不建模每组+24H未写尾字段，不公开数组、不设原步长断言、不转为既有文字/图形记录。
当前没有地址值生产或消费证据，不把零槽擅定为T*、void*、回调或句柄。
以后若找到真实消费者，需在同一owner上补类型证据及必要T*映射，不能建影子副本。

此方案完整承接每个构造已证的写入及返回，不代替尚未知的消费者合同。
不对齐总SPEC、不压缩历史；其余暂缓/待决项不变。

2026-10-01在原已打开IDA会话逐字节查`[D68938,D68A78)`的直接xref：
72处全部是下列八构造的写入，没有读引用；+24H尾字段没有直接引用。
六个标量的直接xref也仅在本初始化链内。此为有界直接引用证据，
不是间接别名/全程序不可达证明，不据此删除代码或排除复刻范围。

## 八组赋值

每组原基址为D68938+i*40，i=0..7；均依次读取5858A0、D68930、
5858A4、CB1DD8各一次，不跨记录缓存或把640/24直接内联成运行结果。
`cdq; sub; sar`为S32除2向零截断，使用普通S32除法，不改成无符号移位。

| 已写槽（原偏移） | 值 |
|---|---|
| 0（00H） | 5858A0快照/2 + D68930快照 |
| 1（04H） | 5858A4快照/2 + CB1DD8快照 |
| 2（08H） | D68930快照 + 80*i |
| 3（0CH） | CB1DD8快照 |
| 4（10H） | 80 |
| 5（14H） | 24 |
| 6（18H） | 0，仅已证初始化值 |
| 7（1CH） | 22551+i，仅已证常量值 |
| 8（20H） | 0，仅已证初始化值 |

八组第0槽都取同一个半宽偏移，不自行改成各格中心。
第0组写序为2→4→0→5→3→1→6→7→8；
其余七组为4→0→2→3→1→5→6→7→8。
高度读取与后续Y读取分别保留原位置；第0组独立实现，
后七组用只处理相同读写序的私有助手，传入原偏移及常量，不统一掉第一组的差异。
