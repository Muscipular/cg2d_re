## 完整控制流

### 1. 入口与提前返回：0x507146–0x507195

1. 先读取 `S16` 图形计数，决定本次使用的末尾排序槽位置。
2. 将 `0xD6978C` 的旧值按 `U32` 比较：小于 59 时加 1，否则置 0。
3. 用更新后的索引查询 `0x58ACC8[60]`，将结果写入 `0xD69768`。
4. 写入 `0xD6976C = -1`。
5. `0xCA0AB4 != 0` 时清槽并提前返回；该路径保留旧文本索引、鼠标事件字节和描述缓冲，不得补写这些状态。

入口确定的排序槽位置与后续重新读取的图形计数属于不同读取阶段，不能合并为一次快照。

### 2. 文本正序命中：0x5071A4–0x507256

文本从下标 0 开始正序遍历；每次失败后重新读取 `S32` 文本计数，仅处理 `value7 != 0` 的记录。

调用 `TextMeasure` 后，按下列顺序短路判断，边界均包含等号：

1. `X <= x + w + 2`。
2. `x - 2 <= X`。
3. `Y <= y + fontHeight + 2`。
4. `y - 2 <= Y`。

四项分别执行相应的 `CryptInt` 读取；不能将同轴两次读取合并或先读出鼠标坐标再复用。首个命中结束文本搜索。

### 3. 文本命中收尾：0x50733F–0x507407

先写入文本下标，再按 `value7` 处理：

- `value7 == 2`：绘框参数为 `(x - 3, y - 4, x + w + 2, y + h + 4, 218, D69768, 0)`。
- `value7 == 3`：绘框参数为 `(x - 3, y - 4, x + w + 2, y + h + 4, 214, marker, 1)`，其中 `marker` 为 `0xD69768`。
- 仅上述两类在绘框后调用排序；其他命中文本不补调用排序。

随后写图形索引 `-1`，将鼠标事件低 8 位写为 `0xD4`。仅当 `0xD460C8 == 0 && 0x58589C != 0` 时清 `0xD68AC8`，然后返回。

### 4. 文本未命中后的图形逆序搜索：0x50725C–0x507585

仅在文本未命中时重新读取 `S16` 图形计数，并写文本索引 `-1`。

从入口确定的末尾位置逆序遍历每项 4 字节的排序槽，以槽内 `S16 cacheIndex` 定位每项 40 字节的图形记录：

1. 先要求图形记录 `+0x10` 的 `value4 != 0`；该字段不是 `layer`。
2. 再调用 `0x522570(imageNo)`，要求 `EAX != 0`。
3. 任一条件失败即继续搜索，不能提前做后续对象或矩形处理。

### 5. 图形命中矩形：0x5072B8、0x507408、0x50748D–0x50756F

| 条件 | 命中范围及限制 |

- `0x58AD5C` 使用 `obj[+0x1D0]` 与选中的字符串；通常为 `obj + 0xC4`，特定分支优先 `obj + 0xE1`。
- `0x507791–0x5077B0` 另压入 `obj + 0xE1`，但格式不消费该参数，不得新增对应显示。
- `%-16s` 仅规定最小宽度，不截断字符串；`sprintf` 不带容量参数。IDA 项长度和栈缓冲长度不能替代 NUL、实际文本长度及格式化容量契约。
