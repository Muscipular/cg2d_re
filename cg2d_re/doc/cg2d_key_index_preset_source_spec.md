## 工程裁决

依既有委托先记SPEC后实施，只改三个实际文件：WindowProcedure.cpp的4597B0参数类型、KeyState.hpp对应声明/说明，Input.cpp预设调用参数表达式。无新增函数、状态、接口层或依赖。

1. 4597B0声明/定义同为std::int32_t key，保完整W32；函数仍从唯一gKeyStates按索引读一次U8状态，返回0/0x10，不清状态、不归一bool。不增负/大索引拒绝、钳制、默认值或范围分支；异常地址不专项模拟或声明等价。
2. 4597A0原完整S32索引、U8状态和0/4返回正确体保持。256B键态owner、窗口/SDL事件生产及Clear/Reset、4597C0短路查询全部保持，不调整其它位或初始化。
3. 预设将0x70+index直接以原S32表达式传入，去掉U8收窄。Shift bit1命中选16组且不读取Ctrl，否则Ctrl bit1选8组；F1..F8顺扫，最后非零命中覆盖selected；未选保最后查询返回。
4. 选中仍借唯一24项15CH InputContext文本，先真实44A160装载，再调用既有52C450并透传S32。现有三原查询点复用一个循环不变，当前现代473F80唯一调用/所有其它父和源码保持；不把该路径当旧99表handler来源。
5. 原声效call多压栈51/320/240；只读支持体52C450的164条551B仅两处读取入口参数+4/+8，额外第三值未被读取，既有51/320两参声明/调用保持。该支持证据不混入87条分母、不新增音频成员/语义或验收，也不开发/恢复暂停音频。

全部已证键值保持，正常旧返回/预设选择不变，不宣称已有合法键错误。x64仅既有真实地址原生承载，索引不提升size_t/U64；网络原格式只明文、两加解密叶排除与内存CryptInt保持。
