# 启动保护值四项构析与宿主登记 SPEC

> 2026-10-04；C02/C04局部实施，依据[D02/D03与工程委托](cg2d_closure_decisions_spec.md)、[启动生命周期](cg2d_crt_startup_lifecycle_spec.md)。改本组活动构析和退出登记，保留原完整应用序待验；不启用旧私有CRT整表。

<a id="startup-protection-baseline"></a>
## 1. 原端基线与当前缺口

[实际原证据](cg2d_startup_protection_lifecycle_evidence.json)保存四相邻槽、十二原身份全部44条指令及直接入向。四Init各6条，登记后置chunk分别401C40/404140/404180/4041C0，不增加函数身份。

| 原表槽→入口 | 构造 | 固定owner | 退出 |
|---|---|---|---|
| 553004→401C10 | 401C20，4条 | 5939C8→5939D8两个独立值 | 401C50，4条，D8→C8逆序 |
| 553008→404120 | 404130，2条 | 594070校验值1 | 404150，2条，同一值 |
| 55300C→404160 | 404170，2条 | 594080校验值2 | 404190，2条，同一值 |
| 553010→4041A0 | 4041B0，2条 | 59E548进程保护值 | 4041D0，2条，同一值 |

每Init先完成实际构造，再立即53B406登记本项固定无参退出，返回真实S32结果。原表正序调用且不消费返回；一次登记失败不短路下一项，不回滚已经完成的构造，也不预登记退出。

全部构造沿原401C70，首项两个值依次构造，后三项各一个，共五次已有RNG消费；退出只沿原401CF0恢复token，不释放值存储，不加清零、重采样或拥有其他对象。原数值/算法本组不重做。

现存五个LegacyCryptInt是唯一实际聚合存储，使用本线既有16B字段表示。LegacyMouse.cpp四自动适配各直接调用构造、以自身析构调用退出；同时四具名Init另沿旧退出表登记。当前自动适配未调用Init，因此原即时登记职责没有成为这组实际活动路径。不能增加Init调用却保留四自动析构。

<a id="startup-protection-decision"></a>
## 2. 本步实施选择

1. 保留五个实际聚合存储、初始字段和所有构造/析构/值算法源码原文。没有新owner、影子对象、句柄、字节镜像或跨域释放。
2. 四既有Init仍先调用本项构造，登记改为实际std::atexit对应本项既有无参析构，并传出真实宿主S32结果。仅宿主退出表、私有分配/异常机制依D02/D03承接，不把std::atexit记为53B406旧体等价或新原函数调用。
3. LegacyMouse.cpp原四适配所在位置改为一个无析构动作的StartupProtectionValuesStartup。构造按553004→553008→55300C→553010依次调用四真实Init，每次完成构造立刻登记，丢弃返回而不短路。用静态断言约束适配析构平凡；没有对应自动退出。
4. 保留当前同模块前置位置和后续WorldObjects/流/其他适配。全应用原序迁移时必须同小步移除本适配，再接四Init；不能双调用或将本组相邻顺序外推跨模块顺序。
5. 不新增once、懒构造、成功默认值、登记重试、回滚、失败保护、额外RNG或重复调用保证。登记失败沿实际宿主语义，原表caller不消费结果且继续后项；不能用新增自动析构补偿未成功登记。
6. 仅本组从旧退出表迁移。其他Legacy provider、全表/退出、标准流活动归属、原堆和音频暂停仍各自按既定合同推进；不把本组变更推广为所有构析已迁移。

构造/注册/退出现在通过同一具名provider可成对移动，取消本组四个重复自动析构入口。注册目标就是原固定析构，不加额外包装清理，也不把私有退出表迁移说成业务功能排除。

## 3. 本组验收门禁

| 局部门禁 | 必须证明 |
|---|---|
| I | 四Init完成构造后真实宿主登记，五实际owner与十二原身份准确对应 |
| W | 唯一模块适配正序调用四项、不消费/短路结果；退出由已成功登记回调逆序承担，无自动析构并行 |
| S | 四表槽/44原指令及本组新增活动路径可追踪；扣除登记与适配变化后源码不变，原构析和RNG没有修改 |
| R | 现行禁构建/测试/运行；实际宿主登记失败、退出/跨模块序和完整客户端未验 |

局部I/W/S可归档，C02/C04与完整FUNC-STARTUP/FUNC-CRT门禁仍开放；源码收口不代运行与整体分类/数据闭包。

<a id="startup-protection-source-closure"></a>
## 4. 本组源码收口

四既有Init在LegacyCryptInt.cpp/MainLoopSupport.cpp改为完成原构造后即时std::atexit登记同一既有无参析构，返回实际宿主S32。删除这两个文件仅供本组旧登记使用的LegacyRuntimeExit依赖，显式包含所需cstdlib；接口和所有原构析/值/RNG/保护代码不改。

LegacyMouse.cpp原四自动构析适配改为一个StartupProtectionValuesStartup，在原位置依553004→553008→55300C→553010调用四Init并逐项丢弃结果；析构平凡写入静态断言，未执行编译。取消四自动退出动作，没有第二owner或自动析构补偿登记失败。本组只调用一次，未来全应用原序接通须同时移除此适配。

四原Init与53C8CD关联更新，八已存在构析叶新增独立身份记录，均在原3680库存中；后置登记chunk不另算身份。语义1144→1152条、有效原ID1141→1149，18pending/4分类引用保持。十二原身份登记adapted，使已审39→51/3680；宿主私有登记差异明确，不登记为53B406源码等价或新增原体调用。

归档E-STARTUP-PROTECTION-I/W/S-20261004三限定局部证据，累计21条，实现固定至Git命名快照cg2d-re-startup-protection-source-20261004。C02/C04仍open，已关闭源码任务仍10，完整功能门禁与叶验收0/182不提升。全应用相对序/跨模块/快速退出、其他owner与完整客户端运行仍待，音频暂停和不构建/查产物/测试/运行/文件摘要限制不变。
