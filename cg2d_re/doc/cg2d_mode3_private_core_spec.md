<a id="mode3-private-core-baseline"></a>
## 原端与当前事实

[机器证据](cg2d_mode3_private_core_evidence.json)归档三个完整原函数：
541FB1分配275条/777B，541C88释放265条/809B，542466原位扩容259条/758B，
合799条/2344B；这里只登记边界、指令及直接引用，不声明逐条算法等价。

当前原会话中三个入口仍分别有3/3/1个直接引用，与M3H01的七个call一致，
父为53BFF8、53C3EA、53C0A9、53FA5B。
当前src/include中的三旧C++符号仅见于LegacyHeap.hpp的无本体声明，
无调用、取址或定义；五mode3分支已由真实SDK提供者接通。
该观察只覆盖已纳管源码和已证直接引用，不关闭未知间接目标/alias/R1。

<a id="mode3-private-core-decision"></a>
## 开发裁决

1. 删除三个已无源码引用、且从未实现的私有核心声明。
   原函数身份、指令、七个call及历史记录完整保留；不删除原函数证据，
   不提供同名空包装或伪装成SDK ABI的旧接口。
   这是对M3H01“仅留身份/参考”的接口收口，历史“保留”不再要求保留不可调用声明。
2. 541FB1的三个原调用角色，分别由53BFF8的std::calloc、
   53C3EA的std::malloc和53FA5B的std::realloc模式3路径承担。
   541C88的直接free角色由std::free承担；
   其两个realloc迁移后释放角色由SDK同域realloc内部承担，不重复释放旧块。
   542466的原位尝试由同一SDK realloc整体承担，不再暴露旧bool结果或区域参数。
3. 三原ID按D02登记为host，表示私有分桶/拆合/原位机制由宿主接替；
   不登记equivalent，不把三个原内核列成新增本体。
   五外层API继续按M3H01的adapted合同：原请求/门禁及明确失败策略差异保留。
4. 只改该头声明块及两处过时注释；原模式1/2、所有CPP本体、
   元数据结构/初始化/区域生产、五SDK分支、外层handler及现有各分配域保持。
   存活期间模式稳定/同域要求不变，不新增模式切换、指针标签或混域转换。
5. 原区域/组生产者仍为保留的兼容元数据入口，不能据其声明推导旧分配核仍待实现。
   本步不退休其生命周期、不扩展host分类，也不关闭C01/C08/C11。
