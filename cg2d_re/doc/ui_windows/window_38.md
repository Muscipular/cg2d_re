不专项模拟别名、不改成外部字段、不增加拒绝或补零，也不记异常等价。

随后写各自缓存；bit1且hover>=0时，bit2在used非零才启动mode1拖动/SE51，

页码S32自增后与pages有符号比较，到尾归零，仍不因空槽取消消费。
源框自有kind2且source>=8，外部kind2/5且source>=100；不要求来源窗口相同。
