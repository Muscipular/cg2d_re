## 实施裁决

1. 三个私有函数仅替换return为left+right／left-right，保S32、名字／noexcept和调用点；不重构、不添helper、保护／限制或溢出模型。
2. 六上界比较接已有Less_401DB0，实参为同一platform::gLegacyMouseState.mouseX/Y与原S32上界；上界值在进入单次读取前算好。既有LegacyMouse.hpp已提供声明与owner，不改头／库体。
3. 其余两完整源码保持，特别是BSB01六下界IntLessCryptRaw的低W8条件、mouse读取次数／短路、焦点／字符串／计时／声音与保存、两轮visibleCount现场重读、原数字图号／除余及低W16保持。音频仍暂停，网络原格式明文保持。
4. 三真实F新增语义／adapted局部处置，INPUT加三成员，比较叶只六AL调用域，全部其它别名／完整EAX／ABI仍未验。两X映射用途；U10／R04仅current与引用保持open，不新完整功能门禁。
5. 不执行编译、测试、客户端、算法样例、调试、产物读取或摘要。RPLAN.24禁止专项处理的域不因此计为修复或范围排除。
