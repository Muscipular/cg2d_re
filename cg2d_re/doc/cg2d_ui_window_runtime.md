**+40/+44/+48/+4C**，循环步长0x10，不照搬IDA把数组起点标为+44。

## 关闭请求

只读完整`4CD3E0@[4CD3E0,4CD3F1)`和`4CD400@[4CD400,4CD411)`：
各自从原记录指针+0x1650、+0x15FC取得实例，分别为索引68、67。

## 普通移动父函数469FC0

完整`[469FC0,46A188)`已只读核。放在SceneState，返回U16仅承接所有
出口已定义的AX；原469C90消费低AL，其他高位不造寄存器模拟状态。

1. 先采9EE8B8，随后无条件把9DAD78置F32 1；所采值非零立即返回低W16。
2. C821D8 CryptInt等于0、9A86D8/9FB92E均零才调用46AB60；
   返回非零直接返回低W16，不执行跟随、清C8222E或尾部投影。
3. 快照X→Y各读取一次乘64，保持F64比较，共享世界坐标保持位型采样；
   X未到达不读Y，原C3的unordered分支保留。
4. 到达后C821FC非零且C82202为0时先清C821FC，再调用完整46B6F0。
   路径计数为0且待发送计数为0，调用46B4B0(55D9FC的S16)，
   随后重新采S16路径数，再写55D9FC=FFFF。
   路径数>0且待发送数为0时，46ABD0；新待发送数>0才46AA00；
   无论该分类是否把数量归零，随后都4CD3E0→46AC10。
5. 待发送数S16>0时46AF30，取首S16方向，再46BCF0出队；
   采玩家S32步速、方向Y低S16，给玩家Y作401E00；
   之后才采方向X低S16，给玩家X作401E00，最后46A410(X,Y,speed)。
   401E00全指令证实先读CryptInt、再MOVSX低W16相加；
   新端用已有Add_401E10与符号扩展S16参数等价承接，不把未定义参数高位
   加入运算。初始化后再当前Y→X读取并46A5A0，不改读快照代替。
6. 公共尾46A5F0后重读9EE8B8，清C8222E W16；非零返回其低W16。
   零时46A700→46A940→468200，再先读世界X/Y、后写投影参考X/Y，
   返回468200原AX位型，不返回世界坐标。

所有直接下游本体在本步接通；窗口owner的生产/失效仍未闭合，469C90
上游及普通/战斗完整场景仍缺。仅静态检查，不构建、测试、运行或实际发包。
