# 4.06 动作标志与主挂件适配（AF406）

2026-10-19。用户已明确“都按4.06的”，随后排除 GraphicInfo.flag 的低8位截断。本项按该裁决实施，不再新增顶部居中／60%居中的自定义算法。

## 依据与边界

以当前已打开的 cg4.06cn.exe IDA 会话只读取证：417852..417876 根据 AnimeInfo.flag bit0 选择12／20字节动作头；41793D 保存动作头+0E的16位属性；470755..470759 在播放时写入当前图形缓存+24。该字段对应本线 ActionEntry.revert，不是 AnimeInfo.flag，也不是帧音效／事件flag。

用户提供的 ANIM_PUK2_FORMAT 宏定义可用于命名：REVLEFT=1、REVTOP=2、LOCKPAL=4、LIGHT=8、FIELD=0x10、SHIELD=0x20、TITLE=0x40、LOCKPOS=0x80、CHPAL=0x100、WING=0x200。宏注释不是算法证据；当前4.06主挂件链未发现TITLE的图片顶部计算，也未证实CHPAL在该版本的文字指定调色板消费，不凭名称新增行为。

范围是地图和战斗的主佩戴挂件：地图action30、战斗gear13B4。宠物类辅助挂件、全部战斗技能与网络协议不扩展。本线SDL后端、现有图形/动画编号、图形偏移和独立调色板系统保留。GraphicInfo.flag仍完整16位保存、按100取余/相除；GRT04零色色键保持。

## 已证动作标志

| 标志 | 行为与证据 |
| --- | --- |
| LOCKPOS 0x80 | 40AF1B..40AF5A：跳过人物当前图形Coordinate，坐骑Coordinate仍累加；不代表不使用挂件自身图形／帧偏移。 |
| WING 0x200 | 40AFC7..40B055：跟随父动作，骑乘时以坐骑为同步源；100250..100273、100650..100655在动作6时不绘制。4707E5..47080B：动作5/8/9/10的下一帧索引跟随同步源。 |
| FIELD 0x10 | 40B061..40B0B1：不附加人物Coordinate，普通地图使用层4；战斗使用层2；动作10及地图骑乘过渡分支不绘制。 |
| SHIELD 0x20 | 40B0B6..40B0EB：不附加人物Coordinate，普通地图用默认层6；战斗用人物层；动作10及地图骑乘过渡分支不绘制。 |

优先级WING > FIELD > SHIELD > 普通挂件。普通挂件动作2/3/4映射为0，8映射为3，其余跟随人物；不是一律只使用动作0。

0x436656..0x43666D按方向4/5/6与其它方向标记关联图形，43693C..4369B9决定提交顺序，4746C3同层按索引降序绘制。普通地图最终方向4/5/6为挂件在主体后，其余在前；动作10另以层5处理。战斗的WING分支在方向4/5/6时将挂件层减1，保留动作10的播放策略。

## 本线接线

1. AnimeInfo完整保留16位格式值，以bit0选择长头；不修改GraphicInfo解析。动作标志完整16位发布到按graphic索引的现有缓存，保留4.06同图共享、后播放覆盖的语义；渲染描述符仍为16字节，低字节混合用途保持。
2. Coordinate加载时将已解析的图号及x/y发布到同一图形缓存；沿现有配置和延迟加载流程，不另开资源文件。主挂件使用Coordinate独立偏移，不再把人物动画帧x/y重复当作挂件锚点。横向翻转时Coordinate X取反；4.06该路径未对Coordinate Y做翻转。
3. 两个动画播放入口增加可选同步源，只由WING挂件传入；实际取帧后按4.06更新下一帧索引，等待帧不额外推进或触发音效。其他调用保持原默认行为。
4. 地图沿既有主对象和前后附件链处理WING，骑乘时保留主对象/坐骑/挂件的相对次序。当前普通地图层为10，对应4.06普通层6；FIELD适配到层8、倒地WING适配到层9、SHIELD与普通挂件使用层10。层级差异仅是宿主队列接线，不改变全局排序器。
5. 战斗保留现有父对象存活、隐藏、颜色和更新时序；加入上述动作、坐标、隐藏条件与最终层选择。排序后再应用主挂件层，避免原排序覆盖标志选择。
6. 未证实的TITLE/CHPAL完整保留位值但不新增消费者；不将它们宣称为已经实现的顶部／文字调色板功能。LIGHT/翻转/调色板既有绘制功能不在本项重做。
