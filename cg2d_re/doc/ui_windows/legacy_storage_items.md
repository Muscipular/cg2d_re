# 旧选择72：物品存放子页

本页记录旧选择表72内的4E2030及数量层4E10F0，不是现代窗口编号72。
外层4E0380在4E042B把4E2030写入局部子页函数表；本步不补造旧表分派，
也不把本子页完成记作外层切页、存放确认或完整往返已实现。

## 局部方案与边界

沿用户工程委托采用：七个已证函数在LegacyUiRecord承接，使用现有
LegacyPanelRecord表达582B70唯一面板；原40/16/560/364、编号72、
背景23340及其余零初值保持。两组矩形为(13,94,60,141)、
(291,94,338,141)，每组5列4行，间距52。

物品继续借WindowRuntime唯一CC4D58展示区，side步长FBF8、
每条C44，以显式memcpy读写W16/S32；不重建另一份物品数组或强转
未建立生命周期的结构。玩家数量/金额、鼠标、键盘、socket、输入焦点及
悬停文本沿既有owner。非地址数值维持32位，4E0270原返回尾指针用char*。

CA0AA8为本页数量层门禁，与CA0A90六材料来源数组不重叠：
47D56C、47DD2C、481992等及4F553D仅比较offset CA0AA8，
实际值读写只有4E0380、4E10F0、4E2030。不把数组末端xref当成共享值。
来源D3FACC、目标CC4D38、数量CB2220均为独立S32，不套旧16拆分槽。
这些槽及CC4C98/CB09D4拖动、D67C94页、D67C98消息、D67C9C时间、
CF49BC/CF4A04/D2DAD4/D30404计数、D40B04/D2F79C金额均为虚拟零；
582C64/582C68上次悬停才是已加载-1。D30404尚无直接写xref，
不把当前初值当固定容量；其生产与旧72外层待后续追踪。

## 父子页交互与绘制

入口消息>0且tick非零才取时间，随后重读tick，按无符号tick+2000<now
清消息/时间。先查两side悬停，再用数量门禁将两者置-1；悬停变化清页，
已打开数量层先更新，再统计背包side1空槽，最后取鼠标低U8。

背包右键0x10优先：used且状态非负才处理，状态1清0/SE54；
其他须D2DAD4<D30404且gold-D40B04-D2F79C>=1才异或1/SE79。
缺钱写消息1/当前tick后SE55；容量不足只SE55。上述有效分支音效后
重读鼠标再清拖动。左键拾取需used且状态非负；异槽放下按Ctrl与
移动方式门禁、来源count>0和目标空判断数量层，生产四槽并清拖动/SE56；
否则空目标或状态非负才真实510EC0，清拖动/SE51，同槽或负状态只清拖动。
其他取消分支先SE51再清拖动；无拖动时右键2递增详情页并按记录页数回零。

存放side0处理使用上述可能重取的鼠标：0x10切选择，容量沿
CF4A04/CF49BC，不查玩家金额；否则bit2翻详情页。拖图230层，先读图号、
鼠标Y再X。两side同时命中时side0详情优先，详情绘完才画两组物品。
费用/玩家金额文字2层，底图212层23341。提示先side0非负选择项，
否则side1；flags100优先名称+[kok]，flags200为memo+[han]。
普通side0为取出；side1按选择状态、容量显示四提示。提示不清默认值。
返回保留最后绘图结果、最后检查的C44相对偏移、0或strlen+1的原分支差异；
尾部先写side1再side0上次悬停。
