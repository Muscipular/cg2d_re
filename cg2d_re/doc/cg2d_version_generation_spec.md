# CMake版本头生成（VG01）

- 用户要求将1.0.0改为`yy.m${vTag}@${gitHash:8}`，已确认vTag由CMake参数手动传入。
- vTag为CMake缓存字符串，默认空；支持英文数字及`.`、`_`、`+`、`-`，例如`-DvTag=beta`。日期按构建环境本地年月，年份两位、月份无前导零；例如2026年10月为`26.10beta@xxxxxxxx`。
- Git标识读取当前仓库HEAD完整提交号并截取前8位，不读取EXE摘要、不创建标签。不附加dirty标记。缺少Git或无法读取HEAD时报错，不生成虚假版本。
- CMake在配置时以及每次客户端构建前生成构建目录下`generated/version.h`，输出窄/宽版本字符串宏。configure_file仅在内容变化时改写头文件，避免无变化构建重编译；日期和Git更新不依赖手动重新配置。
- 登录模块的kVersion改为读取生成宏，现有标题与版本绘制共享此值，不改网络/协议版本。
- 版本文字变长后，原540起点可能超出640宽登录区域；绘制时按实际字体宽度必要时左移，保留原Y、颜色及图层。
- 使用本会话授权的build.bat Debug验证配置、生成、编译和链接；不运行客户端或新增测试。生成头不提交，源码模板与进度提交。
