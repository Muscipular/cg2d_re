# cg2d 当前保存记录条件值恢复证据

## 函数边界与调用关系

- 原函数：`sub_520730@[0x520730,0x520744)`，共 20 字节、7 条指令、
  3 个基本块，无参数、无 callee。
- 唯一 caller/callsite 是 `sub_5201B0@0x5201E4`；调用后立即在
  `0x5201E9` 覆盖 `EAX=1`，因此忽略本函数返回值。
- 源码只在 `LoginSavedState.cpp` 匿名命名空间定义私有
  `[[maybe_unused]] RestoreCurrentSavedValue_520730()`；本项不接 caller。

## 数据引用与映像初值

源地址是唯一当前记录 `gCurrentSavedRecord@[0xFF4918,0xFF4E28)` 内的
`0xFF4918+0x315=0xFF4C2D`。该地址共有 2 个 exact-address direct xref：

| 指令地址 | 函数 | 行为 |
|---|---|---|
| `0x520725` | `sub_520720` | 写入 W8 |
| `0x520730` | `sub_520730` | 读取 W8 |

目标地址 `0x553438` 是 signed W32，映像初值为 10；新端由中性命名的唯一
`cg::platform::gValue553438` owner 持有并初始化为 10。其 7 个
exact-address direct xref 全部如下：

| 指令地址 | 函数 | 行为 |
|---|---|---|
| `0x4FE3F0` | `sub_4FE3F0` | 读取 W32，随后以 signed `jge` 比较 |
| `0x4FE409` | `sub_4FE3F0` | 写入递增后的 W32 |
| `0x4FE440` | `sub_4FE440` | 读取 W32，随后以 signed `jle` 比较 |
| `0x4FE459` | `sub_4FE440` | 写入递减后的 W32 |
| `0x4FE987` | `sub_4FE860` | 以 `fild dword ptr` 读取 signed W32 |
| `0x520720` | `sub_520720` | 只读取目标低字节 |
| `0x52073D` | `sub_520730` | 写入零扩展后的 W32 |

IDA 把 `0x553438` 错识别为字符串起点；该标签不构成业务语义。W32 宽度、
signed 比较、`fild dword ptr`、映像初值和 exact xref 才是本项采用的证据。

## 读取、条件写入与返回

`0x520730` 只从当前记录 `+0x315` 读取一次 W8。若值为 0，函数不读也不写
`0x553438`，保留其旧值并返回 `AL=0`；若值为 `1..255`，函数先零扩展为 W32，
再写入 `0x553438`，并以同一个低 8 位值返回。函数不重读源字节，不读取目标，
也不布尔化或钳制输入。

原机器码只定义 `AL` 返回值，高 24 位沿入口状态保留，不能抽象成有定义的完整
`EAX`。新端因此使用 `std::uint8_t` 返回类型，只表达原函数有定义的低 8 位。

反向函数 `sub_520720@[0x520720,0x52072B)` 无条件读取 `0x553438` 的低字节，
并写回当前记录 `+0x315`；它不保存目标高 24 位。

## 异常与实现边界

原函数没有空指针或记录长度参数，也没有字段范围保护。若唯一当前记录不可读，
异常发生在源 W8 读取处，目标尚未被访问或写入；源读取成功后，零值路径不写目标，
非零路径只执行一次 W32 写入，没有批量提交或回滚。

本项不修改当前记录 owner、CMake 或 caller，也不实现 `sub_520720`。行为证据只取自
当前 `ida-17524 / cg2d.exe`；STONAGE 仅可作为架构参考，不参与本项行为、地址、
语义或验收结论。
