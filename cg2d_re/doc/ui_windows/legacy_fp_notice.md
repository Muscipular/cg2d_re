# 旧选择编号34：FP不足提示

本页记录4F0B40，不是现代window id34动作选择。入口由旧选择37的
[再次使用失败分支](legacy_skill_result.md)504180(34)发布；旧表handler调用器仍未证。

## 局部方案与证据

完整父入口放LegacyUiRecord。583E20为唯一LegacyPanelRecord，
x160/y180/宽320/高96/id34，背景及其余字段全零；
不因底图为0而替换成其他提示窗口。CC31D8沿旧UI共享S32，不增加影子存储。
它的三个直接xref为4EF351、4FFB43写和4F0C57读；4FF650仍未实现/待决，
本轮仅实现37生产和34消费，不把此字段存在等同于全部上游完成。

只读核[4F0B40,4F0CCC)全部110条指令、面板196B及三段原文本。
反编译char返回不采信：实际EAX在普通路径来自503440，在通知路径来自511DD0，
两者完整W32均保留，采用uint32_t，不截低S8。
返回2后先MOV AL,5F9754，原EAX高24位仍为零；标志0直接返回0。
这不是返回公共函数的2，也不改成固定成功。

## 完整流程

入口构造CharacterModalUiRecord：文字(x+146,y+64)，
命中(x+144,y+64,36,18)，标签55C5D4；
503160(opened,panel,null,0)，返回0直接0。
返回2时5F9754非零才读玩家Y后X、511DD0(socket,x,y,62)、
清5F9754并返回该完整结果，零直接0。不清其他技能pending或改场景。

其他非零路径先查503990，bit0置位时5042D0(panel.id)、SE57，
之后仍格式化/绘制两行，不提前返回：
- 589BFC原文字，无格式占位，于(+16,+24)，layer2/font0/color0。
- 589BE8仅一个%d，使用当前CC31D8，于(+16,+44)，同字体/颜色。

局部256B缓冲；第一sprintf实际只压format和buffer两个参数，
反编译追加的七个按钮字段不是实参，不能照抄其伪代码。
绘制逐次重取面板Y/X，低S16边界保持。
最后503A20(button,2,4,1,当前hover,218)，再503440(panel,0)，返回完整W32。
