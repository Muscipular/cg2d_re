- 保持单一`std::uint32_t gRandomSeed=1`及既有extern声明；所有播种和取数仍在现有MainLoopSupport模块共享，不改为宿主CRT、TLS、独立对象或新增owner。

- 区间沿[既有RAND正常域裁决](cg2d_random_range.md)：upper==-1返0且不消费；否则只取一次随机数，再用普通S32区间/余数加lower。保留RPLAN.24，不添加上下界排序/门禁、除零或溢出故障策略、回绕仿真、钳制和异常等价声明。
- 七个源码播种表达式所在父源保持。原十CALL与这些表达式只记录各自来源；外部键盘范围排除保持，不以原引用恢复该功能，不称所有父/消费者和整条RNG消费时序已通过。

本步零源码改动、零新接口/helper/owner或实现I，三正确primitive仅纳管到LOOP的实际成员与限定S。旧RAND文档中的并行、独立review和待批措辞是历史阶段记录；当前按子项目AGENTS单线程、既有委托与RPLAN.24执行，不重复申请或启动代理。

## 标准线性同余引擎承接（LCG01）

2026-10-14用户明确要求使用std::linear_congruential_engine；按第8条工程委托，保持原序列与消费者，只替换共享随机状态及两基础入口内部实现。
使用std::linear_congruential_engine<std::uint32_t,0x343FDu,0x269EC3u,0>；模数参数0表示2^32，乘数／增量和32位状态对应原递推。
初始种子仍1；增量非零，seed(0)按标准保留0，完整U32播种不截位。SeedRandom仍返回传入值且不取数，NextRandom每次仅调用一次引擎，再按(seed>>16)&0x7FFF返回原15位int。
