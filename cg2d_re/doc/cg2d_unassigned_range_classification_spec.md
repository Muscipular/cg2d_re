<a id="range-classification-padding"></a>
## 62段填充的证据

每段完整字节全为90H，区间内逐字节检查没有当前函数归属和直接代码/数据引用；前一实际代码指令到区间左界结束，为RET或已证o_near直接JMP。前一所属实际函数块以左界结束，后一实际函数入口或已证尾块入口始于右界。

尾块按Chunks取实际边界，不把函数主块end_ea当全部块终点；401920属4596D0尾块，401C40属401C10尾块，404140属404120尾块，相关填充仍以原X身份登记。已证直接JMP与RET同样终止此处顺序执行，区间内引用检查保持完整。

不从“全90H”单独推出用途，也不从零直接xref推出没有未知间接目标/alias。原16字节对齐元数据只作辅助，原完整字节、前后实际指令/块和逐字节检查共同作本步依据；相邻函数及真实间接路径另行验收。

## 本步限定静态验收

1. 64区间身份/边界逐项等于库存且无已有处置；502B及parts连续覆盖不重叠，62纯90H及两表32B/8目标、2B边界字节和20B后缀全部有证据。
2. 逐字节owner/directxref检查数量等于区间长度，纯填充没有当前owner/直接引用；RET/直接JMP、前后实际函数块与所有邻接身份对照原库存，不将尾块误作新函数。
3. 两表索引×4、cmp3/ja、目标属原父及原只读MOV解码可追；源文件/声明与相邻业务不改。不把静态引用覆盖外推未知间接alias或整父。
4. 64辅助处置、两父语义/网络依据、两open任务、派生看板和唯一进度精确同步；只消本批R7字节分类缺口，不新增业务开发证据、范围排除或关闭完整门禁。
