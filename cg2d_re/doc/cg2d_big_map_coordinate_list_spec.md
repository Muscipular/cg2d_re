# 大地图坐标列表（BMCL01）

状态：指针坐标偏移已按明确要求修改；坐标列表方案待用户确认。

## 已确定要求

- 地图指针旁的坐标文字起点改为鼠标位置(x+24, y+0)，字体和裁剪保持原处理。
- 在“地图选项”文字右侧留10像素后添加“玩家居中”图标及“坐标列表”文字。复用641527/641528/641529三态图标，保持原尺寸；原玩家居中按钮继续保留。
- 列表使用WindowProto的静态预定义子控件，与其他窗口一致，支持滚动和翻页。

## 待确认的具体方案

1. 入口与“地图选项”同一行。位置按现有字体12测量“地图选项”文本右边缘再加10像素确定；图标与文字均可点击。
2. 列表作为大地图内部展开面板，默认收起；再次点击收起。与地图选项面板互斥，避免重叠，切换不改变七类勾选状态。
3. 数据复用当前地图从data/mapdesc.txt加载的标注，跟随七类筛选；按已有坐标顺序展示“地点名称  x, y”。列表不额外按探索状态隐藏记录，越出当前地图边界的坐标不列出。
4. 面板位于入口下方，宽260像素，每屏10行，行高20像素。名称区域裁剪，坐标右对齐，底部显示页码。复用现有滚动条和上下/翻页素材，不导入新图片。
5. 鼠标在列表区域时，滚轮逐行滚动；拖动滚动条调整首行；上一页/下一页各移动10行。到首尾停止，空列表显示“暂无坐标”。
6. 本次列表仅展示和翻阅，不新增点击条目定位或寻路行为。地图原双击寻路、右键改目标保持现状。
7. 列表区域消费鼠标事件，避免点击或滚动穿透到地图。换地图及调整类别筛选时重置列表首行；关闭大地图后随窗口释放。
