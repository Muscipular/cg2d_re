## 适配原则

- 参数继续使用原参考的 `GetCommandLineA`、`strstr`／`sscanf`，不增加尺寸钳制、白名单或异常输入拒绝。正常尺寸沿本线既有资源／SDK失败处理；不据此宣称异常输入兼容。
- 布局复用现有存储；重复窗口初始化按尺寸增量更新，避免在本线重建链累加平移。新增辅助类型及函数仅承载上述业务，不生成虚假的 IDA 地址。
- WIC／ARGB、索引色转 Alpha 和 SDL 混合属于已选业务差异；原 x86／DX 机器接口由本线原生实现承接。具体缓存键、释放时点、源坐标方向和分支接线在实施前继续核对原文并记录。

### R02 接线裁决

原分辨率初始化借 `WndInit` 执行。新端在首次 `InitializeWindow` 创建窗口之前解析原进程参数，随后重建窗口复用已发布尺寸，窗口原型只适配一次，避免重复比例缩放；不新增运行期分辨率修改入口。仅在本次 `/width:` 与 `/height:` 扫描结果同时非零时适配 71 槽窗口原型／保存坐标，保留参考门禁及共享 36／37 原型的遍历写序。

CPU 尺寸改为查询现有 gWindowWidth／gWindowHeight，行距和容量由实际宽高计算；退休无人消费的固定数组别名和常量断言。Back 仍多分配一个像素，缓存面调用保留原 S16 尺寸边界。SDL 呈现与鼠标换算采用相同逻辑尺寸，避免自定义窗口仍映射回 640×480。

地图投影／逆投影使用宽高整数二等分，明确裁剪点使用宽＋32／高＋24、对象宽高与鼠标高－24；窗口随机越界恢复只替换界限／20 像素余量，RNG 调用及顺序保持。指定战斗平铺、指令位置、倒计时图标坐标与上下扫描线转场采用尺寸；参考修改的四个 F32 全屏阈值也对应替换，其他转场行数组和 R09 算法不迁入。

对话创建沿 S16 坐标调用边界先适配，特殊 (32,12,576,432) 对话直接居中；战斗指令 (299,69) 复用同轴规则。开启日志时输出参考的尺寸及对话前后坐标。阵位和背景缩放、倒计时文字实测居中留到下一步 R03。

R02 只读 IDA 9.4 核对补充：0x54D47C／0x54D484／0x54F65C／0x54F664 的完整引用包括 40B5E0、416AB0 动作界限，440C50 观察投影、WIN_PROC 输入换算与 51D790／51E0D0 阈值；原 51DE35 写入 480 为指令立即数，保留该写入，仅比较阈值采用高度。0x55DA80／84 分别由 46CE30／46CE80 使用整数加／减，已接宽高整数中心。实际数据库只读，不改注释／名称／布局，不加载其他副本。

R02 已实施：两参数、动态 CPU 容量／行距／缓存／呈现、同尺寸鼠标、地图中心与指定裁剪／动作阈值、71 槽布局／随机恢复、对话位置及指定战斗 UI 已接现有入口。参考以 DX 后端强制窗口模式，本线未迁 R01；为保证选定尺寸在既有模式下传到物理窗口，WndInit 及对应窗口消息的固定客户区回退也采用当前尺寸。仅完成静态核对；完整 R09 转场仍未迁入，其 480 行数组及未选布局仍保留，不能将本步称作所有分辨率下全转场验收。

### R03 接线裁决

22 项既有阵位表改为可写，四个坐标沿参考按本次中心偏移减上次偏移的增量更新，窗口初始化调用；不逐消费者另加偏移。战斗背景仍先借原 DrawGraphic(320,240) 生产记录，只将这一条原背景入口标为扩展批次 15；按参考组装完整源纹理，再以窗口宽高绘制到 (0,0)，保留源裁剪、色调／独立调色板／混合及队列层序。

完整背景缓存保留原图号、源尺寸、资源色表标记对应的调色板／版本、独立色表索引及 mixFlags 刷新条件；仅全节点上传／复制成功后发布键。缓存独立持有 CPU 纹理，重建不借用已释放的 Back／节点面；替换释放旧面，退出由局部静态 RAII 持有者释放。复制按源实际行距逐行完成，不受色键／Alpha 混合影响。倒计时图标坐标已在 R02 接尺寸；回合文字沿现有宽字符字体测量，测量非正时回退字宽乘长度，再按实际宽度居中，数值／声音／协议及期限保持。

R03 已实施：原 22 项阵位表四坐标统一增量调整；唯一战斗背景生产点接扩展批次 15，完整背景缓存由原节点上传组装后按窗口尺寸缩放，裁剪／色表刷新条件沿参考；回合文字按实际度量居中，回退长度按本线 GBK 字节数承接参考 strlen。主队列排序规则与原 0–12 消费、倒计时业务保持。完整源缓存采用本线纹理引用持有者，逐行复制保留全部四通道；后续 R04／R05 在同一上传与绘制链补 PNG／Alpha。仅静态，未作画面／退出运行验收。

R03 后续静态接线核对发现：旧 RenderTexture 使用 renderer 的节点纹理宽高作为 UV 分母，不能承接完整背景面。已沿参考 PNG 绘制的实际纹理尺寸新增 render 内部 RenderImageTexture，共用既有四顶点提交／裁剪／混合，以完整面实际宽高归一化 UV；不使用旧节点缩放中的额外 1 像素扩边。该入口也供下一步外部 PNG 消费使用，不改原节点绘制。
