## 字段与复用边界

空记录在 `0x45F109` 检查后直接返回 0。非空路径严格按以下顺序各读取一个
signed W32：

| 顺序 | 偏移 | 用途 |
|---:|---:|---|
| 1 | `+0x04` | Y / top |
| 2 | `+0x00` | X / left |
| 3 | `+0x0C` | height |
| 4 | `+0x08` | width |

共享实现使用既有 `ReadRecordW32` 逐项 `memcpy` 读取，避免未对齐和严格别名
未定义行为。随后构造零初始化的 `login::LoginSceneControl32`，只映射
`top/left/height/width`；其 `drawX/drawY/normalImageNo/activeImageNo` 保持 0，
调用唯一 `login::QueryLoginControlState_5036F0` 并原样返回。

命中矩形 W32 回绕、`Sub_5049A0(...,-1)`、三个鼠标全局低字节快照和位打包均
由该既有入口完成；本函数不复制命中测试、鼠标状态或打包逻辑。

## 九位返回位图

未命中返回 0；命中后先置基础位 `0x040`，再按既有共享鼠标快照累计：

| 来源 | 返回位 |
|---|---:|
| `edge & 0x01` | `0x001` |
| `held & 0x01` | `0x002` |
| `edge & 0x02` | `0x004` |
| `held & 0x02` | `0x008` |
| `pulse & 0x01` | `0x010` |
| `pulse & 0x02` | `0x020` |
| 命中基础位 | `0x040` |
| `edge & 0x10` | `0x080` |
| `edge & 0x20` | `0x100` |

`edge/held/pulse` 分别复用 `0xD68D9C/0xD68D98/0xD68DA0` 的唯一共享存储，
本函数不写入或初始化它们。三项位于 `.data` 的无文件后备虚拟尾部，均由 PE
装载器零填充；IDA 对该区域返回的 `0xFF` 占位字节不是文件初值。若新端启动时的
共享鼠标初值或重置时点仍与原启动链存在差异，应由未来启动接线收口，不能在本
函数内补清零、固定值或额外门禁。

## 新增旧页面的点击来源纠正 SPEC（2026-10-02）

本轮板块核对发现，近期新增五个页面的直接行点击错误读取D68D98：
该槽是heldButtons，原指令读取的gMouseClickState实际地址为D68D9C，即edgeButtons。
已有QueryLoginControlState_5036F0的九位打包本身正确。按原合同修正直接消费点，
不改变业务设计，不新增输入过滤或按键状态：

| 新端函数 | 原读取证据 | 修正范围 |
|---|---|---|
| 4F7150旧20列表 | 4F73D9取D68D9C低字节 | 左/右键共用的局部快照来源 |
| 4D7470旧58目录 | 4D7677 test byte[D68D9C],1 | 行选择左键来源 |
| 4D7C20旧59候选 | 4D8113 test byte[D68D9C],1 | 行选择左键来源 |
| 4D8230旧60技能槽 | 4D8810 test byte[D68D9C],1 | 槽选择左键来源 |

该修正避免把持续按住误当点击边沿；当前不运行，不能声称交互回归通过。

同时确认45EFD0的45EFD7/45EFDA、45F100的45F107/45F109原有空记录门禁，
现有两处空记录保护应保留，未移除。

本轮为选择下一板块做的词法定位：旧表99记录含97个非零入口，六个未定位本体
为旧19、7、8、62、85、98；其中7/8属暂缓音频，其余为既有待决。
非键盘私有Dependencies头的564个地址后缀名字未定位三项：
50E680、403E50、4626A0；扩大到src/include头共2664个地址后缀名字，
另有4F7870、52C3D0、424620。这些仅是名字定位，不证明命名空间、完整依赖、
非地址函数、数据定义、链接或语义验收；无参4626A0亦不等于已实现的显式门禁版本。
