# 旧地图面板

此处选择编号1来自57C368旧表，不是窗口主表window id1。
公共合同见[旧面板运行期](shared_legacy_panels.md)。

## 方案与边界

2026-10-01按既有工程委托完整实现502930跳转入口、502940构造及5029B0面板。
运行期D68868采用既有LegacyPanelRecord，初始全零，归LegacyUiRecord.cpp私有owner；
原页签指针字段按原生宽度，构造尾部按字段清空，不对新结构硬套原156B memset。
默认位置57CB24为S32初值392、D67AD4为独立未加载区S32初值0，
当前两者只有502940读取；57CB24另作99行旧表的区间终点，不把它并入第100行。

原CRT槽5530C8指向502930，该入口唯一指令尾跳502940。
新端复用LegacyMouse.cpp现有顺序静态初始化机制，将该项放在已实现的
55309C/5530A0两个选择器之后、5530F8鼠标之前。保持已实现项相对顺序，
不为尚未实现的5530C4/5530CC等邻项填空体，也不据此宣称完整CRT初始化已齐。
该构造无RNG/分配/析构注册，不新增退出清理或首次使用懒初始化。

地图名称、玩家X/Y CryptInt、C8A780/C8A77C许可和D046C0命中编号
均复用既有owner，地图绘制使用真实521AA0队列入口，不复制地图状态或画面数据。
本步只实现旧面板及已证构造接线；5029B0的上层分派仍须证据，
不按57C368中的handlerToken猜造99项调用，不降低整体验收。

## 构造合同

502930..502935为单条尾跳；502940..5029A9共20条指令，无call。
先各读一次默认X/Y，再依原写序更新：
background[1]=0、x、background[2]=0、y、background[3]=0、
width=248、height=220、id=1、background[0]=22535、background[4]=0，
最后清原+40起156B尾部。新端尾部对应五个页签、selected、hovered、
两保留字节及关闭按钮，各字段清零/空指针，不截断页签提示T*。
最终返回0，不用硬编码构造后实例替代实际CRT调用。

本步将三个入口声明放既有LegacyPanelRuntime.hpp，完整实现仍在LegacyUiRecord.cpp；
LegacyMouse.cpp只增一个5530C8构造器，沿已有顺序注册，不触碰鼠标正文。
原5530C4=4FF340、5530CC=502C30等未落位项仍未接线，不能把相对顺序核对说成全表完成。

## 面板合同

5029B0..502B7E共130条指令。先503160(opened,map,nullptr,1)，
返回0或2时原样透传R32，且不测量/读坐标/绘图/改许可。
其他返回值才进入完整绘制，不使用现代窗口39额外的440B50门禁。

- 名称：先TextMeasure(同源9DAD30,0)，后取面板Y/X，
  在(x-width/2+124,y+36)绘原文本，字体参数(2,0,0)，宽度除2向零。
- 东坐标：原401EA0沿现有401EC0入口仅读取一次玩家X；
  用58AA54原字节格式化到256B局部，再重读面板Y/X，
  在(x+62,y+186)绘字。不得先读取Y或把两坐标合并为快照。
- 南坐标：随后独立读取一次玩家Y，用58AA4C格式，
  重读面板Y/X，在(x+133,y+186)绘字。三处DrawText均至边界取低S16。
- 503590命中关闭按钮时复制55331C提示，否则保持此前提示。
  之后仍按原顺序重新写完整关闭按钮，不省略为“503160已写过”：
  先采width/x，写普通图22509、imageX=x+width-16，
  再采y，写left=x+width-26、top=y+6、imageY=y+16、
  width/height各20、选中图22510。
- 以该次x/y、层212调用521AA0发布地图项，随后503440(map,1)画面板；
  两者返回都不传播。最后重新读D046C0，值为1才先C8A780=1、后C8A77C=1；
  非1不清这些许可。最终返回完整U32命中编号，不固定返回1。
