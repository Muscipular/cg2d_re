## 具名实施裁决

1. 只在既有LegacyIos.cpp添加cstdlib、移除不再使用的LegacyRuntimeExit.hpp，
   将18个RegisterLegacyAtExit表达式直接改std::atexit。无新包装、私有表、
   状态槽/once、owner、cpp/公共类型、CMake或外部依赖。
2. 每项先实际构造，返回弃；完成后立即登记同一固定无参callback，
   直接传出宿主S32。构造异常原样传播，尚未完成时不登记；
   登记失败不回滚构造、不立即清理、不重试或伪造成功。
   原普通空返回等消费及各构造内部失败前缀不改。
3. D03批准由宿主承接登记表、扩容/编码、内部失败时机与返回非零值。
   不把宿主非零规范化成-1，不称原0/-1位型或内部表算法等价。
   唯一直接原表消费不读EAX；未来新调用若消费具体数值须另证，
   不能将本组许可外推到兼容RegisterLegacyAtExit全部62原caller。
4. 全18callback及构造body原文保持：14被动实际流/缓冲、四Init身份、
   原W32计数及U8登记、共享指针/重读、原虚析构/flush、locale/FILE/
   codecvt和各分配域保持。四控制器回调仍独立、每次真实Init对应一次登记，
   不因共享尾合并回调或仅登记一次，不清原槽/新增最终free。
5. 本组不新增模块或调用，不启用旧cinit/CRT根，不将SDK流强转Legacy对象，
   不重复构造同一owner。当前66应用+2 SDK配置投影不变；
   17待接、完整登记容量/较大正常索引和facet真实生产继续开放。
6. 正常宿主退出将调用已登记的本组回调；原quick、callable、异常终止与
   全应用跨组逆序仍须按完整退出合同核。当前不活动这些Init，
   不声称已运行、SDK就绪、实际flush/退出或全寿命闭合。
   原兼容退出表/其ETH01域、其他caller、业务算法不改。
7. 18既有语义只同步当前源提供者，原数字call/表槽/分离chunk和历史来源保持。
   原关联53B406与真实std::atexit同时具名，18变化根记adapted；
   不新增库存身份、升级辅助已审或把原所有caller当已迁。

RPLAN.24异常不专项模拟、不加边界保护/补零/拒绝/限制，
不记x64安全/故障等价；音频暂停、原格式明文及单线程保持。
