# 旧设置主菜单（旧选择编号3）

本页记录旧面板584E70，不是71槽主窗口表的window id 3。
公共记录及交互见[旧面板公共运行期](shared_legacy_panels.md)。

## 本步方案与边界

- 复用`LegacyPanelRecord`与`LegacyPanelTextButtonRecord`，在既有
  `LegacyUiRecord.cpp`中保存面板和八条按钮的唯一可变状态。
  文本、提示及无参S32回调均保存原生指针，不把原地址编号当函数指针。
- `4FC420/4FC430`接原CRT5530A8相对位置，位于5530A4浏览宠物之后、
  已接5530C8地图之前；不为尚缺的中间构造填空体。
- 八个回调和完整`4FC730`一起实现，复用已有选择、保存与公共交互本体。
  旧选择表handler调用路径尚未证实，不新增推测分派，也不把本体完成记作运行接线完成。
- 不改变现代设置窗口24、存档owner、音频实现或两项未批准补零。
  本步仅局部实现记录，不触发总SPEC对齐或日志压缩。

## 原端合同

`4FC420`只有尾跳`4FC430`。构造`4FC430..4FC723`共120条指令，
先读584E74的Y，再读584E70的X，之后不再读取面板坐标、没有调用。
八行共用X+45绘制/X+27命中，Y依次加50、80、110、140、170、200、230、260；
每行宽136、高18，颜色0、原+21字节1、+22字节F9，+23字节未写。
原文中的偏移均为十六进制；新端以`reserved21[0..1]`承接两个写入字节，
不对整记录赋零、不改`reserved21[2]`。返回首次Y快照+260，不固定返回0。

584E70的196B静态原型为：X/Y均0、宽192、高304、id3、首背景22500；
其余背景、页签、选择/悬停、保留字节、关闭按钮全零。
原40B按钮连续覆盖D67D38..D67E77；x64沿用既有56B类型，不以原步长访问。

八回调各七条指令，统一先`5042D0(3)`、再`504180(目标)`，忽略两返回值后返回0。
这使`5030A0`在点击后仍可继续检查其余记录，不能改为返回1或立即结束父绘制。
文本与提示按原有界字节读取，包含终止NUL，不从反编译显示文本重新编码。

`4FC730..4FC7E4`在当前IDA数据库中未归入函数，按已有指令项及分支目标核对，
不修改数据库或猜造函数边界：

1. `503160(opened, &584E70, nullptr, 1)`返回0则直接返回0。
2. 返回2时，按`520470→520590→读取角色S16→520510→520640→5206F0→520200`
   保存；末项原为尾跳，返回其完整W32，不把2透传或改成固定成功。
3. 其他状态调用`5030A0(D67D38,8)`，非零立即透传返回。
4. 否则`503120(D67D38,8)`绘制，再`503590(&584E70)`；
   非零时将55331C关闭提示含NUL复制到既有D68AE8。
5. 最后`503440(&584E70,1)`并返回其W32。

父入口没有重建八条记录，也不把`4FC430`作为`503160`初始化参数；
保留该事实，不为拖动后几何自行增加刷新。面板坐标与关闭按钮仍由公共运行期原位更新。
