## 原表整理行为

原窗口表从 C8B094 到 C8B1B0，共 71 个 x86 指针槽；当前按既有原生指针槽扩大，不用原字节步长索引 native 对象。

空槽向后寻找非空槽，移入并清来源，再处理同一槽；找不到则结束。非空实例先读一个 W32 state，该同一值先判 bit15（8000），未关闭时再判 bit13（2000）。关闭命中调用完整释放函数，之后将后续槽逐个左移、清最后槽，继续处理当前位置。关闭对象不计入返回数量。

重排标记命中时，保留原实例指针，按前项 layer 的 S32 比较前插：前项 layer 小于当前实例 layer 即停止，否则后移；相等也后移。每轮现场读取当前实例 layer，不冻结比较值。写回原实例后重新读取其 W32 state，只清 bit13，随后计数。非重排实例只计数。原排序标记、关闭标记、等层行为和返回 S32 数量均保持。

当前正文两次读取 state 分别作上述分支；改为在原读取位置保存一个 W32 state，并由它作两个判定。重排完成后的清位仍通过实例现场读写，不复用早期 state。空槽压紧、释放后的重读与移动、等层前插和数量循环均不改。

## 原直接关闭行为与工程边界

472160 从实参实例读取 id，计算原 54H 状态记录地址，发布到全局当前状态指针，再通过刚保存的同一记录地址将 flags 置 bit1，最后调用 471270。它不清窗口表槽；唯一原调用父 472190 负责随后清槽，已有完整 BVR01 合同保持。

当前正文发布全局指针后，重读全局指针写 flags。改为保存真实 detail::WindowState*，发布该地址，再通过同一保存地址写 flags；不另造记录或镜像 owner。记录地址沿既有 x64 类型计算，flags 仍为 W32，不冻结原 54H native 布局；指针不逃逸到新接口。公开 void 声明保持，原调用父已证弃返回，机器 ABI 仍未验。

两逻辑组、三处访问对齐：整理根的两状态判定共用原样本；直接关闭的全局发布与 flags 写共用原记录地址。两定义和两实际声明共四条关联注释。仅现有 CPP 和两个头文件，不新增类型、字段、API、helper、owner、分配或释放方法，不影响已有完整创建、释放和更新正文。

原空槽/状态分支和循环退出保持，不补新保护、默认值、补零、钳制、容量限制、回滚、异常或溢出模型。清槽和清 bit13 均是原业务行为，不增加新的失败模拟。
