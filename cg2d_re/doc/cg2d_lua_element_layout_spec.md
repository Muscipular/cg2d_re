# Lua元素默认顺序与文本框语义（LEL01）

状态：用户回复“y”同意合并修订SPEC；方向已确认，本次记录具体规则，尚未修改引擎实现。对齐编号、零尺寸及裁剪细则为本方案建议，不冒称旧接口已有行为。

## 1. 目标与覆盖范围

LuaUI后添加的元素默认置前；AddText采用左上角文本框语义。公共几何继续归WindowElement，文本布局选项归WindowElementData.text指向的WindowTextData。

实施后覆盖[NEU01](cg2d_native_element_unification_spec.md)中Lua元素默认max+1追加、Lua文本直接采用原生锚点的两项约定。单一元素对象、原生排序/分发链、稳定身份、遍历上限和安全点回收继续保持；不恢复UIControl及components。

## 2. Lua新增元素默认置前

- LuaWindow::AddControl共用创建入口：空窗口默认seqNo为0；否则取当前窗口有效元素最小seqNo减1。所有Lua Add系列统一，包含添加到原生窗口和滚动容器的元素。
- 显式seqNo优先，原生原型及背包分页的序号不变；仍按(seqNo, elementId)排序，较小值先命中，在当前同层绘制队列中位于前方。
- 不增加独立序号计数器，不重排或重编号已有元素。更高/更低渲染层级仍受现有图层规则约束，“默认置前”不跨越图层。
- 创建后用Set或属性赋值调整seqNo仍沿notifyUpdate规则；遍历期间禁止重排的限制不变。

示例：先创建背景，再创建按钮、文字，默认按钮和文字在背景之前；hitable=false的文字不拦截按钮事件。

## 3. AddText文本框规则

| 属性 | 拟采用含义 |
| --- | --- |
| x、y | 相对窗口或父容器内容区的文本框左上角。 |
| width、height | 文本框尺寸，不从x/y中扣除，不因文本变化自动回写。 |
| text、font/fontType、color | 继续读写实际文本载荷；测量与绘制使用同一字体。 |
| align | 建议0左对齐、1水平居中、2右对齐；默认0，垂直方向仍顶对齐。 |
| hitable | 保留AddText默认false；显式开启时按文本框几何及父裁剪命中。 |

创建、Set批量更新、直接属性赋值和读取使用同一语义。改变宽高只改变布局范围，不移动左上角；修改text、font或align后按最新数据重新布局。不能只在AddText创建时对坐标加宽高，否则后续属性更新仍会错位。

建议以实际文本宽度T计算水平起点：左对齐为x，居中为x+(width-T)/2，右对齐为x+width-T；整数定位沿当前渲染坐标规则。y保持文本框顶边。

### 尺寸与裁剪

- 正数width/height形成该轴的文本框裁剪范围，并与滚动容器裁剪相交；对齐先按完整文本测量，再裁剪可见内容。
- 保留现有省略宽高、默认0的调用方式：0尺寸不限制该轴的自身显示范围；width为0时按左对齐起点绘制。只是不加该轴自身裁剪，不取消父容器裁剪。
- 命中仍使用声明的元素矩形，零尺寸不自动扩成可点击区域。
- 沿现有文本入口与裁剪能力实现，不新增自动换行、省略号、富文本或颜色转义；不把完整字形裁剪宣称为逐像素裁剪。

## 4. 原生文本与载荷

WindowTextData保留style/text前缀，增加明确的文本布局类型和对齐字段：原生锚点布局作为默认，文本框布局由Lua AddText显式选择。布局类型表达文本功能，不增加isLua之类的来源标记，不按owner窗口类别猜测布局。

- 原生原型创建的Text仍按(x-width, y-height)绘制；由Lua取得原生元素引用不会隐式切换布局。
- Lua创建的Text即使挂在原生窗口中，仍使用文本框布局；几何字段不保存另一份坐标副本。
- align在文本框布局中生效，并在创建、Set、直接赋值和读回中接入真实载荷，不落入自定义properties。
- 对原生锚点文本设置align不能默默存成无效属性或偷偷改布局；建议明确报告该布局不支持对齐。布局类型不新增为Lua可写的模式切换接口。
- 核对所有WindowTextData聚合初始化、new/delete及宿主布局依赖；新增字段默认值必须保证既有原生文本不变。

## 5. 边栏迁移

实施默认置前后，移除运行目录边栏.lua中本次补入的手动背景seqNo调整，依创建顺序自然获得按钮优先、背景在后的效果。保留关闭和创建时重置跟随状态的修复。

现有AddText坐标按左上角解释，不再让脚本补偿宽高偏移；align=1按本方案的居中规则生效。只同步本次已确认的边栏，不批量重写其他业务脚本；已有自行补偿坐标或依赖默认追加顺序的脚本需单独检查。
