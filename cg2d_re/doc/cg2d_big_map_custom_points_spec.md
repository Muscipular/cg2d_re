# 大地图自定坐标接入（BMP01）

2026-10-25，用户要求参考已打开的cg4.06cn.exe，接入mappoint.dat加载、新增、修改、删除。依据本线AGENTS.md第8条工程委托，按以下取证结果裁决实现；覆盖BMUI01中mappoint.dat暂不接入的旧范围，不扩大七类标注或网络功能。

## 原端证据

分析仅使用现有cg4.06cn.exe的IDA MCP，串行只读，无数据库修改。所有下列地址属于4.06，不能当作cg2d.exe原函数地址。

| 地址 | 已确认行为 |
| --- | --- |
| 47D9F0、43995D | 使用工作目录下data/mappoint.dat |
| 4399B8、4399F0、4399FE、439A26..439A2E | 清0xA00字节；逐条读0x28字节，按当前地图号过滤，+04覆写为从1开始的全文件物理记录序号；最多64条，含无效条目 |
| 43921B..439290、47DB8C | 有效记录填原名称，空槽默认“自定坐标%d”；名称输入参数20 |
| 439597..4395B1、4395F3..43960D | 保存写W16有效标志1、地图号W32、坐标W16；坐标需位于地图内，名称字节长度大于1且小于20 |
| 4394C0、4397BC..439805 | 删除只清W16有效标志；已有物理序号按40*(序号-1)定位，否则追加文件尾；写回40字节 |
| 439B30..439C62、43A18F..43A1AA | 有效项显示名称并可选择寻路，空项保留设置入口；选项可进入编辑 |

记录布局由读写指令及已有BMUI01数据证据共同核对，工程中加布局断言：

| 偏移 | 类型 | 内容 |
| --- | --- | --- |
| +00 | U16 | 有效标志，零为删除/空项 |
| +02 | 2字节 | 未证用途，加载/写回保留 |
| +04 | U32 | 加载时覆写为全文件记录序号；零表示未落盘 |
| +08 | char[24] | GBK名称，读取限定字段范围 |
| +20 | S32 | 地图号，对应gMapFloor |
| +24、+26 | S16 | X、Y格坐标 |

## 实施合同

1. 当前大地图增加“自定坐标”入口，与原“坐标列表”共用十行、滚轮、滚动条、翻页及单击定位/双击寻路。两个来源互斥：原入口仍显示mapdesc.txt七类标注，新入口只显示mappoint.dat有效项，不把有效标志误作类别。选中自定点后可修改或删除；新增使用本地图第一个无效/空槽。
2. 首次打开、换地图或重载时读取本地图最多64个物理记录，含删除记录。保留原文件顺序及物理序号，同坐标不合并。七类筛选只作用mapdesc.txt，自定点不受七类筛选影响；选择后沿原目标标记展示，不额外混入七类地图绘制。
3. 编辑面板使用当前原生窗口元素与已有输入上下文，允许编辑名称和X/Y。新增默认取已选目标，否则玩家坐标，名称使用“自定坐标N”；可保存或取消。名称编辑可装入原字段23字节正文，提交仍检查2～19个GBK字节，避免载入旧长名称时静默截断。坐标沿当前地图尺寸校验。输入失败或文件读写失败明确提示，不伪装保存成功。
4. 保存只写目标一条40字节记录；已加载记录按物理序号覆盖，新空槽追加。删除仅清有效标志，保留名称、坐标、保留字节及物理位置，后续新增可复用本地图删除槽。禁止压缩/重排文件、整文件覆盖或改写其他地图记录。
5. 文件缺失按空列表处理，在第一次实际保存时创建；区别于原端打开列表即创建。已有文件打开失败不以wb覆盖。写入和关闭均成功才发布内存变更；这是本线明确的文件失败处理，保留原磁盘格式，不照搬失败后无效句柄及提前发布内存的行为。
6. 编辑面板前景元素优先消费鼠标，遮挡区域不触发地图平移/选点；输入关闭、切换来源、换地图、关闭窗口及离开普通场景时释放焦点并恢复原输入。新增元素使用固定ID和独立前景顺序，旧控件ID及邻接滚动条关系保持。
7. 内部名称继续宽文本，仅文件边界GBK；源码/文档显式UTF-8。复用当前资源、输入、字体和Copilot，不加依赖、不迁移4.06快捷键/寻路算法、不修改原客户端及用户实际数据文件。

## 静态验证及剩余验收

- 核对40字节记录布局、64槽边界、物理序号、按条更新/追加/软删除、保留字段及其他地图写入隔离。
- 核对两个列表来源、切换/重载时借用指针失效、编辑显隐、鼠标顺序、输入焦点及释放、保存失败反馈。
- 严格UTF-8读取及Git差异检查；用户本轮追加授权build.bat Debug配置、编译和链接，不测试、不运行客户端、不计算摘要。
- 实际加载既有文件、修改后重开、删除后重用、新增到另一地图、界面显示和寻路仍需运行验收，静态核对不替代该验收。

## 实施说明

- 实现集中在WindowBigMap.cpp，原95项元素原样保留，新控件固定ID96～117，以seqNo=-2排在原列表和地图事件之前；三个自有输入上下文由既有元素载荷析构释放，关闭编辑时先解除焦点。
- 新增“自定坐标”入口及新增/修改/删除/重载按钮，编辑面板复用既有九宫格、输入绘制及GBK边界。自定列表按文件顺序显示有效项，超出当前地图的旧坐标可选中修改/删除，但不能用于寻路。
- 写入或关闭失败时不发布成功状态，并要求重载后继续编辑，避免未知写入结果后再次追加。保留本地图删除槽的物理序号和其他字段，新增优先复用该槽；新记录仍按原端写零物理序号，成功追加后仅内存记录真实位置，下次加载重新赋序号。
- 117个元素ID唯一，旧95项ID及顺序、滚动条邻接和三个新输入的焦点/释放路径已静态核对。按用户追加授权执行build.bat Debug，配置、编译和链接通过，退出码0；不运行客户端或测试，实际文件操作和交互仍待运行验收。
