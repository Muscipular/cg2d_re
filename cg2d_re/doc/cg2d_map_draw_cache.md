## 生产和挂接

1. `46BD60` 仅以 signed count>=1024 返回 -1；逐字段写图号、
   F32 位型、S16 坐标、将第六参数布尔化为批次 0/1，再写原索引。
   描述符有源时按四个 W32 顺序复制；空源按 x/y/w/h/color/clip/mix/palette
   分别写 0/0/0/0/FFFFFFFF/0/0/0。清两链接后发布 count+1，返回旧 count。
2. `46BE50` 先查 mapNo：1 调 46BD60，强制 mode=0、descriptor=null；
   <=999 的其他值不入队。>999 再查 flag2 的低 W16，等于 3 选特殊表，
   否则普通表；各自 signed count 门禁，写批次0、描述符、清链接后发布计数。
3. `46DFF0` 直接写普通表，不查图号/flag2，不清 pre/next。
   有描述符时先复制前三个 W32、读第四个，再发布 count+1、最后写第四个；
   空描述符在全部默认字段之后发布。不能复用带清链/不同发布顺序的生产者。
4. `46C060` 仅拒绝负主索引和 signed 挂件计数>=1024；
   第二参数非零沿 pre，零沿 next，先把链尾指向旧计数项，
   再重读挂件计数确定写入项。图号先写，随后读取主项世界 X/Y，
   再写目标 X/Y、S16 坐标、原低 W8 批次、主索引、描述符、空双链接、计数。
   不新增主索引上界、负计数或空链保护。

## 比较和排序

`46C300` 两个世界 X-Y 差先经 F64 运算落 F32，再调用
GetGraphicSxSy→GetGraphicMapNo。mapNo=1 或占地恰为1×1时，
第一差严格大于第二差才返回1；unordered 返回0。
其他情况先比较世界 X，再按短路读取世界 Y，最后按 S16 屏幕 X
选择占地 sx/sy 的 `(48-48*n)/2` 阈值，等屏幕 X 则直接比屏幕 Y。
保留 x87 C0/C3 的 unordered 路径，不用总序排序或额外 NaN 拒绝。

`46C440` 排序差值不落 F32，而按 PC53/F64 比较：
小于或 unordered 返回 -1，大于返回1；平差后按原世界 X/Y、
第二项批次、第一项批次和 signed 原索引决定 -1/1，**从不返回0**。
同位置且两个批次非零时比较不对称，不能假定可换成 std::sort、
stable_sort 或不同 CRT 的 qsort 而仍保留原比较/交换序列。

因此只读补核原 `_qsort@53C112`、`shortsort@53C266`、
`swap@53C2B4` 的完整指令，在本文件实现此表专用的原算法：
长度<=8 逐轮找最大值换到尾；其余中点换首，以首为 pivot，
左扫描 <=0、右扫描 >=0，再交换并分区，使用原 30 槽显式栈。
两分区选择原按字节差的 `leftBytes-1 >= rightBytes`；
按元素差等价为 `leftElements > rightElements`，不因记录改64B改变选择。
按完整新记录交换，链接值随记录移动，但目标始终是未排序的挂件数组。
本适配不替换其他模块 qsort，也不声称旧 CRT 通用重建完成。

## 合并与提交

- `46C2F0` 严格先排序再 `46C4D0`；两处原 caller 均弃返回，
  后者混用计数值/尾地址的 EAX 不发布为 x64 假指针，使用 void 私有边界。
- 合并不排序普通对象表。逐个比较主项与当前普通项；需先输出主项时，
  先查 mapNo，仅非1才复制到合并表。继续检查相邻主项世界 X/Y 的 C3，
  相等或 unordered 都归同组，X不命中不读Y；原先读下一项再检查计数，
  包括最后项与残留下一项比较的次序不改，不额外补哨兵或检查。
- 主项先发布合并计数再复制；首个命中普通项同样先发布后复制，
  后续连续命中的普通项则先复制后发布；保留外层额外递增和内部回退。
  主项耗尽时按剩余普通数整段前向复制后发布；再补剩余非 mapNo=1 主项。
  最后只在合并数<3072 时追加特殊表，每项重读其计数，末尾一次发布。
- `46C1C0` 动态读取合并计数，逐项按 pre 链→主项→next 链提交。
  每次都读取**主项** descriptor.clip 是否精确为1来选 DrawGraphic3/2，
  挂件使用自身 batch/图号/描述符，主项 batch固定0，layer固定10。
  先读 batch/图号，再Y/X，调用后才取下一指针；不清队列或链。

本步只做指令、接口、布局断言、接线、编码与差异静态核对；
不构建、不测试、不运行客户端。异常越界/溢出按 RPLAN.24 不专项模拟、
