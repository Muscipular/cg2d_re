# sub_52B990 还原证据

## 范围与调用关系

- 当前 IDA 实例为 `ida-17524/cg2d.exe`。原函数范围为
  `[0x52B990, 0x52B9D8)`，原型为 `unsigned int __cdecl(void)`，共 19 条指令、
  4 个基本块且无被调函数。
- 函数共有 10 个原始代码交叉引用：`0x43D226`、`0x43D352`、
  `0x440FE5`、`0x45EF38`、`0x45FF96`、`0x461618`、`0x463B9B`、
  `0x51C5FA`、`0x51C6A1`、`0x52C967`。这些调用点均丢弃返回值。
- 当前 x64 还原把唯一声明放在 `cg::audio`；登录、角色选择和 World 的
  依赖头仅以 `using cg::audio::Sub_52B990` 保留原 `detail::Sub_52B990()`
  调用表达式。

记录只确认 `+0x00` 为 `int32_t value00`，其余 `0x48` 字节保持 opaque。
`sub_524230` 在 `0x52B561` 每轮令 `ebx += 0x4C`，并在 `0x52B567`
以 `ebx < 0x2600` 继续循环，因此容量严格闭合为 128 项。`value00` 可追溯到
`bgm.cf` 的第四个十进制字段；现有证据不足以赋予它进一步的业务名称。

## 精确行为

1. 只采样一次索引。若索引小于 0，或其 W32 无符号值大于等于 128，则只按
   W32 位型返回该索引；不读记录表和音乐音量，也不写 flag 或商状态。
2. 有效路径先把 flag 写为 1，再读取 `table[index].value00`，随后读取
   `cg::platform::gMusicVolume`。
3. 两个 `int32_t` 操作数先按原 W32 位型转为 `uint32_t`，无符号相乘得到
   模 `2^32` 的 `productBits`；再把相同位型解释为 `int32_t product`，避免
   C++ 有符号乘法溢出的未定义行为。
4. 商状态写为 `product / 15`，遵循 C++ 有符号除法向零截断；返回
   `productBits >> 31`。

## 尚未还原的生产者

本项只建立上述状态的唯一 x64 所有者与 `sub_52B990` 消费路径，不实现索引、
记录表、flag 或商状态的其他生产者/消费者。原表装载路径 `sub_524230`、
索引更新路径及其他音频状态路径仍须按各自函数另行取证后接入；当前不得用
占位生产者、固定值或未经证实的业务字段补齐它们。
