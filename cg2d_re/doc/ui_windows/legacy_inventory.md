## 使用与拖放

先采鼠标低U8。悬停>=0且bit10优先：
used且canUseInField低bit0才使用。图26569依序写C8B388=0、
C8A96C=悬停、CF4AA8=(slot-8)%5、D2D614=(slot-8)/5，再打开79；
该分支不重置拖动、不播放SE。其他可用物品读玩家Y/X，
510A00(socket,x,y,slot,0)→SE77→4FB8F0→CB01EC=slot。
不可用SE55后重置拖动，不写CB01EC。

无上述直接使用时，先快照当前拖动编号：
- 编号负：有效used悬停且bit1先写图号、编号、模式1，再SE51；
  否则bit2按物品pages循环详情页。无used或无悬停不重置。
- 已拖动且有效悬停/bit1：模式1且来源不同，先读D67AE8再读Ctrl[17]；
  模式0反转Ctrl低字节后取bit1。来源/目标>=8、来源count>0、目标未used、
  该bit非零才发布拆分三槽并按焦点打开16；不添加数量1特判。
  其他条件走完整移动，但5F9754非零且任一槽7时不发送；
  允许才510EC0(socket,source,target,0)和SE51。
  同槽不发送且无音效。模式2且目标used时读Y/X，
  510A00(socket,x,y,source,target)和SE77。各路之后均重置拖动。
- 否则鼠标事件状态D68DB4的**低U8**<212且bit1：
  模式1才读Y/X并510CE0(socket,x,y,0,source)，但其他模式也重置。
  再否则bit2重置，无两类点击保持拖动。

拖图号非零才读鼠标X并发布CC4880，再读Y，重读图号后发布CC4884；
图号仍非零时重取X，以层221绘图。不能改成Y先读或只保留一次图号采样。
