不登记部分元素或占位按钮，不称37元素及编辑/提交交互完成。

按既有委托采用以下局部方案，不触发总SPEC对齐或日志压缩：

- 玩家name/level/titleIndex/ownTitle继续借SceneState既有owner，
  原称号表FF0508及排序表DE03F8继续共用既有TitleRecord。
  不重新排序、不复制列表快照、不以编号有效性过滤六行。
- 草稿D45FC0用256B原字节数组，CF4E54用独立S32页起点；
  InputContext D2DC10由Input唯一持有，UI原型57CCB8以原生非拥有T*借用。
- 输入原型沿既有WindowInputPrototype表示；编辑分支取原型当时的
  context->text，不改成直接读固定D2DC10，也不误读原型内嵌初始化文本。
- 只比较原字节是否相等，使用strcmp零/非零结果；不做大小写折叠、
  locale或Unicode转换。两次比较分别执行，不缓存第一次结果。
- 所有复制包含NUL且不增加截断；保留各次current window/elements/data
  的快照与重取。页索引、文本异常按RPLAN.24，不增加范围保护。
- 释放采用既有void签名；主更新保留S32参数，-1初始化，公共尾返回1。
  刷新原返回无人消费，采用void，不固定伪造有效原返回值。
