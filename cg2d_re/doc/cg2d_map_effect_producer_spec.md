# MFP01 效果记录生产取样与正常固定点

<a id="map-effect-producer-baseline"></a>
## 缺口与原生产链

[场景合同§20.6](cg2d_scene_state.md)已有46F090载荷生产。当前源码镜像X/Y及转固定点使用先前局部值，遗漏原记录读取点；固定点初值仍用U32左移16承载有符号坐标。沿[MFA01](cg2d_map_effect_arithmetic_spec.md)已落的正常S32固定点合同，本步补回真实取样并恢复正常缩放，不改原记录位型。

[原证据](cg2d_map_effect_producer_evidence.json)保存原[46F090,46F151)完整64条193B、三直接call/一个父46F1D0；三调用局部窗复用MFA01已存原体，不重新核整个父。原46F090先领取，失败返回空且不写载荷/计数；成功写kind低W16，再按三个参数作signed余数及镜像：

- 46F0B4..46F0DB：verticalSign为0则phase%880+1040，否则horizontalSign非0取phase%1920，为0取phase%1040。
- 46F0E3/46F0E9先写X/Y=-400；offset<1040写X=offset-400，否则写Y=offset-1440。
- horizontalSign<0时46F109重读[record+00]、46F110作240-X、46F112写X；verticalSign<0时46F11B重读[+04]、46F123作80-Y、46F125写Y。两判断及读写不合并。
- 46F128/46F12A依序再读记录X/Y；46F12D/46F130缩放16位，46F133/46F13A写固定点+08/+0C，再写speed/graphicIndex原W32、独立计数C8A756加W16一，返回领取指针。

有符号余数的绝对值小于正除数；由上述分支直接推得镜像后正常X在[-2319,2559]、Y在[-400,480]，乘65536可由S32表示。这是原表达式的静态数域推导，不是新增输入范围/运行采样/异常承诺，不限制phase或符号实参。

## 委托裁决与实现

1. 仅SceneState.cpp/Sub_46F090三处片段：两负符号镜像分别重读实际字段W32解释S32后作原减法；固定点块先依X→Y读取当前字段，再作两次S32×65536，按X→Y写真实W32位型。共补四读取点（两条件、两无条件），不换负S32左移或扩大数值为S64。
2. 领取及失败返回、kind写点、signed余数三分支、两-400先写、offset条件写、两镜像分支顺序、speed/graphicIndex原位型、W16共享计数和指针返回保持。不清未知字段、不新建记录owner或补偿释放，不改调用者/RNG/动作创建。
3. 新端仍以MapEffectRecord*承载既有唯一池；公开前置声明和签名不改，记录布局及非地址宽度不变。MFA01/MCA01消费本体、原专用x87和三caller保持。三caller均弃返回的既有事实不外推所有间接alias。
4. 一个既有生产本体补正式原身份/来源及adapted分类，仅本次取样/缩放局部和生产合同静态；完整池/调度/所有调用实参和间接alias、完整owner重进退出/借用失效、实际ABI/SDK/图像和RNG运行未闭。
5. 依RPLAN.24，数学溢出/越界不专项保护、拒绝、补零、钳制、回绕或故障模拟，不宣称异常安全/故障等价。不外推一般坐标缩放、网络格式或音频。
