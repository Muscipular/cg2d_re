# 大地图交互与独立底图方案（BMUI02，B方案已确认）

2026-10-19。用户提出优化交互，或按4.06独立实现地图生成。用户随后选择B，已授权独立生成及交互优化，覆盖BMUI01仅复用MapEx的底图边界。

## 现状与原端证据

- 当前BigMapWindow直接使用UIMapExControl。底图根据自动地图颜色表绘制小菱形，投影为X=2×(格X+格Y)、Y=格Y−格X；不是实际地砖和物件的缩略画面。
- MapEx采用128×64像素分块，每3帧生成1块。大视口首次打开及拖到未缓存位置时，会逐块补齐；地图边界外和空数据也显示黑色，单张截图不能区分全部原因。
- 当前拖动反算整格坐标，存在量化；按钮在选项栏展开时缺少寻路/居中文字说明。已有唯一入口、七类筛选、右键目标、现有Copilot和外部GBK标注继续适用。
- 4.06@4376E6消费实际地砖、物件图形编号、尺寸、偏移和排序分支，生成640×480局部地图画面。基本投影步长为32、24，比例4:3，与MapEx的2:1不同。
- 4.06@413102按10格步进扫描候选区域，比较两份地图层摘要的异或结果；调用43766E/4376E6后，将局部画面缩小、拼入大地图纹理，成功更新一处后返回。不能把原端描述成一次生成整张地图。
- 4.06@412B49按地图尺寸选择缩小除数：宽≤64且高≤48取4；否则宽≤256且高≤192取8；否则宽≤300且高≤300取10；其余取16。
- 4.06@412B8A创建/恢复大地图纹理和分块状态；412EE9保存地图缓存。原端使用D3D9/D3DX及map/<分组>/<地图号>.bin，不能直接当作当前SDL纹理接口使用。

以上来自已打开cg4.06cn实例的只读反编译和当前源码。413102部分参数由寄存器传递，缓存写出伪代码也存在类型恢复歧义；实施前按具体迁移点核对指令，不能直接照抄伪代码。

## 两种可选范围

| 方案 | 工作内容 | 结果与限制 |
| --- | --- | --- |
| A：只改善交互 | 像素平移、拖动状态、按钮提示、生成状态反馈 | 继续使用当前色块底图和2:1投影，不能获得4.06的实际资源缩略外观 |
| B：独立底图并改善交互（建议） | 大地图专用生成器，迁移4.06局部真实图形合成、缩小拼接、分块更新及坐标转换；包含A的交互改进 | 地图形态接近4.06；需新增离屏合成和独立缓存，工作量与验证范围更大 |

## 方案B实施边界

1. 大地图窗口使用专用底图对象；原UIMapExControl及Lua接口保持。专用对象管理地图快照、分块状态、像素/纹理缓存与视口坐标转换，不复制整套窗口系统。
2. 继续读取当前地图文件及已接收的地图更新。用当前Graphic资源、调色板、图片偏移和已确认的地图排序语义生成地砖/物件画面。人物、NPC动画、战斗、特效不进入静态底图；玩家和目标等标记单独叠加。
3. 投影和默认缩小除数按上述4.06依据；全局纹理边距、拼接区域、边缘重叠、读取范围、分块完成判定及重绘顺序在编码前补核原端。继续遵守用户排除的flag低8位截断，不因迁移重新引入。
4. 离屏目标在当前渲染边界内实现，使用现有SDL后端；大地图生成不能切坏主场景目标、裁剪、调色板或消费主场景绘制队列。具体承接现有CPU像素面还是SDL目标纹理，按当前接口与原端滤波需求核对后记录，不直接迁入D3D依赖。
5. 分块生成按原端增量行为组织；为未生成、已生成、待更新和数据缺失保留不同内部状态。已生成内容在刷新期间保留，界面明确提示生成中或缺少数据，不把失败当完成。性能验收不得以取消物件/降低图形完整性代替。
6. 独立缓存键至少包括地图分组、路径组、楼层、尺寸和图形/调色板有效状态。先完成内存缓存与失效链，再落实持久化；持久化使用本项目独立缓存目录，不覆盖4.06的bin。文件布局与版本需在该步骤补充SPEC；旧bin兼容尚未核证，不宣称可直接读取。选择B并不等于省略持久化验收。
7. 标注、玩家、目标、路线和鼠标拾取共用同一投影/视口转换；纸面遮罩和面板遮挡仍同时影响绘制与命中。法兰城1000等标注继续按gMapFloor匹配。

## 交互改进（A、B共有，均为待批准设计）

- 平移使用像素视口偏移，只有拾取时取整到地图格；按下后移动超过3个逻辑像素才进入拖动，单击不解除玩家跟随。
- 拖动捕获至松开；失焦或被更高窗口接管时终止，避免松手后继续拖动和场景误走路。
- 寻路、玩家居中按钮在选项栏开关两种状态均有悬停提示；右键选点后明确显示目标坐标和可执行操作。继续由按钮开始寻路，不增加快捷键入口或右键立即移动。
- 筛选保持整行可点，补齐悬停/勾选反馈；刷新坐标仍只重读mapdesc，不混同地图底图重建。
- 玩家居中、拖动、选点和换图使用统一状态转换；换图清除旧目标，恢复跟随；关闭释放窗口持有资源。
- 本轮不提出滚轮缩放、额外快捷键、地点搜索或新的寻路算法，以免扩大到未讨论的功能。

## 实施顺序与验收

确认范围后：先补核生成/排序/缓存关键证据并落实接口，再完成底图生成与坐标一致性，然后调整交互与缓存。按可验证小步同步唯一进度并提交。

必要验证包括：当前地图与换图、首次生成与重复打开、空区域与加载中区别、分块接缝及高大物件、标记和拾取坐标一致、面板遮挡、拖动松开/失焦、七类筛选、目标与现有寻路、纹理和缓存释放。构建沿已有授权使用build.bat Debug；不自动运行客户端或新增测试，实际画面/交互/性能由用户复验，编译通过不等于视觉等价。

风险：真实图形合成比颜色底图昂贵；SDL与D3DX滤波可能有像素差异；原端随机地图和特种地图分支需逐项核对。未证分支单独报告，不以色块回退掩盖，亦不承诺迁移后所有黑区消失。

## B方案已批准及实现裁决（2026-10-19）

用户已选择B，进入实现。4.06@4746C3确认层号升序、同层入队序号降序；4376E6对普通地砖flag1==1使用层2，否则层0，普通物件flag1<2使用层6，否则层3。静态对象遍历逆序等价于按投影Y升序、同Y投影X升序绘制；不在此链加入人物排序。

为适配当前CPU像素面，采用640×480原尺寸的互不重叠输出块，按412B49除数作BOX面积平均；每帧至多生成一个可见块，按视口中心优先。源候选以图形完整包围盒分配到块，避免高大物件被固定读图窗口截断。此为分块组织适配，保留真实图形、投影、偏移、层序和缩小后像素坐标；不照搬原D3D纹理/寄存器ABI。整图坐标基准为(352+32×(x+y),240+24×(地图宽+y−x))，底图与标记共用除数。

持久化缓存放data/cache/bigmap/<路径分组>_<路径组>_<楼层>_<模式>.bmc，使用新版本头、当前资源路径/文件长度/修改时间、调色板与色调快照、完整地图三平面及已完成块像素。按字节匹配有效性，不计算摘要；当前随机地图分组1不落盘。未完成/失败块不冒充完成；写临时文件成功后替换本项目缓存，不触及原端bin。文件同长度且修改时间被人为保持的资源替换不能由该元数据检测，清除独立缓存可强制重建。

.cut地图使用当前工程已加载的裁剪记录和静态图形范围；不注册或推进地图动画、音效。普通地图保留当前ResolveMapGraphicNumber映射和完整16位flag % 100。特殊地图底色/背景分支继续核对后接入，未证行为不填充假图。

## 实施核对补充

- 4377F4实际寄存器传入图号14392，源矩形(0,820)至(320,940)，为地图59529/38251补接该静态背景。另一个n7==7分支来自原端观察/转场控制（4515AC、40E802），本线未直接照搬该状态数字；本轮只迁静态地图，不接4.06的观察转场系统。
- .cut源裁剪沿当前DrawGraphic3_520970扣除GraphicInfo.x/y，不能仅减(320,240)；裁剪表单独快照，换图保存旧缓存时不得读取新地图的cut记录。
- 当前调色板/色调变化标记旧块待更新；地面和物件按实际变化范围失效。空块无需占生成配额；资源读取或上传失败保留旧像素并重试，不能以失败黑图落盘。原图上传限流可能返回成功但保留旧色，合成接口额外检查paletteChoice/version/index。
- 输入在平台边界查询前台窗口，失焦终止捕获；拖出地图视口仍保持捕获至松开，高层窗口已占用输入时终止。未增加快捷键。

- 413090及43858E进一步确认人物/地砖的横向基准为320+32；生成和视口均保留该32像素锚点，不能只取画面中心320。
