# 窗口更新鼠标状态字节合同 SPEC（WMB01）

2026-10-05，修正既有窗口更新对同源鼠标状态的访问宽度。
上位：[窗口合同](cg2d_ui_window_runtime.md)、[追踪体系](cg2d_traceability_acceptance_spec.md)。
固定快照：`cg2d-re-window-mouse-byte-source-20261005`。

<a id="window-mouse-byte-baseline"></a>
## 原事实及当前偏差

[原指令证据](cg2d_window_mouse_byte_evidence.json)记录473F80完整103条/368B及唯一504170尾跳；
504120完整23条/85B只作为当前真实入口背景，不代全部场景或运行。
原474058和4740E7以W8写D68DB4=0xD4，4740D9以U8比较同一地址是否小于0xD4。
现有LegacyMouseState.valueD68DB4是32位共享承载，既有窗口更新却整字段赋212并整值比较，
可能改写原指令没有写的高三字节，比较范围也与原指令不符。
其他已有窗口代码使用unsigned char别名读写这一低字节；本组保留唯一共享owner和32位布局。

<a id="window-mouse-byte-decision"></a>
## 实施裁决

依已有工程委托，两个写点只经unsigned char别名写低字节；尾部比较先取uint8_t低字节。
不重定义字段、不新增影子状态/工具函数，不改变高三字节或其他共享调用者。
焦点路径仍按原先取phase→写鼠标字节→写焦点→必要拖动/重置→draw；
尾部仍先快捷键和预设热键、取phase、清current ID，再条件写C8A780=1及低字节212。
没有增加保护、拒绝、钳制或回绕；两写点与一比较是普通访问宽度修复，符合RPLAN.24。
原现代窗口update/draw及拖动回调、元素可见性和共享索引重读、carry和返回1保持。

本步新增473F80语义/具名源码处置及限定S证据，补FUNC-UIRUNTIME基线/已知成员。
现有504120调用不变；没有取得57C368 handler的实际间接调用合同，不凭表内地址生成旧表分派。
旧99条路由/键表、完整输入/owner/alias及原新ABI和运行继续独立验收。
