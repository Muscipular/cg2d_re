### 数值、预览与伤势

所有CryptInt调用独立执行，调用后下一次取值重新读selectedPet/排序编号：

1. nextExp(+5C)与-1作Equal_401D00比较。
2. 恰-1时另取exp(+4C)，按`%8d/       -`；否则另取nextExp再取exp，
   按`%8d/%8d`。两路写11，不把比较的读取值当下一次显示值。
3. 最大HP(+1C)→HP(+0C)，`%5d/%5d`写12；
   最大FP(+3C)→FP(+2C)，同格式写13。
4. S16种族(+4)直接索引原57CB54二十项表，写14，不增加范围/used门禁。
5. 忠诚度(+98)按`%3d`写15、技能槽数(+6A4)按`%2d`写16、
   等级(+8)按`%3d`写18，三次分别重取编号。
6. 重取一次编号，固定同一宠物，先读最大负重(+6E0)再读负重(+6DC)，
   按`%6d/%6d`写19，不把它们当CryptInt。

11/12/13复制时固定elements、测长后取data；15/16/18/19则先固定data。
种族复制固定编号后先取currentWindow，再S16读种族，固定elements后测长/取data。
上述数值共用原256B局部，不新增截断、严格解码或安全格式改写。

预览20：重取编号，固定elements后读宠物+6A0图号，取其
WindowAnimationData中的真实YobiAction*，写2A8；再重取20.data，
读取共享D673D0，取这一载荷的action写2B8。不缓存第一次action，
