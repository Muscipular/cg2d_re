## 局部方案与边界

按已有工程委托裁决：完整父入口与专有对象逻辑放在YobiRuntime的login::detail，
沿既有私有YobiAction定义处理字段，不暴露对象布局或增加逐字段跨模块桥接。
583B00用既有LegacyPanelRecord私有承载，初值x/y=0、宽272、高252、
id38、首底图23357，其余为零。D67CD8为原生非拥有YobiAction*，
关闭只MarkDeath后清槽，不直接释放。父入口关闭返回对象地址，正常返回W32绘制结果，
仅混合返回边界用uintptr_t，不将对象地址截成32位或改为句柄。

CC3E78阶段、CF3F10分类、三组停播值/时钟均由该链唯一持有；
直接xref确认D2D494/D2D64C/D64E0C只在4EE670写零并作为FrameMove第三参数，
不是本轮新增的帧递增计数。CC3E84/D2F794/C8B38C分别由同函数采样/消费。
CF46C4、D64E13保留WindowRuntime唯一owner，增加窄只读入口；
CC236C只读第一槽，不能用5043D0的布尔查询或按可写类别查表替代。
技能配对、技能、玩家、socket、D67AD8、D67C48、5F9754沿既有owner。

对象+294在现有bytes290的偏移4以memcpy读写S32，不重排或扩宽对象，
也不破坏其他对象族对这20B的复制。初始化返回S32；传给503160时使用
明确弃返回的无捕获void适配，不强转不同返回类型的函数指针。
0/1分类动画的同构控制流共用实现，三组实际状态仍分开；
不合并两次时钟采样，也不改成相减判断超时。

只实现已证本体及其内部调用。57C368旧选择记录的id38/handlerToken4EE380
仍是历史表数据，既有有界调查未证handler调用器，不猜造分派或称已生产运行。
504C50另有4EDB20、4EF0F0、4F1C40、4F3ED0四个caller，本轮仅接已实现的4EE380。
不改变三个补零待决，不构建、测试、运行或检查产物。

## 父入口与动画

503160(opened,panel,initialize,1)返回0直接退出。
返回2时，CC236C首槽不为19才处理pending：非零只清D67C48；
否则5F9754非零才读玩家Y/X、511DD0(socket,x,y,62)、清5F9754。
然后取对象，非空MarkDeath、清槽并返回该对象；空返回0。

其他非零结果正常推进：先采玩家图号，再采对象图号调用504C50。
变化才写图、按上述六区间写+294（120156族在此也写0），
标志0时加S8偏移{-2,-1,0}[分类]；按**未偏移的mapped**
决定+309/+310，非特殊只清+309。无变化也在对象非空时清flags bit1。
4D3040(1,1)非零关闭选择并SE57，之后仍继续动画和绘制，不提前返回。

动画分类0/1：阶段0在标志0时分别图号-2/-1，动作1，停播值清0，
采对应U32时钟后阶段1；阶段1先采now，再以`start+2000 < now`
决定动作5/阶段2；阶段2用S32 completedLoops>=2选动作16（标志0）或6，
转阶段3。分类2阶段0直接动作5、清停播值、采时钟、阶段1；
阶段1以S32 completedLoops>=4选16/6、阶段2。
每路随后另采now，再读同源extra/start，U32 `extra+start+4500 < now`
成立才终止（0/1阶段4、2阶段3）、flags|2、返回1；
否则FrameMove(object,100,对应停播值,0)，返回0。空对象/未知分类直接1。

动画返回非零，局部16B仅首字节置NUL，D67AD8、D64E13按S8，配对index按S16，
511EF0(socket,index,level,-1,text)，再置pending=1并关闭当前面板。
尾部仍画分类文本(x+72,y+168,2,0,0,text,0,0)，再503440(panel,1)并返回。
三条文本原字节（含NUL）分别为：

| 地址 | 字节 |
|---|---|
| 589898 | A5 EF A4 EC A4 A4 A1 45 A1 45 A1 45 00 |
| 589888 | A5 B4 C2 79 A4 A4 A1 45 A1 45 A1 45 00 |
| 589878 | AB F5 B1 B8 A4 A4 A1 45 A1 45 A1 45 00 |

保留原编码，不根据IDA显示文字重新编码；显示边界仅按既有DrawText合同取低S16。
操作数字节另核：4EE9E0/4EE5DE/4EE5E5为0F BE，4EE9E7/4EE5F7为0F BF；
因此配对index不可随前一个字节索引误缩为S8。
