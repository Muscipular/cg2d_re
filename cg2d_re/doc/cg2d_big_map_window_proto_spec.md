# 大地图迁移WindowPrototype（BMWP01）

状态：2026-10-19用户已确认并实施，编译链接通过，游戏内验收待复验。

## 目标与现状

将大地图由script::BigMapWindow继承UIWindowInstanceEx、WindowExOpen注册，迁移为现有ui::WindowPrototype及WindowElementPrototype模式。现有原型定义位于src/ui/WindowRuntimeState.hpp，创建、调度、控件分发和释放由WindowRuntime.cpp承接。

当前原生窗口运行表和存档共用kWindowCount=71；不能只增加该常量，否则会改变WindowSavedData的磁盘布局。当前大地图82是扩展窗口编号，迁移后不再注册这份扩展实例。

## 改造方案

1. 在原生窗口编号末尾新增WindowId_BigMap=71，注册独立WindowPrototype；运行期窗口表扩展为72项。单独保留原存档数量71，核对初始化、读取、写入、关闭回存及场景重开分支，原存档结构和既有窗口编号不变；新大地图不写入原窗口存档、不随登录或场景恢复自动打开。
2. 窗口实现迁入src/ui/windows/WindowBigMap.cpp。使用原型update/draw/release回调，按钮、七类筛选的命中区域、图片和文本通过WindowElementPrototype及对应实例表达，复用控件回调完成显隐、选择状态和按钮操作。地图专用绘制留在窗口draw回调，不新增通用控件类型或另一套UI框架。
3. 大地图业务状态按单实例生命周期持有：地图生成器、标注、筛选、目标和拖动状态在初始化时建立、release时释放。BigMapSurface继续沿用现有独立生成、缓存和裁剪算法；绘制接口及命名空间只做接入所需调整。
4. 标题拖动、地图平移、右键选点与双击寻路接入原生窗口输入顺序，确保控件先消费事件、地图后消费；失焦和关闭终止捕获，重复打开只激活现有窗口。原生拖动若与地图拖动冲突，仅在大地图回调中区分标题和地图命中范围。
5. 小地图按钮改调原生打开入口，删除旧大地图扩展窗口注册及其无调用入口。保留小地图唯一入口，不添加快捷键或Lua依赖。
