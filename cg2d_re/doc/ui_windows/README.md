# 窗口明细文档组织 SPEC

本轮按用户“按 window id 分文件记录具体明细内容”的要求实施。
本次仅调整文档组织与引用，不修改实现、原端合同、覆盖范围或验收标准。

## 文件职责

- [总索引](../cg2d_ui_window_runtime.md)保留当前状态、按窗口编号的入口和公共机制入口，不继续累积各窗口明细。
- `window_<十进制ID>.md` 是对应窗口的明细入口，记录原型地址、元素表、主回调、专属取证、实施状态及共享依赖。
- `shared_runtime.md` 记录通用创建、生命周期、绘制、输入、焦点、移动父链与启动/保存，不按窗口复制。
- `shared_items.md` 记录跨窗口物品、宠物、换位、拖动与提示依赖。
- `shared_dialog_routes.md`、`shared_profile.md`、`shared_battle.md` 分别记录跨窗口对话路由、资料交互/路由、战斗目标选择。
- `shared_<ID>_<ID>.md` 只记录两窗口确实共用或在同一次取证中不可拆开的合同；各窗口文件必须链接具体章节，不把同一正文复制两份。
- 没有专属取证正文的窗口不补写推测内容；原型表已有声明不等于窗口已实现。
- `legacy_*.md`承接57C368旧选择编号，标题须标明旧ID，不能写入同号现代`window_<ID>.md`。总索引分列两套编号；跨旧ID共享合同保持单一来源，不因本次总结改名或复制既有证据。
