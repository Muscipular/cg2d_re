1. 仅SceneState.cpp/Sub_51D5B0两模式/两局部块。低半字用既有memcpy读sizeof(uint16_t)=2B；保两字段读序、独立C8A740写点及首次gate读取点，再以同一packed owner字节地址+2写2B缓存低半字。原高半字被覆盖、低半不变；不分裂共享槽、不添影子状态或换字段类型。

4. 一个既有本体补原身份/真实来源及adapted，同时明确MAP/LOOP关联。原31条/两call保存只该局部和正常入口合同，所有父/地址逃逸与间接alias、动作/观察链owner重进退出/借用失效、既有空链返回承载、实际ABI/SDK/时钟/RNG/场景与画面运行未闭。
