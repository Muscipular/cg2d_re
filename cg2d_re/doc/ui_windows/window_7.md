## 范围与工程合同

原型54E360：window id 7，初始坐标(15,97)、尺寸315×261，
73元素起于55FD60；更新474540、绘制46FBC0、释放474310。
本步仅实现完整刷新474FB0及更新/释放，不以部分元素表替代73元素，
不登记占位按钮，不宣称完整创建、交互或画面验收。

按既有工程委托采用以下局部方案，不触发全局SPEC对齐或日志压缩：

- 玩家仍由SceneState私有PlayerRuntimeSlots持有，公会仍由LegacyRecordOrder持有；
  只增加窄读/文本借用接口，不复制资料缓存，不公开原生布局。
- 称号直接借既有gTitlesFF0508，族名复用gTribeNames57CB54；
  所有窗口/元素/图形/文本引用采用原生非拥有T*。
- 四条属性条使用一个内部刷新函数消除实际重复；每次先清十个visible，
  再读取该属性，不提前取得四值。每次图号写入与可见位写入分别重取当前窗口。
- 沿用原256B格式缓冲、含NUL复制和原字节；不截断、不新增索引检查、
  数量钳制或空指针保护。越界/溢出遵循RPLAN.24，不专项模拟。
- 释放适配既有void签名，原EAX=1由生命周期调用者丢弃；
  更新保留未使用S32参数，刷新后返回1。
