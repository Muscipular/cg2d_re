## 头文件与依赖

- `src/Yobi/base.hpp` 为内部基础头，容纳 `YobiAction` 的完整定义及其必需类型依赖；构造实现仍在 `base.cpp`。保持 `cg::login`、`cg::login::detail` 与 `cg::world::detail` 的现有职责和外部符号。
- 各功能头只承接该组需要共享的类型和内部声明。当前仅匿名 namespace 可见、拆分后确需跨组调用的定义，才调整为内部具名声明；单文件私有定义继续私有。
- `include/cg/YobiRuntime.hpp` 继续作为外部声明入口，保留现有接口及不透明 `YobiAction` 声明；不让 UI、场景、网络或渲染直接包含内部完整布局。当前已经公开声明的函数不在内部头重复抄写声明。
- 新 CPP 显式包含自身功能头及实际依赖。更新迁移后失效的相对 include，不扩大包含搜索路径，不通过包含 CPP 拼装编译单元。
- `cg2d_re/CMakeLists.txt` 在原 `src/YobiRuntime.cpp` 条目位置显式列出分组 CPP；完整迁出后删除原 CPP。根 CMake 和独立 AnimationRuntime 模块不纳入本次拆分。
