## 窗口50四记录生产与图号回退 SPEC（2026-09-29）

接续4800e351，先实现4B6970@[4B6970,4B6C14)及其缺失依赖
51BC50@[51BC50,51BCFF)，不以窗口52图号规则替代。
4B6970沿既有LoginWindowRuntimeSlots的D3FAD0与四条D3FAD4记录，
不复制或更换4B5A90已经使用的owner；记录步长40CH、首两S32、四个256B文本
及+408的S32保持不变。另建D30138..D303F8的唯一2C0H字节区，
初值虚拟零，仅做原清零；4DFD38从同区+9起消费，字段未完整取证前不命名业务，
后续必须复用，不当作无用清零删掉。

51BC50先采58B6A0低U8，仅FF时取Puk版本，再调用已有51BA10分类；
版本<3允许类0、3..6允许类3、>=7允许类6。已允许或类0原样返回。
未允许类1/2/6用51BD00，类3用51BAC0，类4在允许类0时先51BF00再51BAC0、
否则仅51BF00，类5在允许类0时51BD00否则51BF00，其他原样返回。
该函数与51B740类别和回退函数均不同；仅新增到既有CharacterSelectPreview，
复用同一覆盖/Puk状态及原图号叶，不改旧叶或扩大数值宽度。

4B6970顺序：

1. 发布入口flags到D3FAD0，原位52D150（不是52D2F0），清2C0H区，
   按`|`取字段1到同源CC24D4标题，容量16。
2. 从字段2开始，四记录各消费五字段：首整数经51BC50写+0；
   次整数写+4；第三整数写+408；第四字段(cap767)经52D2F0，
   长度>16才拷贝原554590的`???`，否则原样复制到首256B文本。
3. 第五字段(cap767)经52D2F0；**先strcpy至256B临时区，再两次strlen**，
   长度>140时分别复制同源593850到后三个文本，不用固定空串替换。
4. 长度<=140时固定执行三轮，每轮只认CR(0DH)，最多70字节；
   先推进源索引/写字节，再判断索引>长度，未超过才推进目标索引并判断70。
   每轮按当前目标索引写NUL；44B190返回3时源索引退1、上一目标字节改NUL。
   不改为普通分行/Unicode算法，不把LF也当分隔符，不先补零临时区。
5. 每记录尾偏移加40CH，到1030H停止并返回最终偏移4144；
   不按首图号或时间过滤记录，也不在此打开窗口。

临时区仍为768B字段区+256B拷贝区连续1024B，保留先复制后校验和三轮扫描。
拷贝越界、读未初始化尾部和数值异常按RPLAN.24，不新增校验或复现原栈残留，
不将异常路径记为修复/验收。51BC50和文本叶接口按现有模块复用，
后续仍需窗口50输入/逐帧回调、36元素及交互、49D2E0父路由接线。

实施状态：两函数及2C0H唯一清零区已落位，4B6970复用既有四记录/标题owner，
51BC50复用原类别与回退叶、同源版本状态。两函数全指令、两个父路由caller、
清零区及记录虚拟零初值、4DFD38同区消费、字段/复制/分类顺序、声明与源登记
已静态核对；58元素/102主回调/13网络回复不变，未构建/测试/运行/检查产物。

不把原生T*截回字节或伪造固定成功，其他函数维持已证返回契约。

四组重复更新可按七元素步长表达，来源仍既有同一四记录；日期结构沿项目
现有不完整类型指针与显式偏移memcpy读取，不另造tm布局或时间状态。
本步不映射36元素，不因类型读取取证而宣称元素已落位；鼠标两回调及
