## DNS 与提示

沿参考以服务器地址和端口构造 <地址>.<端口>.cg.qoq.im，使用系统 getaddrinfo、AF_INET／SOCK_STREAM 查找并取首个可转成文字的地址；每次 WSAStartup 成功均配对 WSACleanup，查询成功的 addrinfo 链配对 freeaddrinfo。不迁移 utils.cpp 其他 TXT 查询／指定公共 DNS 流程，不新增依赖。

| 检查结果 | 行为 |
|---|---|
| 解析结果非空且不等于 0.0.0.0 | 直接 std::exit(std::rand())，不弹提示。 |
| 解析失败、无可用地址或结果为 0.0.0.0 | MessageBoxW 弹出参考的完整研究用途／版权／退款提示，父窗口为 nullptr，标题为“提示”，标志为 MB_YESNO／MB_ICONWARNING。 |
| 提示选择“是” | 返回原连接流程。 |
| 提示选择其他结果 | std::exit(std::rand())。 |

每次普通地址成功查询均执行这条策略；不增加结果缓存、白名单、超时、重试或新输入限制。此 DNS 结果仅用于检查，不替换真实连接地址。开发期间不执行 DNS 查询。

## 本线适配裁决

1. 参考 MY_DEBUG 是独立编译开关；本线复用 A11 的 IsClientDiagnosticsEnabled（Debug 构建或 --debug），调试时跳过普通地址的 DNS／提示。不开新配置项，不改现有诊断初始化；该初始化位于主循环连接查询之前。
2. 源 hook 忽略原查询失败并固定返回 0；本线保留已落实的 -1／0 查询合同，只在成功查询后应用 A10，避免改变现有连接失败分支。
3. 源 ipBuffer 借用临时栈缓冲并通过脱离线程、全局 mValue 和随机 Sleep 等待；本线在查询调用内同步完成 DNS／提示，参数在调用期间有效，不移植这些线程及全局中转机制。首次查询仍须等待许可；重复查询也等待本次检查完成，明确区别于源 mValue 未复位时的异步返回。
4. 源退出分支同时使用脱离线程 exit 和 x86 随机地址 ret；本线将这两类终止手段统一为单次标准进程退出，保留 DNS 命中／拒绝提示的退出条件及随机退出码，不移植随机跳转、忙等 Sleep 或其随机数消费。该机制适配不声明源线程竞态／随机数调用次数等价，也不扩展其他业务 RNG。
5. 普通地址继续沿既有字面地址复制，不迁移 sprintf(ip, buff) 的格式字符串用法或 hook 日志、VM／异或地址保护。公共接口只传 char 地址和 W16 端口，Winsock／Win32 类型留在 platform 实现中。
