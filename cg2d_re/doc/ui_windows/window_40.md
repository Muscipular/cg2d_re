## 工程边界

按既有工程委托，三类邮件仍由MailState唯一持有，新增非拥有MailMessageView，
仅借用原消息+0未读W8、+1种类W8、+2文本及+14H正文。
普通F7CA08按角色/联系人/页、公会DE0B30按角色/邮件槽/页、迷你10763A0按联系人/页
计算地址，显式传入各阶段已采样索引；借用函数不自行读取角色或复制UI缓存。
只按原字节区取得std::byte*/const char*，不将原字节区强转新结构体对象。
角色保持S16，其他索引/页号保持S32；地址按原生T*，不截为W32。

4A48A0的唯一caller为4A4627，返回后立即调用519300，不消费返回寄存器。
原返回混合扫描地址/整数，包括全零扫描后的数组前地址。本线采用void，
保留全部状态写入、扫描与调用，省略无人消费的返回，不构造数组前指针。
这不是邮件读取失败保护：公会刷新原有slot==-1分支保留，悬停无此门禁也不添加。
物品占用直接借用SceneState的D67B08七W32字节视图；头像借ReadPlayerValue17C，
即FDA87C，不与FDA878图号合并。509080复用已有真实单RET适配，不造空依赖。
