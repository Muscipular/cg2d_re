2026-09-28，只读核50E3C0/50E3F0、4E4E80/49E800/4E4E60、
4E5620/4B0110、4D3020及511FF0全部指令；核唯一dispatcher

### 同源承载与类型裁决

沿受托工程决议：十条17B选择文本CF3F20、S32计数CF46A8和
CB1E14唯一回调归UI；回调采用
`void (*)(int32_t, const char*)`，原49EFCA传编号和该项文本，
不消费返回。文本仅借用，回调不拥有选择表。
49E800、4E4E80、4B0110、4E5620的创建结果保留YobiAction*，
不缩成W32；D67B7C为同源非拥有YobiAction*，创建失败同样写nullptr。

CF4A1C/D673E0为数值页签，CC4C94/C8AF68/CB03CC/CF4AB8
为逐条递增的计数，D67CB8/CBC、CC3EC4、D66E08、CC2344
按原数值宽度保留S32；补核4E621E/4E623C、4E6694–4E671A、
4E8549/4E854F/4E8602的生产证据，不把数值扩大为地址。
17B交易名称D2D654及上述新增状态均为原虚拟零初值。
CF4688、D046D0、CC4224、D2E2B0、D67B80及两组交易物品/宠物
复用已有owner，不重建副本或在单侧复制时额外重置。
4D3020仅将x→CC4D34、y→CC4D3C两S32依序保存并返回x，
不保存CryptInt对象、猜测中间地址用途或新增移动限制。

### 选择列表与回调

49E800先计数清0，再逐条只清十个文本首字节。
独立字段索引从1递增，最多执行十轮；还保留当前count<10门槛。
每轮提取最多255B到同一未预清256B局部区，返回严格1时停止；
否则52D2F0反转义，重读共享count后复制到该项并递增count。
不按文本长度截断、不跳过空文本、不把字段索引改为共享count。
原分段复制的主体在count发布前、末0..3B在发布后完成。
循环后保存回调，再按Y→X读取玩家CryptInt，4D3020(x,y)，
CreateWindowAnimation(44,1,0,nullptr)，原样返回YobiAction*。
4E4E80仅传入真实4E4E60回调，不额外反转义整段源文本。

4E4E60先用共享socket发送511FF0(socket,index)，不检查发送结果；
随后4E5620(name)，不能因发送失败跳过本地打开。
511FF0依原58B2EC的ASCII `QeuC`建命令，格式化整数前采共享容量，
追加与发送分别重读共享缓冲，返回真实发送值，不新增重试。

### 完整打开与回复门禁

4E5620先清完整1EBE0H交易物品区，再清3BD8H交易宠物区。
随后按原序清CF4A1C→D673E0→CC4C94→C8AF68→CF4688→
CB03CC→CF4AB8→D046D0→CC4224→D2E2B0；

再D67CB8=0→D67CBC=0→CC3EC4=-1→D66E08=0→CC2344=0，
最后4B0110先D67B80=0→CreateWindowAnimation(43,1,0,nullptr)→

50E3C0：9A6E0C非零直接返回；否则仅一次CryptInt门禁，
为0才4E4E80(text)。50E3F0也先同一场景门禁；
